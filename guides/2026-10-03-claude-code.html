1. Claude Code는 무엇을 해주나요?

“이 폴더의 자료로 안내 페이지를 만들어줘.” Claude Code는 이런 요청을 받아 파일을 읽고, 필요한 파일을 만들거나 고치고, 명령을 실행해 결과를 확인하는 도구입니다. 코드를 복사해 붙이는 단계까지 사람이 모두 처리할 필요가 줄어듭니다. 다만 실제 파일이 바뀌므로 작업 위치와 허용 범위를 알아야 합니다. 공식 문서 · 작동 방식 ↗

여기서 Claude 모델은 내용을 이해하고 다음 행동을 판단하는 부분입니다. Claude Code는 그 모델이 파일과 도구를 사용해 일하도록 연결한 제품입니다. 처음에는 “판단하는 AI와 실제 작업 도구가 함께 있다”고 이해하면 충분합니다.

하네스 엔지니어링은 이 작업대를 더 잘 구성하는 일입니다. 거창한 자동화부터 만들 필요는 없습니다. 참고 파일 한 개, 분명한 요청, 확인할 항목 세 개만 있어도 시작할 수 있습니다.

예를 들어 “안내 페이지 예쁘게 만들어줘”에서 멈추지 않고, “이 자료의 일시와 장소를 그대로 넣고, 휴대폰에서도 읽기 쉽게 만들고, 신청 기능은 넣지 말아줘”라고 알려주는 것입니다. 이제 AI가 할 일과 사람이 확인할 일이 함께 선명해집니다.

3. Claude 데스크톱 앱으로 시작해도 됩니다

Claude Desktop은 Claude를 앱 창에서 사용하는 방법입니다. 앱에는 Chat·Cowork·Code가 있습니다. 이 가이드처럼 프로젝트 파일을 만들고 수정하는 실습은 Code 탭에서 진행합니다. CLI는 같은 Claude Code를 터미널에서 사용하는 방식입니다.

CLI와 무엇이 다른가요?

작은 화면에서는 표를 좌우로 움직여 두 방식을 비교하세요.

이 가이드의 선택 기준: 화면과 변경 내용을 나란히 보며 첫 페이지를 만들고 싶다면 앱으로 시작해 보세요. 명령을 복사해 재현하거나 스크립트에 연결하는 작업을 익히려면 CLI 예시를 따라가면 됩니다.

이 글의 CLI 명령을 앱에서 따라갈 때

  • claude --model … --effort …는 운영체제 터미널 명령입니다. Code 대화창에서는 해당 메뉴를 선택합니다.
  • /permissions 같은 터미널 전용 패널 명령은 앱에서 사용할 수 없습니다. 권한 모드는 메뉴에서 선택하고, 세부 규칙은 설정 파일을 확인합니다.
  • /config는 앱 설정을 엽니다. 뒤에 설정값을 붙여도 적용되지 않습니다.
  • 스킬은 / 또는 + → Slash commands에서 찾습니다. Wayfinder·Superpowers도 앱의 플러그인 관리자에서 설치·활성화를 확인한 뒤 실제 표시된 이름으로 호출합니다.

앱의 터미널에서 claude 명령도 쓰고 싶다면 독립 CLI를 별도로 설치합니다. 심화 실습에서 쓰는 Node.js·Playwright도 앱 설치에 포함된 것으로 가정하지 않습니다.

실습에서는 Local부터 선택하세요

앱에는 Cloud·SSH 등의 실행 환경도 있습니다. 선택한 환경이 바뀌면 작업 위치와 사용할 수 있는 도구도 달라집니다. 이 장은 내 컴퓨터의 파일을 다루는 Local 기준이며, Cloud에서 같은 폴더나 설정을 그대로 쓴다고 가정하지 않습니다.

화면이 다르면 먼저 앱을 업데이트하세요. 데스크톱 앱 버전과 claude --version으로 보는 독립 CLI 버전은 구분합니다. 계정·운영체제·설치 버전에 따라 메뉴와 제공 기능이 달라질 수 있습니다.
