# Pinterest 사용자 여정 추론

- 작성·확인일: 2026-11-02
- 글: `insights/2026-11-02-pinterest-user-journeys.html`, COMMERCE INSIGHT 08
- 업무 질문: 추천 담당자가 흩어진 상품 탐색을 어떤 목적에 묶고 다음 방문에 무엇을 보여줄지 결정한다.
- 범위: 공식 운영 사례, 성과의 비교 기준, 자사몰 이어보기 카드 제안. 모델 실행·고객 실험·알림 발송은 수행하지 않음.

## 공식 근거

### 현재 운영과 실험의 경계

- [From Activity to Intent: Generating User Journeys with LLMs](https://medium.com/pinterest-engineering/from-activity-to-intent-generating-user-journeys-with-llms-9652b9417626)
- Pinterest Engineering, 2026-10-09. 본문 전체와 Figure 3 확대 화면을 브라우저에서 확인.
- 운영 모델은 추가 학습한 Qwen3 4B. 출력은 순위가 있는 여정 이름 목록이며, 상품 목록·구매 확률·발송 결정과 구별한다.
- 이름은 후속 검색에 쓰고 검색·순위·발송을 별도 처리한다. 거절한 여정 억제와 근거 부족 시 빈 목록 허용을 확인.
- 현재 운영 설명과 `What we’re building now`의 의미 코드·외부 전환 신호·피드백 최적화를 구분한다. 실험 확대 범위를 전체 사용자 제공으로 표현하지 않는다.
- 초기 미국·캐나다 실험은 기존 군집 시스템 대비 이메일 클릭 +1.1%, 푸시 열기 +1.3%의 상대 개선으로 읽는다. 절대 비율·표본 수·실험 기간이 없으므로 %p나 구매 전환 개선으로 바꾸지 않는다.
- 정확한 의도 파악률·매출·공헌이익 개선을 입증한 근거로 사용하지 않는다.
- 후속 공식 공개 여부를 주제·제목으로 검색했으며 이번 확인에서 위 실험의 전면 적용을 입증할 별도 공식 자료는 확보하지 못했다. 현재 상태는 이 글의 공개 시점 기준으로 기술한다.

### 이전 시스템의 성과

- [Identify User Journeys at Pinterest](https://medium.com/pinterest-engineering/identify-user-journeys-at-pinterest-b517f6275b42)
- Pinterest Engineering, 2025-10-21.
- `Experiment Results`와 각주 확인. 미국 2025년 4~5월 내부 데이터. 관심사 알림 대비 이메일 클릭 +88%, 푸시 열기 +32%. 군집 기반 여정 알림 성과로 귀속한다.
- 새 LLM의 추가 개선치와 분모가 다르므로 합산하지 않는다. 구매·매출 지표로 옮기지 않는다.

## 편집과 제품 제안

- 작은 주방·선반·수납함·장난감의 기록과 담당자 검토 카드는 자체 가상 예시다. 실제 Pinterest 출력이나 고객 기록이 아니다.
- ‘목적 후보 + 근거 행동’, 목적 식별자·거절 기록, 자사몰 이어보기 카드, 치수·재고 확인은 헬로우 휴먼의 설계 제안이다. Pinterest의 출력 계약을 확장해 설명하지 않는다.
- 가상 100건은 초기 오류 탐색 규모의 제안이며 통계적 성과 검증 표본이 아니다.
- 모델 호출료의 실제 견적이나 성과 실측이 없으므로 임의 비용 금액·ROI를 넣지 않는다. 운영비 평가의 포함 항목과 분모만 제안한다.
- 시스템 구성 전체를 옮기는 대신 목적 추정과 상품·발송 검증의 책임을 설명한다. 공개 원문에 등장한 개인정보 필드를 우리 제품의 필수 입력으로 복사하지 않는다.

## 검증 기록

- `node --test`: 기존 71개 테스트 통과, 실패 0개. 새 JS나 테스트는 추가하지 않았다.
- `git diff --check`: 오류 없음.
- 파일 기반 검사: 홈·목록·본문 제목 일치, 08호·총 8편, 새 글 1회 등록, 내부 링크와 상대 자산 경로 존재, 중복 id·누락된 목차 대상 없음, noindex 유지.
- 브라우저 검사: 프로젝트 하위 경로(`/hello-human/`)로 로컬 제공. 데스크톱 1280px와 모바일 390px, 라이트·다크의 한글 줄바꿈·도식·검토 카드·표·이미지 확인. 문서 가로 넘침 없음.
- 좁은 화면의 표는 내부 가로 스크롤을 사용한다. 키보드 오른쪽 화살표로 스크롤 위치 0→40 이동 확인.
- 외부 링크의 새 탭·noopener·noreferrer 확인. 목차 이동 확인. 브라우저 경고·오류 로그 없음.
- 목록의 새 글 New 확인 → 본문 열기 → 목록 복귀 → 새로고침에서 New/Updated 재표시 없음. 홈 최신 카드의 링크·날짜·제목·08호 연결 확인.
- 확인 한계: 모델 추론, 고객 실험, 상품 API와 실제 발송은 수행하지 않았다. 원본 이미지는 외부 서버 로딩에 의존한다.
- 결과는 로컬 변경만 남겼다. 커밋·푸시·배포하지 않았다.

## 2026-11-02 시각화 보강

- 요청: 글의 인사이트가 더 직관적으로 드러나도록 시각화를 강화한다.
- 첫 도식을 행동 기록 → 목적 묶음 → 두 개의 가상 쇼핑 화면으로 교체했다. 선반·수납함·장난감 아이콘은 직접 작성한 SVG이며 실제 상품 사진이나 Pinterest 화면이 아니다.
- 같은 가상 기록에서 `계속 찾는 중`, `이미 골랐어요`, `맞는 선반 품절` 세 상태를 바꿔본다. 목적별 추천의 의미를 묶음 제안·종료 기억·판매 가능 조건 확인으로 설명한다.
- 비교 A는 목적 종료 정보를 사용하지 않는 단순 상품별 추천이라는 가정이다. 이를 기존 추천 시스템의 일반적인 한계나 Pinterest의 실제 대조군 구현으로 해석하지 않도록 화면 아래에 표시했다. 품절 상태에서는 A와 B 모두 같은 재고 조건을 적용한다.
- 인터랙션은 고정 문구와 화면을 전환한다. 모델 호출, 고객 기록, 외부 API, 상품 검색, 알림 발송, 실제 성능 측정은 없다.
- 성과 표를 두 개의 독립된 비교 카드로 변경했다. 기존 수치·상대 개선율·지역·비교 기준을 유지했으며, 합산 그래프나 출처 없는 성능 수치는 추가하지 않았다.
- 변경 파일: 본문 HTML, 전용 CSS(v2), 전용 JS(v1), 이 기록. 기존 글의 URL·호수·날짜·홈·목록 소개는 유지.
- 검증: `node --check assets/insight-user-journeys.js`, `git diff --check`, 기존 `node --test` 71개 통과. 별도 테스트 파일은 추가하지 않음.
- 브라우저에서 3개 상태의 단일 패널 표시, 품절 시 양쪽 선반 추천 보류, 초기화, 방향키로 라디오 선택과 결과 전환을 확인했다. 데스크톱 1280px·모바일 390px와 라이트·다크에서 도식·비교 화면·성과 카드 배치를 확인했으며 가로 넘침·콘솔 오류 없음.
- `DOMContentLoaded` 이후 초기화한다. 조작 → 목록 복귀 → 새로고침에서 해당 글의 Updated 오표시 없음. JS 없이 읽는 기본 HTML에는 탐색 중 예시가 남고, 동작하지 않는 조작부는 숨겨져 있다.
