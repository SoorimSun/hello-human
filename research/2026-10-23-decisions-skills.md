## 초안에서 바꾼 편집 판단

- 포괄적인 ‘AI 에이전트’ 제목 대신 주요 제품과 정식 출시 사건을 제목으로 삼았다. 제목·메타·H1·목록·홈을 동기화한다.
- ‘최근 24시간’을 쓰지 않았다. 원문 게시일을 확인했지만 모든 발표 시각을 한국시간으로 환산해 24시간 창을 검증하지는 않았다.
- Decisions 속도 비교 대상과 베타 이후 기능 추가 시점을 보완했다. 기본 단가 외 캐시 저장·지역 처리·긴 입력 조건을 덧붙였다.
- Agent Skills를 처음으로 공통 표준이 된 것처럼 묘사하지 않았다. 관리 체계 이관과 향후 제안 구분을 유지했다.
- Uber의 업무 플랫폼 도입과 개발자 Codex 사용을 나눴다. 사내 스킬이 Agent Skills 규격이라는 연결은 근거가 없어 단정하지 않았다.
- METR을 현재 시스템의 인증처럼 소개하지 않았다. 공개 범위 제한, 사전 합의와 삭제 권한, 재검증 한계를 보완했다.
- 최초에는 커머스 문의 분류 실험을 제안했으나, 개발자에게 도움이 되는 엔지니어링 관점을 원한다는 후속 요청에 따라 CI 실패 로그 분류·진단 실험으로 바꿨다. 실제 구현이나 성능 측정을 한 것으로 쓰지 않는다.

## 검색·후속 자료 확인 범위

공식 원문에 더해 API 변경 기록과 현재 개발자 문서를 확인했다. Decisions API 베타 이력, Agent Skills 이관, Uber 도입, METR 평가의 후속 정보를 검색하고 공식 근거만 기사에 사용했다. 검색 결과의 재인용 기사는 독립 근거로 세지 않았다. 확인한 공식 자료 범위에서 GA의 철회나 METR 수정 사항의 외부 재검증 결과는 확인하지 못했다. 모든 후속 발표를 포괄적으로 조사했다는 뜻은 아니다.

Uber는 한국어와 영문 원문을 대조해 한국어를 사용했다. Decisions의 `ko-KR` 주소는 영문으로 리디렉션돼 영문 원문을 사용했다. Anthropic·METR은 확인한 영문 공식 원문을 사용했다.

## 시각 자료와 미디어

- 반환 형식 비교, Skills/MCP 비교, Uber 도입 대상 막대, METR 평가 타임라인, 모임 실험 순서는 자체 작성한 HTML/CSS 설명 자료다. 실제 제품 UI나 성능 실험 자료가 아니다.
- Uber 그래프의 기준은 사람 수이며 시범 1,000명과 확대 제공 대상 3만 명 이상을 구분한다. 두 번째 막대는 점선·무늬로 계획 범위를 표시하고 길이는 3만 명 기준이다. 활성 사용이나 완료율로 읽히지 않게 캡션을 붙였다.
- 서로 다른 고객 자체 성능 평가와 분모가 다른 감시 비율을 같은 축의 그래프로 만들지 않았다.
- O1의 GPT-Live 표정 선택 데모를 원문으로 연결한다. 마이크 사용·음성 세션 실행·성능 측정은 하지 않았다.
- 공식 시각 자료를 추가해 달라는 요청에 따라 O2의 Choice → Team routing 애니메이션을 정지해 캡처했다. CSV 내보내기 실패 문의가 Technical support 1.00으로 표시되는 설명용 장면이다. 위젯 영역만 잘라 저장했으며 실제 API 호출 결과로 표기하지 않았다.
- O1의 실제 브라우저 화면에서 공식 소개 영상 `Introducing the Decisions API`를 확인했다. 길이 05:25의 원본 Vimeo 플레이어를 삽입하고, 기본 컨트롤·지연 로딩·16:9 비율·원문 대체 링크를 제공한다. 자동재생은 끈다.
