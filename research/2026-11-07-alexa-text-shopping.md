## 후속 상태·한국어 자료

- CrewAI 한국어 개념 문서는 실제 열었으나 `https://docs.crewai.com/v1.15.28/ko/concepts/agents`로 이동했고 이번 conversational API 설명을 찾지 못했다. 구버전의 시각적 빌더 화면을 새 세션 기능의 화면처럼 사용하지 않았다. 최신 릴리스·병합 PR을 근거로 사용했다.
- OpenHands PR에는 v1.37.0 출시 표시가 있다. 초기 템플릿 시연은 별도 extensions 카탈로그를 로컬 설치한 조건이다. 이 조건이 없는 `after-generated.png`를 채택했다. 코드 검토 댓글에 기록된 후속 extensions 버전 변경을 별도 성능·호환성 보장으로 인용하지 않았다.
- Clutch 공식 [News & Press](https://www.clutch.security/press)를 확인하고 Palo Alto 공식 도메인의 Clutch 후속 발표를 검색했으나 거래 완료를 확인하지 못했다. Palo Alto 투자자 보도자료 목록은 웹 도구로 열리지 않았다. ‘거래가 확실히 미완료’가 아닌 ‘확인한 공식 자료에서 완료 발표를 찾지 못함’으로 한정했다.
- Amazon 원문에는 전체 Alexa 이용 수치와 자동 구매 기능도 있으나, 이번 문자 채널의 이용 실적과 섞이지 않게 수치·성과 주장을 제외했다.
- ‘최근 24시간’은 자료의 서로 다른 발행 시각을 감안해 ‘11월 5~6일자’로 정리했다. 첨부의 출처 UI 잔재, 이스케이프된 굵게 표기, 자동화 지속 여부 질문은 기사에서 제거했다.

- [PR #9017](https://github.com/crewAIInc/crewAI/pull/9017)에서 단독 Agent 대화가 기존 Flow conversation runtime을 사용한다는 설명을 확인. 일반 Flow 도식을 이번 세션 기능의 실제 그래프나 실행 결과로 제시하지 않으며, 캡션에 ‘이번 1.15.36 대화 세션 기능의 시연 화면은 아닙니다’라고 명시.
- 공식 문서의 실제 페이지와 1.15.36 태그의 원본 PNG를 확인. 기존 자체 세션 조건 설명도는 유지하고, 공식 도식의 출처를 본문 캡션과 읽은 자료에 추가. 발행일·호수·제목·목록 편수는 변경하지 않음.
- 추가 후 `node --test` 71개 통과, `git diff --check` 통과. HTML 파서로 캡션·출처 링크·이미지 실제 크기·상대 경로·ID·기사 메타데이터를 확인. 데스크톱 1280 × 900과 모바일 390 × 844의 라이트·다크에서 로딩·원본 비율·캡션 표시와 원본 이미지 이동을 확인. 커밋·푸시·배포하지 않음.
