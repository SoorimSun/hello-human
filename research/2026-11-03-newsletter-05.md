## 구성과 사실의 범위

인사 → 추천 3편 → 분야별 전체 목록 → 기존 글 업데이트 → 작은 실험 → 맺음말 순서다. 추천은 Pinterest의 목적 추정, LobeHub·Paseo의 참여·재개, Agents in Games의 협업을 골랐다. ‘기록을 바탕으로 다음 일을 고르되 실제 결과를 확인한다’는 편집 주제로 연결한다.

이 뉴스레터는 사이트에 발행한 글의 안내서다. 모든 제품과 사건을 11월 3일 기준으로 전면 재조사한 최신 뉴스라고 표현하지 않는다. 원문의 확인 시점과 발표·예정·의혹·제작자 보고를 유지한다.

## 작은 실험

대화 상태와 저장소의 현재 결과가 다른 세 작업을 가상 자료로 제시한다. 저장된 보고서가 있으면 완료 확인, 정상 조회에서 0건이면 저장 필요, 조회 실패면 확인 보류로 나눈다. 모델에는 근거 번호와 다음 행동의 계획만 요청하며 실제 저장·발송은 하지 않게 한다.

T-19의 조회 실패를 정상 조회·보고서 존재로 바꾸는 두 번째 입력으로, 새 근거가 생겼을 때 해당 판단만 바뀌는지도 비교하도록 했다. 기대 답안은 주어진 자료를 바탕으로 작성한 것이며 실제 모델 실행 결과가 아니다. 실제 시스템의 중복 저장 방지를 검증했다는 의미도 아니다.

## 검증 기록

- 분야별 목록에서 추출한 최초 발행일·URL 11쌍과 뉴스레터 전체 목록이 정확히 일치한다. 누락·중복·기간 밖 글이 없다. 추천 3편과 업데이트 3편도 별도로 대조했다.
- 변경 HTML 3개의 중복 ID·ARIA 참조·검색 차단·테마·분석·갱신 스크립트·외부 링크 속성을 확인했다. 로컬 파일·앵커 참조 108개가 유효하며 신규 원고의 태그 짝도 맞는다.
- `node --test`: 기존 테스트 71개 통과. `git diff --check`: 공백 오류 없음. 신규 파일은 줄 끝 공백·마지막 개행을 별도로 검사했다.
- 원고 대조에서 AI 송도의 사례 번호를 06으로 맞췄고, Fusion의 실습 소개를 실제 화면이 제공하는 기록 재생 범위로 다듬었다.
- 로컬 HTTP의 `/hello-human/` 하위 경로에서 Edge 기반 Playwright로 1440·768·390·320px와 라이트·다크의 8개 조합을 확인했다. 문서·본문 요소의 가로 넘침이 없고, 추천 카드는 넓은 화면 3열·작은 화면 1열이다. 이미지의 실제 로드 크기는 1800×474다.
- 첫 화면 검사에서는 실행 환경의 외부 웹폰트 접근이 막혀 기본 글꼴로 표시됐다. 공개 CDN의 HTTP 200 응답을 확인한 뒤 외부 접근이 허용된 환경에서 수정 원고를 다시 검사했다. 웹폰트를 불러온 데스크톱 실습·모바일 도입부·320px 실습 화면을 직접 열어 줄바꿈과 여백을 확인했다.
- 홈·목록의 320px 두 테마에서 가로 넘침이 없다. 테마 선택 후 새로고침 유지, 홈 최신 카드 → 5호 → 목록 → 5호 → 첫 추천 글 이동을 확인했다. 목록은 05 LETTERS다.
- 실습 목차 이동 후 제목이 고정 메뉴 아래에 보인다. JavaScript를 끈 상태에서도 기사·업데이트 14개와 추천 3편·실습 입력이 남는다. 반응형 확인에서 JavaScript 실행 오류와 로컬 HTTP 400 이상 응답은 없었다.

## 전체 문장 검토·편집

- 도입부·추천 3편·분야별 기사 요약·업데이트·실습 해설·맺음말을 다시 읽고 반복되는 서술과 추상적인 표현을 줄였다. 고객의 목적, 작업 재개, 완료 확인이 각 글에서 어떻게 연결되는지 구체적으로 풀었다.
- 홈과 뉴스레터 목록의 소개 문구를 수정 본문과 맞췄다. 제목·날짜·편수·링크·미디어 출처와 사실의 확정 수준은 유지했다. 외부 자료를 추가로 조사하거나 가상 실습을 모델로 실행한 편집은 아니다.
- 편집 전 사본과 HTML 3개를 대조했다. 설명 메타데이터의 문구를 제외한 태그·속성, 날짜, 기사·업데이트 14개, 추천 3편이 그대로이며 실습 입력 그룹의 HTML도 동일하다.
- 문장 수정 후 `node --test` 71개가 통과했고 `git diff --check`에 공백 오류가 없었다. 신규 파일의 줄 끝 공백과 마지막 개행도 별도로 확인했다.
- 인앱 브라우저의 로컬 미리보기를 새로고침해 수정 문구를 확인했다. 기본 화면의 실습·맺음말과 390px 화면의 기사 요약·도입부를 직접 보며 줄바꿈을 확인한 뒤 화면 크기를 복원했다.
- 로컬 초안만 갱신했다. 커밋·푸시·배포·메일 발송은 하지 않았다.
