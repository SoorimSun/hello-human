# 행사 안내문 교차 검토 · 실제 실행 결과

2026년 10월 15일 한국시간 기준. `news/2026-10-15-trustworthy-ai-execution.html#experiment`의 요청을 그대로 사용했다.

## 결론

**초안 5/5 → 수정본 5/5. 고객에게 보여줄 안내문은 글자 단위로 동일했다.** 검토 후에는 수정하지 않은 이유를 설명하는 문단만 추가됐다. 이번 실행에서는 사실 오류·누락 수정이나 표현 개선이 발생하지 않았다.

검토 모델은 제목이 본문과 분리되어 노출될 경우 최소 구매 금액을 덧붙일 수 있다고 제안했다. 작성 모델은 현재 요청이 제목과 본문이 함께 있는 안내문이라고 판단해 반영하지 않았다. 무료배송이 미정이라는 문구도 원래 요청에서 필수가 아니므로 추가하지 않았다.

이 과제가 두 모델의 검토 전후 차이를 잘 보여줄 것이라는 기대는 이번 실행에서 확인되지 않았다. 처음부터 충분한 초안을 검토하고 유지하는 사례로 볼 수 있다. 한 번의 관찰로 검토가 일반적으로 불필요하다거나 특정 모델이 더 낫다고 결론 내리지는 않는다.

## 실행 방식

| 역할 | 도구에 지정한 모델 ID | 세션과 맥락 |
| --- | --- | --- |
| 초안 작성 | `gpt-6.1-sol` | Codex 별도 모델 세션 `/root/experiment_writer`. 이 기사의 기획 메모와 작성 요청만 전달했다. |
| 교차 검토 | `gpt-6-astra` | 새 모델 세션 `/root/experiment_reviewer`. 원본 메모·최초 작성 요청·실제 초안·검토 요청을 전달했다. |
| 수정 | `gpt-6.1-sol` | 초안을 만든 동일 세션에 검토 응답 전체와 수정 요청을 전달했다. |

- OpenAI 계열의 서로 다른 두 모델을 Codex 모델 세션으로 실행했다. ChatGPT 웹 앱이나 다른 공급사의 제품 UI로 실행한 결과는 아니다.
- 두 초기 세션은 대화 이력을 넘기지 않는 `fork_turns="none"`으로 생성했다. 원래 대화의 기대 결과나 평가 점수를 작성·검토 모델에 알려주지 않았다.
- 추론 설정은 별도 지정하지 않았다. 기사 요청문 외에 도구·파일·검색을 사용하지 말고 요청 결과만 반환하라는 실행 지시를 추가했다. 전체 입력을 아래 파일에 보존했다.
- 초안 1회, 검토 1회, 원래 모델의 수정 응답 1회다. 오류를 넣거나 초안을 재생성하거나 유리한 결과를 선별하지 않았다.
- 모델 세션의 최종 응답 원문만 저장했다. 내부 추론이나 요청별 시간·토큰 사용량은 수집하지 않았다.

## 원본과 대조한 판정

검토 모델의 의견을 그대로 점수로 쓰지 않고, 주 작업자가 기사에 미리 정한 다섯 항목과 원본 메모에 대조했다. 한 항목의 필요한 조건이 모두 정확해야 충족으로 셌다.

| 항목 | 초안 | 수정본 | 실제 안내문의 근거 |
| --- | --- | --- | --- |
| 기간과 대상 | 충족 | 충족 | 2026년 10월 20~22일, 앱 첫 구매 회원, 가입한 지 오래돼도 구매 이력이 없으면 대상임을 명시했다. |
| 최소 구매 금액 | 충족 | 충족 | 쿠폰 대상 상품 합계 5만 원 이상이며, 행사 상품 금액은 이 계산에서도 제외했다. |
| 할인과 예외 | 충족 | 충족 | 20%, 최대 1만 원을 안내하고 행사 상품에는 적용할 수 없다고 명시했다. |
| 중복 사용 | 충족 | 충족 | 다른 쿠폰은 중복 불가, 적립금은 함께 사용 가능으로 구분했다. |
| 미정인 혜택 | 충족 | 충족 | 무료배송을 약속하지 않았으며 메모에 없는 혜택·제한을 추가하지 않았다. 이 항목은 미정 제안을 생략해도 충족한다. |
| 합계 | **5/5** | **5/5** | **안내문 변경 없음** |

초안과 수정본 모두 제목 한 줄, 본문 세 문장, 주의사항 세 항목으로 작성 형식을 충족했다.

## 고객 질문 세 가지

1. 작년에 가입했지만 구매한 적 없는 회원: 앱에서 첫 구매하고 나머지 조건을 충족하면 대상이다. 초안에 직접 근거가 있다.
2. 일반 상품 3만 원과 행사 상품 3만 원: 일반 상품 전부가 대상이라고 해도 합계 기준에 포함되는 금액은 3만 원이라 미충족이다. 초안의 행사 상품 제외 설명으로 판단할 수 있다.
3. 무료배송 여부: 초안은 무료배송을 약속하지 않는다. 초안만으로 실제 배송비나 검토 중이라는 내부 상태까지 알 수는 없지만, 무료라고 결론 내릴 근거도 없다. 작성 요청은 미정 제안의 공개를 요구하지 않았으므로 누락으로 세지 않았다.
