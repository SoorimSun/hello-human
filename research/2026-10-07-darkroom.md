## 비교·해석

- NegPy 공식 README: https://github.com/marcinz606/NegPy (확인일의 내용). 변환, 롤 관리, 먼지 보정, 원본을 바꾸지 않는 편집이 기존 도구에도 있음을 확인했습니다. 설치·비교 성능 시험은 하지 않았습니다.
- LaMa 공식 저장소: https://github.com/advimman/lama . 모델의 역할을 인페인팅으로 설명합니다. 이 작업에서 모델 추론을 실행하지 않았습니다.
- 기존 도구 연결, 물리적인 스캔 병목, 유지보수 비용, 취미에서 남길 경험, 감상·작업 화면의 다른 사용성 기준을 편집 의견으로 정리했습니다. 이를 제품 성능의 실측 사실로 서술하지 않습니다.
- 상품 이미지 검수는 가상의 적용 제안입니다. 사내 구현이나 실제 데이터를 조회·공개하지 않았습니다. 승인 대상과 버전 기록, 기준 변경 시 재검토는 새 설계 제안이며 원 프로젝트의 구현으로 설명하지 않습니다.
- 사용자가 공개 인용에서 제외한 커뮤니티와 개인 대화의 URL은 본문·공개 조사 기록에 넣지 않았습니다.

### 먼지 검토 원본의 확대 설명

- `darkroom-dust.webp`를 먼지 제거 절에 전체 화면과 두 개의 부분 확대 형태로 배치했습니다. CSS로 표시 영역만 제한하며 원본 파일은 수정하지 않았습니다.
- 하늘의 표시 영역: 원본 2400×1500 기준 `x=1000, y=120, w=600, h=360`. 제작기 캡션대로 초록색 실선은 자동 보정, 노란색 점선은 검토 보류로 설명합니다.
- 왼쪽 DUST 패널: `x=18, y=1000, w=500, h=300`. 원본에 표시된 `75 spots filled`, `75 of 75 on`, `0 of 273 on`을 해당 사진의 보정 적용 75곳과 미적용 검토 후보 273곳으로 설명합니다. 일반적인 정확도나 처리 성능으로 해석하지 않습니다.
- 제작자가 공개한 얼어붙은 호수 장면입니다. 바닷물 반사광 약 2,000개 오검출의 수정 전후 이미지나 이번 작업에서 직접 실행한 결과가 아님을 캡션에 표시했습니다.

### 상품 이미지 검수 가상 예시

- 생성·반영일: 2026-10-07.
- 저장 파일: `assets/case-studies/darkroom-product-review.png` (1254×1254).
- 도구와 모드: 내장 `image_gen`, 새 이미지 생성, 불투명 배경. 생성된 PNG를 장면 수정 없이 복사했습니다.
- 가정한 상황: 이미지 문구는 500mL, 상품 등록 정보는 350mL이며 텀블러 표면에는 작은 회색 자국이 있습니다. 용량 문구·강조 영역·번호는 사진과 분리된 HTML/CSS입니다.
- 역할 구분: 파일 규격 확인과 추출 값의 대조는 코드, 문구·의심 영역의 인식은 모델, 사실 확인과 발행 결정은 사람에게 맡기는 설계 제안입니다.
- 이미지 검수 모델을 실행하거나 실제 상품·협력사 데이터를 사용하지 않았습니다. 가상 등록 정보와 검토 의견은 편집자가 정한 설명용 내용입니다. 35mm-studio의 실제 기능이나 결과와 구분해 본문에 표시했습니다.
- 표면 자국은 먼지 또는 흠집으로 확정하지 않습니다. 자동으로 지우지 않고 상세 사진과 실제 상태를 확인하도록 하는 예시입니다.

## 검증 범위

- 완료: 제작기·공개 설계·고정 커밋 코드 대조, 원본 이미지 확인.

- 사이트 검증 완료: `node --test` 7개 통과. `git diff --check` 통과.
- Edge/Playwright에서 1440px·390px·320px 각각 라이트·다크, 총 6개 화면 조합을 확인했습니다. 가로 넘침, 중복 ID, 잘못된 목차 앵커, 본문 이미지 로딩 실패, JavaScript 실행 오류가 없었습니다. 원본 이미지 크기는 2400×1500, 2400×2567, 800×531, 800×530입니다.

- 목록 → 본문 → 목차 이동 → 목록 복귀 → 새로고침에서 해당 글에 잘못된 `Updated`가 표시되지 않았습니다. 데스크톱·모바일 본문, 비교 이미지·분기 도식, 홈 카드의 스크린샷을 확인했습니다.
