# Agents in Games 사례연구 확인 기록

- 확인일·글 날짜: 2026-11-01 (한국시간)
- 결과물: `case-studies/2026-11-01-agents-in-games.html`, 사례연구 08
- 범위: 제공된 원고를 바탕으로 공식 보고·공개 문서를 대조하고 로컬 사이트에 반영. 게임 실행과 성능 독립 재현은 하지 않음.

## 공식 실험과 기록

- [YC Labs · Agents in Games](https://labs.ycombinator.com/projects/games/index.html), 페이지 표기 2026년 10월. 모델명·기간·승패·행동 수치는 제작진 보고로 표시한다. 모델 일반 성능 순위나 업무 생산성 측정으로 확대하지 않는다.
- [식량 운영 메모](https://labs.ycombinator.com/civ50/shared-machine/plans/food-operations.md)와 [배급 장부](https://labs.ycombinator.com/civ50/shared-machine/notes/food-queue.md): 배급 완료와 실제 수령·섭취를 구분한 근거. 원문의 공개 기록으로, 우리 업무 적용 예시는 별도로 표시한다.
- [Mindustry 6·7경기 비교](https://labs.ycombinator.com/projects/games/index.html#mindustry-zenith-strike): 특정 공격의 방어 성공을 경기 전체의 승리로 표현하지 않는다.
- [Mindustry 리플레이](https://replay.olamlabs.ai/): 독자가 직접 관찰할 공개 결과물 링크. 이번 글에서 전체 경기를 분석하거나 리플레이를 검증했다고 주장하지 않는다.

Minecraft의 호출 전 관찰 갱신, 도구를 통한 행동, 세션 지속, 이벤트 기반 실행과 중단, 팀 메시징·공유 머신은 문서에 근거한다. 모든 동작마다 자연어 추론이 필요하다거나 단순 턴제라고 쓰지 않는다. `local` 환경은 사용자 권한으로 명령을 실행하며 격리되지 않는다.

현재 기본 설정과 보고된 실험 조건을 구분한다. 문서상 Minecraft 기본 모델은 GPT-6.1 Terra, Mindustry 기본 작업은 Codex와 `openai/gpt-6-luna`이다. 공개 버전이 실험 당시 버전과 동일하다고 확인한 것은 아니다.

## 후속 실험 질문의 범위

하네스·도구의 제약, 반응 지연, 명부 순서의 영향은 후속 실험에서 확인할 질문으로 다룬다. 모델 대기·도구 실행·승인 대기를 분리해 측정하고 초기 조건을 하나씩 바꾸자는 제안은 검증된 인과관계나 성능 개선 결과로 표현하지 않는다.

## 편집·시각 자료

초안의 핵심 논지를 유지하고 기존 사례연구의 존댓말 문체로 정리했다. 제목의 ‘AI 50개’는 협업 주체를 명확히 하도록 ‘에이전트 50개’로 바꿨다. 승인 병목과 결과 검증을 구분하고, 상품 정보 변경 검토의 단일 에이전트·세 역할 비교는 가상 설계로 표시했다. 원고의 개인 대화 주소와 내부 인용 표시는 공개 파일에 넣지 않았다.

본문 전체의 번역투와 반복 표현을 다듬고, 관찰 내용에서 업무 제안으로 이어지는 문장을 정리했다. 추상적인 ‘작업 경계’는 문맥에 따라 ‘맡길 일과 권한’으로 풀어 썼다. 제목·실험 수치·모델명·공식 출처·확인 범위는 유지했으며 홈과 목록의 소개 문구도 맞췄다.

대표 이미지와 영상 포스터의 URL·확인일·용도는 `assets/case-studies/README.md`에 기록한다. 영상은 원본 URL로 연결하고 자동 재생하지 않는다. 공통 CSS·스크립트는 수정하지 않는다.

4절에 Minecraft 하네스의 아키텍처 설명도를 추가했다. 위에 고정한 커밋의 `architecture.md`와 `multi-agent.md`를 다시 읽고, 언어 모델 ↔ Pi 세션·도구 실행 ↔ 게임 서버·개인 실행 환경·팀 공유 환경의 연결을 요약했다. 에이전트별 Node.js 프로세스와 개인 기록, 팀의 DM 우편함·공유 머신을 구분한다. 공유 머신을 사용하는 팀 모드의 개념도이며 실험 당시 배포 구성의 재현이 아님을 캡션에 적었다. 그림 안의 글자는 HTML 텍스트로 제공하며 모바일에서는 연결된 환경을 세로로 배치한다.

## 로컬 확인

- `node --test`: 기존 71개 테스트 통과, 실패 0개.
- 본문·목록·홈의 로컬 파일 링크와 목차 대상, 중복 ID, 외부 링크 속성, noindex, 사례연구 8편 표기를 확인했다.
- Chrome에서 데스크톱과 390px 모바일, 라이트·다크 테마를 확인했다. 모바일의 전체 문서는 가로로 넘치지 않으며 표는 자체 영역에서 스크롤한다.
- 아키텍처 추가 후 데스크톱 라이트·다크 화면과 390px·320px 모바일을 확인했다. 도식 내부의 텍스트·카드가 가로로 넘치지 않고, 모바일 분기 연결선이 각 환경으로 이어진다. ID·접근성 참조·파일 경로 검사와 `git diff --check`를 통과했다.
- 홈 → 새 글 → 사례연구 목록 → 새 글 이동, 목차 이동, 대표 이미지·포스터 로딩을 확인했다. 영상은 HTTP 200 / video/mp4 응답과 브라우저의 12초 재생을 확인했다.
- 확인한 브라우저 탭에 오류·경고 로그가 없었다. 게임 자체의 실행·성능 검증과 사이트 화면 검증은 구분한다.
- 후속 게시 요청에 따라 본문·홈·목록·미디어·확인 기록을 함께 커밋·푸시 대상으로 확정했다.
