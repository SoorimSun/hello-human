# 조민하의 포자 대청소 작업물 페이지 편집 기록

소개 등록일과 확인일은 2026-10-16(한국시간)이다. 페이지는 `works/jo-minha.html`이며 홈의 회원 작업물 영역에서 연결한다. 회원 소개 요청이므로 사례연구 목록에는 중복 등록하지 않는다.

## 소개 방향과 현재 상태

사용자는 조민하의 작업물을 긍정적으로 소개하고 코드 리뷰 내용은 넣지 않도록 요청했다. 게임 경험, AI를 활용한 그림·소리·레벨 제작, iOS에서 Android로 이어진 개발을 중심으로 작성했다. 기존 코드 리뷰 문서와 지적 사항은 소개 페이지에 연결하지 않는다.

사용자가 2026-10-16 제공한 최신 상태를 반영했다. 아직 앱은 출시되지 않았고, iOS는 계정 준비 단계다. 기존 코드베이스를 Android Kotlin으로 전환해 출시 전 테스트를 진행 중이다. 스토어 등록 완료, 내부 테스트 트랙 공개, 다운로드 가능 상태로 확대해 쓰지 않는다.

회원의 이름과 작업물 연결은 사용자가 명시적으로 요청한 범위다. 연락처·내부 시스템·개인 대화 링크는 포함하지 않는다. 초기 요청은 로컬 페이지 작성이었으며, 문장 수정까지 커밋과 푸시를 수행하지 않았다. 이후 2026-10-16 사용자가 최종 결과의 커밋과 푸시를 명시적으로 요청했다.

## 시각 자료

사용자가 2026-10-16 후속 요청에서 소개용 이미지 사용을 명시적으로 허락했다. 이에 따라 제작자의 [소개 이미지](https://github.com/twobeansdaddy-hue/SporeSweep/blob/2a08f4ccded30ace820014b74952022587038378/Docs/images/overview.jpg)를 `assets/works/sporesweep-overview.jpg`로 저장하고 게임 설명 뒤에 참고 이미지로 배치했다. 사용자의 후속 의견에 따라 상단은 원래의 소개 문구와 3단계 도식 구성을 유지했다. [자체 LICENSE](https://github.com/twobeansdaddy-hue/SporeSweep/blob/2a08f4ccded30ace820014b74952022587038378/LICENSE)의 일반 재배포 제한과 별개로 이번 소개용 사용 허락에 한정한다.

원본은 1708×900 JPEG, 324,731바이트다. 원본 비율과 내용을 유지하며 크롭·보정·재인코딩하지 않았다. 랜드마크 복원, 퍼즐, 특수 블록, 세계 지도를 네 칸으로 묶은 홍보 이미지이며 랜드마크의 복원 전후를 합친 구성을 캡션과 alt에서 설명한다. 이미지와 ‘크게 보기’ 링크를 누르면 원본 크기의 로컬 이미지를 새 탭에서 볼 수 있다. [회원 작업물 이미지 기록](../assets/works/README.md)에 출처·확인일·사용 범위를 남겼다.

블록 맞추기 → 물질 수거 → 랜드마크 복원 도식은 처음 구성처럼 상단 소개 문구 옆에 배치했다. 좁은 화면에서는 소개 문구 아래로 이어진다. 실제 게임 스크린샷이나 플레이 가능한 데모로 표현하지 않는다.

## 사이트 반영과 확인

- 새 회원 페이지, 페이지 전용 CSS, 홈 소개 카드와 이 기록을 추가한다.
- 기존 사이트의 글꼴·테마·분석·콘텐츠 갱신 기능을 유지하고 공통 CSS는 수정하지 않는다.
- 앱 빌드·모바일 게임 실행·스토어 배포 검증은 이번 소개 페이지 작업에서 수행하지 않는다.
- 기존 사이트 테스트 `node --test` 7개가 모두 통과했다.
- 최초 페이지 검증에서 로컬 리소스·링크 13개, 고유 ID 8개, 내부 앵커 대상과 홈의 소개 링크 1개를 확인했다. 이미지 추가 이후 검증은 아래에 별도로 기록한다.
- 외부 링크의 새 탭·보안 속성, 검색 제외 메타 태그, 코드 리뷰 문구 배제와 미출시 상태 표기를 확인했다.
- 로컬 브라우저에서 기본 데스크톱 화면, CSS 뷰포트 320px·390px 화면과 라이트·다크 테마를 확인했다. 모바일 DOM의 가로 넘침이 없었고 본문·제목·도식의 줄바꿈을 확인했다.
- 홈의 회원 작업물 카드에서 소개 페이지로 이동하고, 본문의 출시 준비 상태 바로가기가 해당 영역으로 이동하는 것을 확인했다.
- 소개 페이지 브라우저 콘솔의 경고·오류 기록은 없었다. 검증 뒤 뷰포트 설정과 라이트 테마를 복원했다.
- `git diff --check`가 통과했으며 새 파일의 줄 끝 공백과 마지막 개행도 별도로 확인했다.
- 변경 범위는 `index.html`, `works/jo-minha.html`, `assets/work-sporesweep.css`, `assets/works/sporesweep-overview.jpg`, `assets/works/README.md`, 이 기록이다. 커밋·푸시·배포는 하지 않았다.

### 소개 이미지 추가 후 확인

- 사용자의 최종 배치 의견에 맞춰 상단은 기존의 소개 문구와 3단계 도식을 복원했다. 소개 이미지는 ‘어떤 게임인가요’ 설명 뒤, AI 제작 과정 앞에 한 번만 배치했다.
- HTML 태그 짝, 고유 ID 8개, 로컬 참조 16개, 이미지 alt·크기·확대 링크를 검사했다. 누락·중복·줄 끝 공백이 없다.
- 원본 이미지 1708×900의 로딩과 비율을 확인했고, ‘크게 보기’가 별도 탭에서 같은 원본 이미지를 여는 것을 확인했다.
- 데스크톱과 CSS 뷰포트 320px·390px에서 가로 넘침 없이 이미지와 캡션이 표시된다. 라이트·다크 화면 및 키보드로 이미지 출처·확대 링크에 접근하는 동작을 확인했다.
- 브라우저 콘솔 경고·오류가 없고, `git diff --check`도 통과했다. HTML/CSS와 이미지·출처만 수정했으므로 기존 JavaScript 테스트는 이번 배치 조정에서 재실행하지 않았다.
- 검증 뒤 임시 뷰포트 설정을 해제하고 라이트 테마와 페이지 상단으로 돌려놓았다. 커밋·푸시·배포는 하지 않았다.


### 멤버가 읽기 편하도록 문장 다듬기

- 게임의 경험 → 그림·소리·레벨 제작 → Android 전환과 출시 준비 순서가 자연스럽게 이어지도록 도입·본문·소제목·마무리와 홈 소개 문구를 다듬었다.
- 그림을 겹쳐 복원을 표현하고, 소리를 가공해 장면에 연결하며, 자동 플레이 기록으로 레벨을 다듬는 구체적인 과정을 살렸다. ‘도시 해금’은 ‘다음 도시 열기’로 풀어썼다.
- 기존 근거 안에서 문장만 수정했다. 수치·현재 출시 상태·링크·레이아웃은 유지했고, HTML 태그와 속성이 수정 전후 동일함을 확인했다.
- 390px·320px 모바일 화면에서 문장·제목 줄바꿈과 가로 넘침을 확인했다. `git diff --check`가 통과했다. 문구 수정이므로 JavaScript 테스트는 다시 실행하지 않았다.
- 상단 도식과 게임 설명 뒤의 이미지 배치는 유지했다. 커밋·푸시·배포는 하지 않았다.
### 커밋 전 최종 확인

- 2026-10-16 사용자 요청에 따라 최종 소개 페이지와 관련 파일 6개를 main에 커밋하고 origin/main에 푸시하는 범위로 진행한다.
- 커밋 직전 `node --test`를 다시 실행해 테스트 7개가 모두 통과했다.
- 원격을 가져온 뒤 main과 origin/main 사이에 선행·후행 커밋이 없음을 확인했다.
- 이전 코드 리뷰·사전 분석 문서는 이번 커밋에서 변경하지 않는다.
