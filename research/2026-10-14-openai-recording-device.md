# OpenAI 회의실 녹음 장치 사건 확인 기록

- 확인일 2026-10-14, 한국시간. 사건·발표 날짜는 미국 현지 기준.
- 대상 `news/2026-10-14-openai-recording-device.html`, BRIEF 09.
- 사용자가 지정한 채팅 「사실 검증 AI뉴스 단신」의 원고와 최초 요청을 읽고 반영했다. 채팅의 인용 표시는 근거로 재사용하지 않고 실제 원문을 열어 대조했다.
- 해커뉴스 토론은 논점 검토에만 참고했다. 기사와 이 기록에 링크나 댓글 인용을 넣지 않았다.
- 로컬 기사·목록·홈 반영 범위. 사용자 지시에 따라 푸시하지 않는다.

## 사이트 반영

- 기존 단신의 한 열 레이아웃, 두 항목 비교 카드와 공통 CSS·테마·분석·콘텐츠 갱신 기능을 재사용했다.
- 목록은 새 단신을 10월 14일 일반뉴스보다 먼저 한 번 추가해 총 25편(일반뉴스 16, 단신 9)으로 갱신했다.
- 홈의 최신 단신 카드에 제목·날짜·단신 09와 기사 URL을 맞췄다.

## 검증

- `node --test` 기존 테스트 7개 통과.
- 홈·목록·기사의 로컬 참조 101개, 외부 링크 속성, 중복 ID, 검색 차단 메타 태그 확인.
- 전체 25편(일반뉴스 16, 단신 9), 날짜 내림차순·같은 날 단신 우선 정렬, 신규 URL 1회 등록, BRIEF 09와 발행일 일치 확인.
- 브라우저에서 기사 → 목록 → 단신 탭(9편) → 기사 → 홈 → 새 단신 이동 확인. 홈의 일반뉴스 16 카드 유지 확인.
- 데스크톱·모바일 화면과 라이트·다크 모드, 모바일의 두 카드 세로 배치와 가로 넘침 없음 확인. 모바일 제목의 쉼표 뒤 공백을 보완하고 다시 확인.
- 브라우저 경고·오류 로그 없음. 기사에 해커뉴스 URL, 채팅 전용 인용 표기, 엠대시 없음 확인.
- `git diff --check` 통과. 커밋·푸시·배포는 수행하지 않음.

## 가독성 편집

- 멤버들이 쉽게 읽을 수 있도록 사건 경위 → AI가 등장한 두 맥락 → 아직 알 수 없는 부분 → 우리 업무에 적용할 생각의 흐름을 다듬었다.
- AI 비교 카드 앞에 연결 문장을 넣고, 반복되던 유죄 미확정 설명은 도입부로 모았다. 회사 설명·검찰 주장·미확인 사항의 구분은 유지했다.
- 계정 식별정보, 장치 식별정보, 모델 가중치, 구금 심리 등을 쉬운 말로 풀고 긴 문장을 나눴다. 기사 소개와 목록 요약의 ‘유출 범위’는 유출이 확인됐다는 인상을 피하도록 ‘정보 유출 여부를 어디까지 확인했는지’로 바꿨다.
- 기존에 확인한 사실·출처·제목·발행일·호수를 유지한 문장 편집이다. 이번 수정에서 추가 사실 조사나 최신화는 수행하지 않았다.
- 수정 후 기사 참조 28개, 외부 링크 속성, 발행 정보·중복 ID·목록 등록·금지 표기를 확인했다. 브라우저에서 전체 본문을 다시 읽고 데스크톱·모바일 줄바꿈과 카드 배치, 가로 넘침 없음, 경고·오류 로그 없음을 확인했다. `git diff --check` 통과. 실행 코드 변경이 없어 기존 동작 테스트는 다시 실행하지 않았다.
