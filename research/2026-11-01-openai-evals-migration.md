## 후속 확인과 제외 판단

- OpenAI 공식 도메인에서 이번 라운드의 최종 조달 확정 발표를 찾지 못했다. ‘없다’고 단정하지 않고 확인한 자료가 보도 단계임을 밝혔다.
- Reuters 재게시의 종전 기업가치 표기는 `$1.4 billion`으로 앞뒤 맥락 및 Investing.com의 1조4천억 달러와 충돌한다. 이번 기사는 모집 목표·약정에 집중하고 기업가치 숫자를 제외했다.
- [The Information 선행 보도](https://www.theinformation.com/articles/nvidia-talks-provide-billions-credit-support-cloud-providers-45-billion-anthropic-deal?rc=zj2rxx)는 공개 범위만 열렸다. [Bloomberg 확인 보도](https://www.bloomberg.com/news/articles/2026-10-29/nvidia-in-talks-to-offer-credit-support-for-nscale-project)는 조회 실패. 이를 직접 전면 확인했다고 쓰지 않았다.
- 초안에 있던 Nscale의 운영 칩 2.5만 개·계획50만 개, 환경 피해, 영국 Microsoft 프로젝트 철수, 최초 건물460MW 수치는 핵심에 필요하지 않아 제외했다. 회사 전체와 개별 시설, 가동과 계획을 섞는 그래프도 만들지 않았다.
- Nscale 공식 소개는 검색 캐시와 실제 페이지에 차이가 있었다. 실제 페이지 상단 설명 1.35GW와 Key Facts의1.38GW도 서로 달랐다. 200억/690억 달러 투자 계획 등 변동 수치를 기사에 새로 추가하지 않았다. 공시의 계약 조건과 설비 준비 범위만 사용했다.
- CAPEX·OPEX·CI·Eval의 사전식 정의, 임의 Java17·Spring Boot 지정, 추상적인 AI Native 결론 반복을 줄였다.
- ‘최근24시간에 새로 발표’ 대신 과거 공지의 일정 도래와 최근 보도를 구분했다.

## 실험 편집 판단

최근 실험과 대조했다.

- 10/27: 쿠폰 코드 변경을 독립 검토 에이전트로 확인.

이번 질문은 ‘모델을 바꾸기 전에 평가 도구의 채점 의미가 유지되는가’이다. 입력 소재는 초안의 복합 문의를 살리되 실제 모델 응답을 고정하고 채점 규칙을 비교하는 실험으로 바꿨다. JSON 배열의 순서·업무 누락·불허 필드·파손·보류를 구분한다. 조정용6건과 평가용18건은 모임의 제안값이며 실측이 아니다. 기존 판정이 없을 때는 사람의 기준과 비교할 수 있지만 과거 플랫폼과의 동등성을 입증하지 못한다.

입력→기존/신규 판정→차이 확인의 순서 도식과 기대 판정 표를 제공한다. 단순 순서여서 조작 UI나 실행 엔진은 추가하지 않는다. LLM 채점은 고정 규칙과 구분하며 같은 설정의 반복 판정을 확인한 뒤 실제 모델 교체로 넘어가도록 제안한다.

## 검증

- `node --test`: 기존 테스트 71개 통과, 실패·건너뜀 0개. 새 모델 평가를 실행한 결과가 아니다.
- `git diff --check`: 통과. 추가 파일의 줄 끝 공백·인코딩 대체 문자도 별도로 검사했다.
- 정적 구조 확인: 기사·홈·목록의 제목·34호·11월 1일 일치, 기사 등록 1회, 전체46편/일반34편/단신12편, 목차 대상·고유ID·상대 링크·자산 존재·외부 링크 속성·noindex 확인. 환산 금액 검산 통과.
- 실제 브라우저: 프로젝트 하위 경로 `/hello-human/`로 제공하는 loopback 미리보기에서 확인했다. 1280×720 데스크톱, 390×844·360×800 모바일 화면의 제목 줄바꿈과 가로 넘침을 확인했다. 라이트·다크 모드에서 일정·표·본문을 확인했다.
- 공식 이미지 로딩 확인: 원본4433×2035, 파일153,200바이트. HTML 크기 속성을 원본과 맞췄다. 모바일 로딩과 종횡비를 확인했다.
- 목록: 일반뉴스 필터34건, 단신 필터12건, 키보드 방향키 전환, 단신에서 새 일반뉴스 숨김, 중복 등록 없음 확인. 기사 읽기→목록→새로고침 뒤 해당 글에 잘못된 Updated 표시가 붙지 않았다. 홈의 일반뉴스 카드→기사 이동과 기존 단신 링크 유지 확인.
- 새 JS·실제 API 호출·평가 도구 설치는 없다. 실험은 제안으로 남겼다. 인쇄 미리보기와 JS를 끈 실제 브라우저는 별도 확인하지 않았으며, 기사 본문·표·도식·목록 수는 정적 HTML에 포함되어 있다.
- 남은 사실 확인: WSJ 원문, 확정 투자 유치 조건, NVIDIA 보증 최종 계약은 확인 범위 밖이다. 본문과 출처에서 이 한계를 표시했다.

## 11월1일 시각 자료 보완

- 사용자 후속 요청: 02·03 소식의 공식 이미지·시각화 자료 확인. 기존 호수·발행일·URL·홈·목록 편수는 유지했다.
- 02: OpenAI 공식 뉴스 목록과 공식 도메인 검색에서 이번 조달 보도에 대응하는 발표·시각 자료를 찾지 못했다. 기존 표를 종전300억→수정약200억 달러의 목표 비교 그래프로 바꾸고, 별도 보도된 약정약110억 달러는 축에서 분리한 상자로 표시했다. 공식 이미지가 아닌 보도 기반 자체 그래프임을 명시했다. 숫자·원화 환산 근거는 그대로다.
- 03: Nscale Monarch 페이지에 공식 조감도가 있음을 실제 브라우저로 확인했다. 원문 링크를 별도 카드로 제공한다. 미디어 키트와 사이트 이용약관도 열었으며, 조감도의 재배포 허가를 확인하지 못해 파일 복사는 하지 않았다. 출처·원본·이용 조건은 기존 미디어 기록을 보완했다.
- 관계도는 NVIDIA의 GPU 공급 계획과 보증 협상 보도를 실선·점선과 텍스트로 구분하고, Nscale→Anthropic 공급 계약에는 최대 지급액과 조건을 붙였다. Nscale 공식 페이지의 상충하는 용량·투자액은 추가하지 않았다.
- 추가 검증: 기존 테스트71개 재실행 통과. 브라우저에서1280픽셀 데스크톱·360픽셀 모바일의 그래프 비율·화살표·줄바꿈·넘침·라이트/다크 표시를 확인했다. 새 인터랙션·API 호출은 없다. 인쇄 미리보기는 별도 확인하지 않았다.
- 공식 조감도 본문 삽입 후속 요청은 원본 파일 확보 제한으로 완료하지 못했다. 현재 기사에는 조감도 원문 링크와 자체 관계도가 있으며, 조감도 이미지 파일은 포함하지 않는다. 이 상태를 알린 뒤 사용자의 푸시 요청을 받았다.
