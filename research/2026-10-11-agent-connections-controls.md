## 후속 확인과 접근 한계

- 공식 Beam 발표·회사 소개를 직접 열고, 가중치 공개 후속 자료와 NVIDIA 공식 발표를 검색했다. 이번 확인에서 가중치 배포 완료나 거래 확정 공식 발표는 확보하지 못했다. ‘그런 발표가 어디에도 없다’고 단정하지 않는다.
- Anthropic 보고서는 원문을 읽고 후속·한국어 자료를 검색했다. 동일 내용의 유효한 공식 한국어 원문은 확보하지 못했다.
- GitHub 공식 기록에 제시된 기능 범위로 한정했다. 플러그인 설치, 실제 MCP 연결과 권한 테스트는 수행하지 않았다.
- Reuters 원본, CNA·Investing.com·MarketScreener 재게재와 The Verge 링크는 웹 읽기 도구에서 열리지 않았다. CNA는 일반 브라우저에서 정상 열려 전체 본문을 확인했다. 제한을 우회한 것은 아니다.
- FT 원문 자체와 거래 관계자의 증언은 직접 확보하지 못했다. Reuters가 FT를 인용한 단계 그대로 표시했다.
- The Verge를 추가 근거로 사용하지 않았다. 내부 평가망 제한은 Anthropic 10월 9일 원문으로 직접 설명한다.
- 기존 12호의 관련 사건은 내부 링크로 연결했다. 12호의 날짜·호수·원고는 변경하지 않았다.

## 초안에서 바꾼 편집 판단

- 세 사건이 같은 기술·원인으로 이어진다는 단정을 줄이고 개발 환경, 평가 환경, 모델 운영 사업으로 나눴다.
- 제목의 ‘권한은 더 엄격해진다’를 ‘권한은 더 세심하게’로 바꿨다. MCP 자동 시작 제어가 권한 제한을 보장하거나 업계 전체 권한 정책이 엄격해졌다고 읽히지 않게 했다.
- IntelliJ·MCP·오픈웨이트를 쉽게 설명했다. Java/Spring의 특정 구현 예시는 짧은 가상 상품 프로젝트로 정리했다.
- Copilot 기본 설정/실행 권한 비교와 Beam 발표/협상 보도/공개 예정 타임라인을 추가했다. 실측 수치가 없어 성능 그래프는 만들지 않았다.
- 실험은 개발자 중심이되 다른 멤버도 요청 작성·검토로 참여할 수 있도록 했다. 실제 운영 계정 대신 가상 환경에서 권한 거절을 검증한다.
- 현재 README와 `docs/publishing.md`는 개별 글마다 README를 늘리지 않도록 명시한다. 스킬의 예전 파일 목록 지침 대신 현재 저장소 규칙을 따라 README는 수정하지 않았다.
