# Shopify의 생성형 상품 탐색

공식 자료 확인일은 2026년 11월 28일이다. [커머스 인사이트 09](../insights/2026-11-28-shopify-generative-discovery.html)는 고객이 명시한 조건을 지키면서 기존 검색이 놓친 상품을 어떻게 찾고 검증할지 다룬다.

## 모델과 학습

- 11월 11일 Shopify Engineering이 검색과 추천을 함께 학습하는 SID-LLM을 소개했다. 실제 상품 정보에서 만든 벡터를 세 개의 코드로 줄인다. 코드의 자리는 고정된 상품 속성에 대응하지 않으며, 전체 코드가 같아도 여러 상품이 연결될 수 있다. 실제 요청에서는 노출 자격을 갖춘 상품으로 코드를 해석한다. [Shopify Engineering 발표](https://shopify.engineering/generative-discovery)
- 11월 5일 최초 제출, 11월 15일 개정한 기술보고서(v2)의 1.1절·6.2절·10절을 운영 범위의 근거로 삼았다. 개인화 검색에는 검색어와 프로필, 추천에는 시간순 행동 기록이 들어간다. 공통 사전학습 뒤 운영 검색에는 다중 토큰 예측과 경량 순위 결정기를, 운영 추천에는 자기회귀 모델과 결합확률에 따른 상품 선택을 쓴다. 양쪽의 학습 결과를 한 모델로 옮기는 증류는 별도 실험이다. [버전 이력](https://arxiv.org/abs/2611.08804) · [개정 기술보고서](https://arxiv.org/html/2611.08804v2)
- 추천 학습 자료를 뺀 비교에서는 학습 토큰을 남은 자료에 비례해 재배분했다. 구매가 일어난 검색 세션의 purchase Recall@10은 전체 자료 33.4%, 추천 자료 제외 32.6%였다. 첫 구매를 강조하는 학습과 발견 평가의 정의는 5.1.3절에 있다. 발견 평가는 이전에 상호작용하지 않은 상품의 후속 구매를 대상으로 한다. [학습 자료 비교](https://shopify.engineering/generative-discovery) · [기술보고서 5.1.3절](https://arxiv.org/html/2611.08804v2#S5.SS1.SSS3)

## 판매 정보와 제품 제안

- 판매자용 한국어 안내에서 상품 정보의 완전성·최신성과 채널별 노출 조건을 확인했다. 검색 결과나 특정 AI 답변의 순위는 각 채널이 정한다. [Shopify Catalog 한국어 안내](https://help.shopify.com/ko/manual/shopify-catalog)
- 에이전트용 문서에서 상품 탐색(`search_catalog`), 알고 있는 식별자로 최신 정보 조회(`lookup_catalog`), 단일 상품의 옵션 조합·판매 가능 여부 조회(`get_product`)를 확인했다. 이 도구들의 호출 절차는 개발 문서상의 사용 예이며 SID-LLM 내부의 처리 경로로 제시하지 않는다. [Shopify 개발 문서](https://shopify.dev/docs/agents/catalog)
- 프라이팬·수납장·선물 사례, 사양 충돌 검사, 현재 판매 조건 확인, 품번 보호, 기존 결과로의 복귀는 헬로우 휴먼의 적용 제안이다. 실험을 제안한 상품군에서 구매나 응답 시간을 실측한 결과는 없다.

## 그림과 도식

- **대표 이미지**. 2026년 11월 28일 ImageGen으로 제작했다. 글 첫머리의 두 주방을 위에서 본 정물로 표현했다. 같은 JPEG(1734 × 907)를 본문 상단과 공유 썸네일에 사용한다. [이미지 파일](../assets/insights/shopify-generative-discovery/frying-pan-search.jpg)

  가로 1.91:1 한국 커머스 매거진의 표지용 에디토리얼 정물 사진. 하나의 ‘프라이팬’ 검색에서 떠올릴 수 있는 두 주방을 위에서 내려다본다. 왼편의 따뜻한 아이보리 타일 위에는 1인용 작은 검은 프라이팬에 달걀프라이 하나, 오른편의 결 고운 스테인리스 조리대 위에는 훨씬 큰 업소용 은색 프라이팬에 윤기 나는 구운 채소 여럿. 두 팬은 같은 축척이고 원형 테두리와 손잡이가 한눈에 읽힌다. 두 조리대의 경계가 한 장의 자연스러운 그래픽 구도를 만든다. 부드러운 옆빛, 섬세한 재질, 절제된 소품, 실제 음식 잡지의 아트디렉션. 작은 모바일 썸네일에서도 두 원형 실루엣이 선명하게 구별되도록 중심부에 배치. 글자, 로고, UI, 테두리, 워터마크 없음.

  </details>

- **조끼의 의미 ID**. Shopify Engineering이 11월 11일 발표한 그림 3을 골랐다. 그림의 실제 라벨을 따라 두 번째 단계는 Jack & Jones와 작업복 스타일, 세 번째 단계는 회색 패딩과 인디고 데님으로 옮겼다. 본문은 Shopify CDN의 공식 그림을 원본 비율(2000 × 1550)로 참조한다. 번역·자르기 없이 한국어 대체 텍스트와 캡션을 붙였다. 재배포 라이선스는 확인되지 않아 파일은 복제하지 않았다. [그림 원본](https://cdn.shopify.com/s/files/1/0779/4361/files/figure-03-semantic-id-example.png?v=1793810179) · [발표와 그림 설명](https://shopify.engineering/generative-discovery)
- **프라이팬 후보 비교**. 첨부 초안의 흐름을 바탕으로 만든 HTML 도식이다. 같은 요청에서 기존·추가 후보를 얻고 중복을 제거한 뒤 옵션 검증과 순위 결정을 거치는 자체 실험 제안이다. Shopify의 운영 화면과 구별되도록 표시했다.
- **검색·추천 운영 구성도**. 기술보고서 v2의 그림 1·5와 7~8절을 대조해 공통 사전학습, 검색·추천의 코드 예측 방식, 기존 후보 합류를 한국어 벡터 도식으로 그렸다. 등산화의 예시 코드 12·47·8은 그림 1에서, 매일 갱신한 상품 색인으로 검색 후보를 제한하는 과정은 그림 5와 8.3절에서 가져왔다. 검색은 MTP 후보 250개를 100개 SID로 좁히고 SID당 노출 가능한 상품 하나를 선택한다. 추천은 AR로 생성한 SID의 확률과 군집 안 상품의 상대 인기도를 결합해 200개 상품을 고른다. 각각 다른 후보 생성기와 합쳐 후속 순위를 정한다. 두 숫자는 생성형 경로에서 넘기는 후보 규모이며 고객에게 보이는 상품 수와 구별한다. 검색에서는 생성형 경로 상위 50개 상품과 각 후보 간 유사도의 최댓값·평균·최솟값을 후속 순위 모델의 입력으로도 쓴다. 통합 모델 증류는 실험 단계다. [운영 구성 7절](https://arxiv.org/html/2611.08804v2#S7) · [검색 추론 8절](https://arxiv.org/html/2611.08804v2#S8) · [학습 개요 그림 1, PDF 2쪽](https://arxiv.org/pdf/2611.08804v2#page=2) · [검색 서빙과 일별 색인 갱신 그림 5, PDF 18쪽](https://arxiv.org/pdf/2611.08804v2#page=18)
- Catalog 개발 문서는 검색·조회 요청 예시로 도구별 역할을 설명한다. 이 사례는 코드 이름과 사용 시점을 본문에 담았다. 판매자 안내는 상품 정보 관리의 근거로 사용했다.

로컬 Edge에서 원본 그림의 로딩과 표시 비율을 확인했다. 1440px·320px 라이트 모드와 390px 다크 모드에서 목차 이동, 표와 실험 도식의 배치, 가로 넘침을 점검했다. 홈에서 목록을 거쳐 글을 연 뒤 목록으로 돌아와 새로고침해도 읽은 글에 갱신 표시가 다시 붙지 않았다.
