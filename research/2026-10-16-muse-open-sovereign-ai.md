## 초안에서 조정한 부분과 확인 한계

- ‘최근 24시간’은 발표 시각을 모두 확인하지 않아 사용하지 않았다. 발표일과 확인일을 명시했다.
- ‘외부 API에서 벗어나는 공통 흐름’은 세 발표의 차이를 뭉뚱그려 제외했다. Meta 공식 문서에는 외부 제공사 API 경로도 있다.
- Muse Wonder와의 비교는 이번 기사에 필요하지 않아 줄였다. 기사 본문과 메타데이터는 Muse Spark Open에 집중했다.
- Meta 연구 블로그는 검색 결과에 노출됐지만 직접 열기는 실패했다. 확인한 개발자 발표와 모델 카드를 근거로 사용했다.
- Apple 자체 발표의 유효한 원문은 확보하지 못했다. Apple 협력·Mac 구성은 Meta의 공식 설명 범위로 썼다.
- Meta 개발자 발표는 다른 업체의 더 강한 압축 배포본도 다룬다. 그 안의 256GB·약 300GB 설명은 서로 달라 기사에서 정량 인용하지 않았다. 공식 두 형식의 메모리 조건만 명시했다.
- Cohere 검색 결과 제목은 의향서, 열린 페이지 제목은 인수 예정으로 나타났다. 본문에 제안된 거래라는 표현이 있어 ‘인수 추진’으로 통일했다. [AISLE 측 발표](https://aisle.com/blog/aisle-and-cohere-to-join-forces)도 열어 교차 확인했으나 읽기 도구에서 본문 추출이 제한돼 세부 근거로 사용하지 않았다. 10월 16일 후속 완료·정정 여부도 검색했지만 확인된 완료 발표는 확보하지 못했다.
- CERN 관련 Reuters의 ‘Flare’ 이름은 확인한 공식 발표에 없어 제외했다. 출시일·성능은 해당 발표에 제시되지 않았다. 후속 검색에서도 이를 바꿀 공식 자료는 확보하지 못했다.
- 공식 한국어 원문을 확보하지 못해 영문 근거를 연결했다. 검색 요약이나 재인용 기사를 사실 확정 근거로 쓰지 않았다.
- 보안 분석·모임 관점·추천 도구의 요청 예시는 편집부 해석 및 미실행 제안이다. AISLE의 내부 설계나 제품 기능을 재현했다고 하지 않는다.
- CERN 절의 상품 분류·검색 비유는 물리학 연구와 직접 연결되지 않아 삭제했다. 해당 절은 연구 목표와 앞으로 검증할 과제로 마무리한다.
- 추상적인 실험 절을 보안 플러그인·스킬 추천으로 교체했다. 사용 환경과 목적별로 세 도구를 소개하며 성능 순위로 제시하지 않는다. 설치·설정 후 쓸 요청 예시와 공식 안내를 연결했다. 직접 설치·스캔·비교 시험은 수행하지 않았다. 기존 앵커 `#experiment`는 유지하고 목차 문구를 변경했다.
- 후속 요청에 따라 각 추천 항목에 ‘간단 설치’ 펼침을 추가했다. Codex Security는 OpenAI 설치 페이지의 앱 추가·Try in chat·폴더 선택 순서, Semgrep은 공식 문서의 Claude Code·Cursor 메뉴와 `/setup-semgrep-plugin`, Trail of Bits는 공식 README의 마켓플레이스 추가·플러그인 설치 절차를 요약했다. Claude Code 대화창과 Codex CLI 터미널 입력을 구분했다. 설치 명령은 안내용이며 실행하지 않았다.
- 설치 명령 5곳에 복사 버튼을 추가했다. Codex 명령 두 줄은 줄바꿈을 유지해 함께 복사한다. 버튼은 기사 전용 JS로 생성하며, 복사 성공을 표시하고 실패 시 명령어 선택과 직접 복사 안내를 제공한다. 설치 명령을 실행하는 기능은 없다.
- 버튼 크기 피드백을 반영해 28×28px 아이콘 버튼으로 줄였다. 복사 후에는 같은 크기의 체크 아이콘으로 표시하고, 접근성 이름과 상태 안내는 유지한다.
- 요청 예시 3개에도 같은 28×28px 복사 버튼을 추가했다. ‘요청 예시’ 라벨과 장식용 따옴표를 제외한 문장만 복사하며, 명령어와 동일한 성공·실패 안내를 공유한다.
- 전체 문장을 모임 독자 기준으로 편집했다. Meta는 Mac 실행 조건을 먼저 설명한 뒤 모델 구조를 풀고, Cohere는 취약점의 의미와 발견·검증·수정을 구분했다. CERN은 연구 목적과 활용 작업을 나눠 설명했다. 모임 관점의 상품 분류 비유를 빼고 각 소식에서 확인할 질문을 정리해 보안 도구 추천으로 이어지게 했다. 수치·진행 단계·출처·설치 명령은 유지하고, 요청 예시 2개와 홈·목록 소개 문구를 쉽게 다듬었다. 이번 수정은 기존에 확보한 근거에 대한 편집이며 새로운 발표를 조사한 것은 아니다.

- 모델 사양·진행 단계·데이터 범위는 텍스트로 읽을 수 있는 HTML 도식을 사용했다. 후속 요청에 따라 세 소식의 공식 발표 이미지도 각 본문 도입부에 추가했다. [미디어 출처 기록](../assets/news/muse-open-sovereign-ai-media.md)에 원본·제공자·확인일·이용 조건·파일 크기를 남겼다.
- 파라미터 막대의 기준은 Meta 제품 문서. 보안 흐름은 헬로우 휴먼의 설명. 물리학 데이터 카드는 CERN 발표 요약.
- 기사 전용 CSS만 추가하고 공통 자산 버전은 유지했다. 홈 일반뉴스와 뉴스 단일 목록을 갱신한다.
- 저장소의 최신 `README.md`·`docs/publishing.md`에 따라 개별 기사 목록을 README에 중복 기록하지 않는다.
- 초안 작성과 검수 단계에서는 커밋·푸시·배포를 수행하지 않았다. 검수 완료 후 사용자가 기사와 관련 변경사항의 커밋·푸시를 요청했다.
