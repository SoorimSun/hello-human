## 원문 접근과 편집 판단

- 10월 27일 문체 수정: 사용자 지정 Entire 절의 제목·본문·도식·캡션을 자연스러운 문장으로 다듬었다. 추상적인 표현 대신 개발자가 코드를 고치고 결과를 확인하는 순서로 설명했다. 확인한 기능·수치·제공 범위와 출처는 유지했다.
- 이어서 나머지 네 가지 소식, 30초 요약, 모임 관점과 실험 제안의 문체도 같은 톤으로 다듬었다. 고객이 상품을 고르고 개발자가 코드를 검토·조사하는 구체적인 행동을 앞세웠다. 수치·비교 대상·공시 시점·실험 조건과 사실 확인 범위는 유지했으며 새로운 외부 주장을 추가하지 않았다.
- 본문 전체의 부연 설명을 정리했다. 문맥상 분명한 부정형 설명, 캡션과 본문의 중복 단서, 기사 주제와 거리가 있는 공모 세부 조건을 덜어냈다. 상품 수·자료 정리 시간 등 지표의 대상, 공급사 발표라는 출처, 과거 사고의 공시라는 시점, 별도 학습 지연 결정, 미실행 가상 실험이라는 표시는 유지했다. 참여도 계산 방식·실험 기간·매출 효과의 미공개 범위는 Fanatics 본문 한곳에 모았다. 세부 검증 한계는 이 조사 기록에 보존했다.
- SEC 문서는 웹 본문 추출 도구에서 오류가 났지만 브라우저에서 직접 열었다. 페이지가 모두 표시된 뒤 본문의 공백을 정규화해 `misconfiguration`, `34 hours`, `more than a month`가 포함된 문단을 확인했다. 검색 요약만으로 확정하지 않았다.
- 초안의 Reuters URL은 열리지 않았다. 사고 단락은 Reuters 재인용 대신 SEC 원문에 연결했다. 초안의 일부 평가·강화학습 환경 중단 설명은 이번에 확인한 해당 공시 문단에서 직접 뒷받침하지 못해 제외했다.
- Fanatics는 실제 한국어 본문과 수치를 열어 영문과 대조했다. CodeRabbit 한국어 URL은 영문으로 이동했고 Ultrafast 한국어 URL은 조회 실패하여 확인한 영문을 사용했다.
- 현재 공식 제품 설명과 저장소를 함께 확인했다. Entire Trails, OpenAI Fanatics, Anthropic S-1에 대해 10월 27일 공식 도메인 후속 게시물도 검색했으나 해당 조건의 결과는 없었다. 이는 후속 수정이 전혀 없다는 증거가 아니며, 모든 게시물·미공개 이용 조건까지 포괄적으로 확인한 것은 아니다.
- 제목의 ‘병목 이동’은 업계 전체의 계량적 사실로 확정하지 않았다. 가장 구체적인 사건인 Entire의 검토 방식을 제목에 두고, 생성 이후의 검증·운영이라는 공통점은 OUR VIEW의 해석으로 남겼다.
- 일반 업무 추천 모델과 Codex의 개발 지원 역할을 분리했다. 가이드 링크는 개발 흐름을 설명하는 OUR VIEW에 배치했다.
- Git·PR·CI·MVP의 반복 사전식 정의를 줄이고, 기능 → 예시 → 의미 → 한계로 연결했다. 71%·89배의 조건은 펼쳐보기로 정리했다.
- 비용 성과를 새로 산출하지 않았다. 쿠폰 실험의 금액은 가상 업무 규칙이며 API 가격이 아니다. 실제 모델 평가나 측정을 수행했다고 쓰지 않았다.

## 실험 제안의 설계

- 합성 쿠폰 정책. 의류 소계 기준 5만 원, 할인 10%, 최대 1만 원, 원 미만 버림. 예시 네 건의 기대값을 계산해 확인했다.
- 연습 2건과 평가 10건 분리, 정상 5건·오류 포함 5건. 오류 정답을 검토 에이전트에게 공개하지 않는다.
- 자동 테스트+사람 대 자동 테스트+별도 AI 검토+사람. 검토 순서 교차 또는 동등한 다른 변경을 사용해 학습 효과 통제.
- 같은 커밋 ID, 고정 규칙·테스트·프롬프트, 독립 문맥 3회. 반복 횟수를 오류 표본 수로 부풀리지 않음.
- 실패·시간 초과는 보류, 수정 뒤 이전 판정 무효화. 검토 에이전트는 읽기 전용. 운영 연결 없음.
- 알려진 금액 오류를 승인 단계에서 막고 사람의 총 검토 시간이 줄 때 다음 시험으로 진행한다는 가상 기준. 실제 채택 성과·운영 안전성의 증거 아님.

## 로컬 반영

- 일반뉴스 29 / 단신 10 / 전체 39. 목록에 한 번 추가하고 홈의 최신 일반뉴스만 교체했다.
- 공통 CSS·JS는 수정하지 않고 기사 전용 CSS를 추가했다.
- `node --test`: 71개 통과, 실패 0개. 기존 테스트이며 기사 사실 검증의 대체가 아니다.
- `git diff --check` 통과. 신규 파일도 별도로 줄 끝 공백을 검사했다.
- HTML 검사: 중복 ID 없음, 모든 목차 대상 존재, 내부 링크·이미지 경로 존재, 외부 링크의 새 탭·보안 속성, noindex, 메타 제목·호수·날짜 일치. 목록 날짜 정렬과 정적 편수 대조 통과.
- 브라우저: 프로젝트 하위 경로 `/hello-human/`에서 확인. 1440px 데스크톱·390px·320px 모바일에서 가로 넘침 없음. 라이트·다크 모드, 제목 줄바꿈, 도식·표 배치 확인. 공식 이미지 2개의 실제 로딩·원본 크기를 확인했다.
- 목차 이동, 키보드 Enter로 수치 설명 펼치기, 실험 비교 설명 클릭 펼치기 확인. 일반뉴스 29·단신 10·전체 39 필터와 키보드 방향키 전환, 목록 중복 없음 확인.
