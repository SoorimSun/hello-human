편집 확인일과 발행일은 2026년 10월 20일이다. 제목은 ‘게임을 만들고, 쇼핑 AI를 시험하고’이며, 웹 원고는 [뉴스레터 3호](../newsletters/2026-10-20-making-and-testing.html)에 있다. 처음에는 사용자의 요청에 따라 푸시 없이 로컬 원고와 목록·홈 반영까지 진행했다. 문장 검토를 마친 뒤 사용자가 3호 변경사항의 커밋과 푸시를 명시적으로 요청했다. 이메일 발송은 포함하지 않는다.

## 수록 기간과 집계

`docs/publishing.md`에 따라 한국시간 2026-10-13 00:00 이상, 2026-10-20 00:00 미만에 최초 발행한 콘텐츠를 모았다. 각 분야의 목록과 원문을 대조했고, 회원 작업물은 홈의 등록 여부와 소개일, 추가 커밋을 함께 확인했다. 파일 수정 시간이나 조사 노트의 날짜를 발행일로 쓰지 않았다.

## 추천과 요약의 확인 범위

이번 호는 기존 기사와 작업물의 안내서다. 각 원문이 확인한 발표·보도·계획 상태를 유지하며, 모든 소식을 10월 20일 기준으로 다시 조사했다고 쓰지 않는다. 날짜는 최초 발행일·수정일이며 사건 발생일이나 제품 출시일이 아니다.

추천 문장의 범위를 확인하기 위해 10월 20일 다음 공식 원문을 직접 열었다. 본문에도 해당 가이드·사례 가까이에 링크했다.

- [Anthropic의 코드리뷰 운영 사례](https://claude.dev/blog/solving-code-review-at-anthropic/): 검토·병합·배포 이후 확인까지 이어지는 운영 맥락을 확인했다. 팀 적용안은 로컬 가이드의 제안으로 유지한다.
- [Shopify의 ShopGym 제작기](https://shopify.engineering/shopgym): 시험용 쇼핑몰과 그 상품·기능에 맞는 과제를 만들며, 일정한 조건에서 반복 평가한다는 설명을 확인했다. 10월 1일 공개된 제작기와 10월 19일 발행한 사례연구 날짜를 구분한다.
- SporeSweep의 고정 커밋 README는 웹 열람 도구에서 가져오지 못했다. 따라서 새로 검증했다는 표현 없이, 기존 작업물 본문·편집 기록·이미지 출처 기록의 확인 범위를 따른다.

## 구성과 이미지

기존 뉴스레터의 인사 → 추천 3편 → 분야별 전체 목록 → 작은 실험 → 맺음말 구성을 따른다. 이번에는 회원 작업물을 첫 분야로 배치하고, 가이드와 사례연구를 이어 읽도록 했다. 신규 커머스 인사이트가 없다는 것도 명시했다.

포자 대청소는 기존 `assets/works/sporesweep-overview.jpg`를 재사용한다. 1708×900 이미지를 직접 열어 네 화면과 복원 전후 합성 구성을 확인했다. 자르거나 수정하지 않았으며, 원본 비율·대체 텍스트·확대 링크와 제작자·출처·기존 확인일을 남겼다. [이미지 출처 기록](../assets/works/README.md)의 소개용 사용 범위를 따른다. 10월 20일 새로 캡처한 화면이라고 표시하지 않는다.

공통 `newsletter.css`와 `news.css`의 기존 반응형 스타일을 사용한다. 공통 CSS·JavaScript와 1·2호 본문은 수정하지 않는다. 뉴스레터 목록 맨 위와 홈의 최신 호 카드에 같은 제목·발행일·수록 기간·편수를 반영했다.

## 문장 다듬기

사용자의 전체 문장 검토 요청에 따라 도입부부터 추천 카드, 기사 소개, 실험 안내와 맺음말까지 다듬었다. ‘소개합니다·살펴봅니다’가 반복되는 부분을 줄이고, 제작기에서 검토·실험으로 이어지는 흐름을 정리했다. ‘Android로 이어간’, ‘검사 결과로 고치는 과정’처럼 대상이나 행동이 모호한 표현은 구체적으로 풀었다. ReplaySSM을 ‘덜 계산하기’로 요약했던 제목은 원문의 범위에 맞게 ‘실행 효율’로 고쳤다. 장바구니 실험은 바꿀 데이터와 비교할 답변을 명확히 했다.

이름 표기는 사용자의 최종 의견에 따라 회원 작업물 소개 문장의 ‘조민하 회원’ 한 곳만 유지한다. 추천 카드는 ‘회원의 제작기’, 글 목록은 ‘회원 작업물’, 이미지 출처는 ‘제작자의 게임 소개 이미지’로 적었다. 홈과 뉴스레터 목록의 소개 문장도 함께 다듬었다.

사실관계와 확인 범위, 날짜·편수·URL·HTML 구조를 유지했다. 문장 수정 전후의 태그·속성을 대조해 링크와 날짜가 바뀌지 않았음을 확인했다. 새로운 조사나 성능 실험을 수행한 것으로 표현하지 않는다.

## 검증 기록

- 분야별 목록에서 최초 발행일로 추출한 URL 집합과 뉴스레터의 분야별 기사 목록을 비교했다. 10편의 URL·날짜가 일치하며 누락·중복이 없다. 신규 회원 작업물 1편과 별도 업데이트 2편, 추천 3편의 포함 관계도 확인했다.
- 변경한 HTML 3개의 태그 구조·중복 ID·ARIA 참조·noindex·테마·분석·갱신 스크립트·외부 링크 속성을 검사했다. 로컬 파일과 앵커 참조 105개가 모두 유효하다. 원문 목록은 JavaScript 없이 HTML에 들어 있다.
- 기존 `node --test` 7개가 통과했고 `git diff --check`도 통과했다. 신규 HTML의 줄 끝 공백·마지막 개행·엠대시도 별도 검사했다.
- 프로젝트 하위 경로를 포함한 로컬 HTTP 미리보기에서 본문·목록·홈을 열었다. 데스크톱의 3열 추천 카드, CSS 폭 390px·320px의 1열 배치와 제목, 라이트·다크 테마를 확인했다. 본문 요소의 가로 넘침이 없고 게임 이미지가 1708×900으로 정상 로드됐다.
- 홈의 최신 호 카드 → 3호 → 뉴스레터 목록 → 3호의 이동을 확인했다. 목록은 03 LETTERS이며 최신 호의 제목·날짜·편수가 본문 및 홈과 같다. 브라우저 콘솔의 경고·오류는 없었다. 확인 후 임시 뷰포트를 해제하고 라이트 테마로 복원했다.
