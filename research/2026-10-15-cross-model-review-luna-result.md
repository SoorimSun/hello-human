# 경량 작성 모델의 행사 안내문 교차 검토 · 실제 실행 결과

2026년 10월 15일 한국시간 기준. [첫 실행](2026-10-15-cross-model-review-result.md)과 같은 행사 메모·작성 요청·검토 요청·수정 요청을 사용하고, 작성 모델을 GPT-6.1 Sol에서 GPT-6 Luna로 바꿨다. 검토 모델은 GPT-6 Astra로 유지하되 새 세션에서 검토했다.

## 결론

**조건 충족 점수는 5/5 → 5/5로 같았고, 쿠폰 지급과 할인 적용을 혼동할 수 있는 표현 한 곳이 명확해졌다.** 첫 실행과 달리 실제 안내문이 바뀌었다. 숫자나 정책을 잘못 썼다가 바로잡은 결과는 아니다.

| 초안의 표현 | 검토 후 표현 |
| --- | --- |
| 쿠폰 적용 대상 상품 합계 5만 원 이상 구매 시 20% 할인 쿠폰을 드려요. | 쿠폰 적용 대상 상품 합계가 5만 원 이상이면 쿠폰으로 20% 할인받을 수 있어요. |

검토 모델은 초안이 ‘구매하면 나중에 쿠폰을 받는다’는 뜻으로 읽힐 수 있다고 지적했다. 원본 메모에는 구매 후 지급이라는 절차가 없으며, 정해진 금액을 충족하면 쿠폰 할인을 적용한다는 조건만 있다. 작성 모델은 이 지적을 반영해 할인 적용을 직접 설명했다.

이 지적은 원본과 연결되는 설명 개선으로 판단한다. 다만 초안을 실제 고객이 어떻게 이해했는지 측정한 것은 아니므로, 고객 오해율이 줄었다고 주장하지 않는다.

## 실행 방식

| 역할 | 도구에 지정한 모델 ID | 세션 |
| --- | --- | --- |
| 초안 작성 | `gpt-6-luna` | `/root/experiment_luna_writer` |
| 검토 | `gpt-6-astra` | `/root/experiment_luna_reviewer` |
| 수정 | `gpt-6-luna` | 초안을 작성한 동일 세션 |

- 두 초기 세션은 `fork_turns="none"`으로 생성했다. 이전 실험 결과나 기대 점수를 전달하지 않았다.
- 이전 실행의 세 요청문과 작성 전체 메시지를 그대로 복사했다. 검토 전체 메시지는 새 초안, 수정 전체 메시지는 새 검토 응답만 달라진다.
- 검토 의견을 작성 세션에 옮길 때 첫 고객 질문에 ‘아직’ 한 단어를 덧붙인 전사 차이가 있었다. 검토 결론·근거·수정 제안은 그대로 전달했다. 검토 원문과 실제 수정 입력을 각각 보존했다.
- 추론 설정은 별도 지정하지 않았다. 모델 ID와 입력을 기록했으며 공개 챗봇 웹 UI에서의 실행 결과는 아니다.
- 첫 초안 1회, 검토 1회, 원래 모델의 수정 응답 1회로 끝냈다. 오류를 삽입하거나 결과가 달라질 때까지 재생성하지 않았다.

## 동일 기준의 판정

주 작업자가 실제 초안과 수정본을 원본 메모에 대조했다. 설명의 모호함과 사실·조건의 누락을 구분했다.

| 기준 | 초안 | 수정본 | 확인 내용 |
| --- | --- | --- | --- |
| 기간과 대상 | 충족 | 충족 | 10월 20~22일, 앱 첫 구매 회원, 오래전 가입했어도 구매 이력이 없으면 대상임을 명시했다. |
| 최소 구매 금액 | 충족 | 충족 | 대상 상품 5만 원 이상, 행사 상품 금액 제외를 명시했다. |
| 할인과 예외 | 충족 | 충족 | 20%, 최대 1만 원이며 행사 상품 적용 불가를 명시했다. |
| 중복 사용 | 충족 | 충족 | 다른 쿠폰 불가와 적립금 허용을 구분했다. |
| 미정인 혜택 | 충족 | 충족 | 무료배송을 약속하지 않았고, 원본에 없는 별도 혜택·제한을 명시적으로 추가하지 않았다. |
| 합계 | **5/5** | **5/5** | 조건 충족 점수 변화 없음 |

초안의 ‘쿠폰을 드려요’는 지급 절차를 명시적으로 확정한 문장으로 단정하기 어려워 다섯 항목의 사실 오류로 감점하지 않았다. 별도의 오해 가능 표현으로 기록했다. 검토 모델도 사실 오류·필수 조건 누락과 구분해 지적했다.

고객 질문의 답도 전후가 같다. 오래전 가입했어도 첫 구매라면 대상이며, 일반 상품 3만 원과 행사 상품 3만 원의 조합은 최소 금액을 충족하지 못한다. 무료배송 여부는 단정할 수 없다.

## 실제 변경 내역

- 본문의 ‘5만 원 이상 구매 시 20% 할인 쿠폰을 드려요’를 ‘합계가 5만 원 이상이면 쿠폰으로 20% 할인받을 수 있어요’로 바꿨다. 검토 의견과 직접 연결되는 핵심 수정이다.
- 제목의 ‘20% 쿠폰 혜택’을 ‘20% 할인 혜택’으로 바꿨다.
- 본문 두 문장을 세 문장으로 나누고, 최대 할인액을 마지막 문장에 따로 적었다.
- 주의사항의 ‘다른 쿠폰과 함께’를 ‘다른 쿠폰과 중복’으로 바꿨다.
- 기간·대상·숫자·제외·중복 사용 조건은 유지됐고, 검토 후 새로 생긴 사실 오류는 관찰하지 못했다.

## 첫 실행과 비교

| 작성 → 검토 → 수정 | 조건 점수 | 안내문 변화 |
| --- | --- | --- |
| GPT-6.1 Sol → GPT-6 Astra → GPT-6.1 Sol | 5/5 → 5/5 | 안내문 변경 없음 |
| GPT-6 Luna → GPT-6 Astra → GPT-6 Luna | 5/5 → 5/5 | 할인 적용을 명확히 설명하는 문구로 변경 |

경량 모델이 만든 초안을 다른 모델이 검토하는 구성이 이번에는 관찰 가능한 문구 차이를 만들었다. 각 조합을 한 번씩 실행한 결과이며, 모델의 일반적인 능력 차이나 경량 모델을 쓰면 항상 검토 효과가 커진다는 결론을 내릴 수는 없다. 같은 모델로 재검토하는 대조 실험은 하지 않았다.
