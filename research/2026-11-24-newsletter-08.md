## 로컬 확인

- 분야별 목록에서 날짜로 뽑은 URL 11개가 본문의 분야별 수록 URL·발행일과 일치했다. 추천 3편, 작업물 업데이트 1편, 지난 호를 포함한 목록 8개, 홈·목록 카드의 제목·날짜·편수, 내부 링크와 자산 참조 110개 및 대상 앵커를 확인했다.
- Chrome에서 1440·390·320px의 라이트·다크 모드로 홈과 목록에서 8호로 이동했다. 본문 이미지 세 장이 로드되고 목차에서 실습으로 이동했으며 가로 넘침이 없었다. 시각 확인에는 외부 폰트 요청을 차단한 환경을 사용했다. 앨리스 결과 페이지 두 주소의 HTTP 응답은 모두 200이었다.
- 독자 의견을 반영해 실습의 예산을 29,000원에서 28,900원으로 100원 낮추고 다시 검색했다. Chrome 157.0.8103.79에서 가상 상점의 검색 폼과 등록된 WebMCP 도구에 ‘텀블러’와 최대 가격 30000·29000·28900을 각각 넣었다. 두 경로 모두 차례로 P200(29,000원), P200(29,000원), 빈 목록을 반환했다. 에이전트에게 말로 예산을 100원 낮춰 달라고 요청하는 단계는 독자 실험으로 남겼다.
- 저장소의 기존 Node 테스트 71개와 `git diff --check`를 통과했다. 초안은 로컬에서 검토했고, 11월 24일 최종 검토 후 푸시하도록 승인을 받았다.
