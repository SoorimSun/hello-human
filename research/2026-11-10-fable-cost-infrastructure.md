## 비용 예시 산식

가상 API 변경 영향 분석 200건, 건당 입력 12,000·출력 2,000토큰. 출력은 청구 대상 전체 출력량으로 가정한다.

- 입력 2,400,000 / 1,000,000 × $8 = $19.20.
- 출력 400,000 / 1,000,000 × $40 = $16.00.
- 기본 합계 $35.20, 같은 양을 Fast로 처리하면 $70.40.
- 캐시·배치 할인, 재시도·추가 호출, 별도 도구, 개발·운영비·세금 제외. 실측·전체 작업비가 아닌 API 이용료 가정.
- 검토 200 × 1.5분 + 추가 수정 20 × 4분 = 380분 = 6시간 20분. 시간당 인건비는 가정하지 않고 시간을 따로 제시.
- 완료 한 건당 총비용의 관계만 설명. 실제 완료 건수나 절감률은 만들지 않음. 소액 API 가격이므로 외환 시세를 가정해 붙이지 않음.

## 실험 선택과 범위

최근 일반뉴스의 실험을 현행 파일에서 대조했다. 11/09 원시 바이트·도구 인자 검증, 11/08 상품 이미지 가격 영역과 재검증, 11/07 채널 간 장바구니 순서, 11/06 접근·실행 권한, 11/05 커밋별 검사 기록, 11/04 코딩 도구로 재고 0 버그 수정, 11/03 견적 변경과 승인 경계.

이번에는 개발자의 API 변경 영향 분석으로 소재를 바꾸고, 모델 선택 A↔B와 결과 캐시 B↔C의 효과를 분리한다. 실행 입력은 합성 안내서·항목별 API 명세·프로그램 사용 명세다. 프로그램은 변경 전·후 API 명세를 비교해 변경 항목을 찾는다. 사용 명세에는 읽는 필드뿐 아니라 기대 형식과 사용 방식을 포함한다. 고정 기대 결과는 사후 채점에만 사용하며 모델·라우터·재시도·캐시에는 전달하지 않는다. 코드를 실제로 수정하거나 API·모델을 실행하는 구현 요청은 아니다.

- A 단일 고성능 / B 규칙 기반 모델 선택 / C B + 자동 검사 통과 결과 캐시. 같은 고성능 모델, 프롬프트, 설정, 검증·재시도 규칙을 고정. 규칙만 사용하는 처리도 기준으로 남겨 모델의 추가 기여를 확인.
- 조정은 별도 문서군, 최종 45건은 한 API의 설명 문구만 변경 15·자료형/필수 여부/허용값 또는 여러 API 변경 15·반복 15(완전 동일 5·문서 변경 5·접근 범위 변경 5). 변경된 접근 범위에서도 허용되는 자료에 대한 정상 요청을 사용. 권한 회수로 조회 자체가 거절되는 경우는 별도 실패 묶음.
- 세 회차마다 C의 캐시 초기화. 요청 순서는 동일하고 동시성 1, 구성 순서는 ABC/BCA/CAB로 순환. 같은 모델끼리 공급자 프롬프트 캐시 정책을 맞추고 할인 토큰 별도 기록. 45건의 반복 측정을 135개 독립 사례로 취급하지 않음.
- C의 완전 동일 5건만 앞서 자동 검사를 통과한 결과가 있을 때 재사용 가능. 이외 캐시 키는 서로 다르게 구성해 최대 적중 5/45=11.1%. 변경 버전·권한 범위 10건을 적중 후보로 세지 않으며 운영 트래픽의 적중률로 일반화하지 않음.
- 코드의 형식·근거 존재·참조 확인과 사람의 기대 결과에 따른 정확성 판정은 다른 단계. 코드 검증만으로 의미적 정답을 보장하지 않음.
- 오류 종류를 합쳐 최초 호출 뒤 추가 호출 1회까지만. 구조/근거 오류는 고성능 모델로 재시도, 전송 오류는 정해진 대기 정책. 추가 시도 실패는 보류·미저장.
- 정답·오답·보류 분모는 구성별·회차별 45. 자동 반환과 정답 판정은 별개이며 사람 수정 전 답을 채점. 중복·누락 없는 영향 대상, 변경 종류, 근거를 모두 요구. 실행 중 실제 오류는 제외하지 않고 주입 실패 검사는 별도. 자동 정답 한 건당 시스템 비용은 실패 포함 시스템 투입 / 수정 전 정답 수이며, 정답 0이면 계산 불가·도입 보류.
- 실행 시간은 접수→반환/보류(라우팅·캐시·자동 검사·대기 포함), 동일 기준 사람 검토·수정 시간은 따로 측정. 기대 결과 작성과 사후 평가 시간은 운영 검토 시간과 분리. 품질 비열화와 사전 지정한 비용·응답 시간·사람 부담을 함께 판단하는 소규모 제안.
- 화면은 미리 정한 기대 상태 4상황×4단계. 실제 캐시 엔진·성능 시뮬레이션이 아님. 데이터 수집·실제 모델 호출 없음.
