## 구성과 실험

인사 → 추천 3편 → 분야별 전체 목록 → 작업물 업데이트 → 작은 실험 → 맺음말 순서다. 실무 가이드·Shopify 개선 과정·패치 적용 확인을 ‘범위를 정하고 결과를 대조하기’로 연결했다. 글 제목과 요약은 원문의 주장을 넓히지 않는 범위에서 읽기 쉽게 다듬었다.

작은 실험은 상품 명세서와 판매 초안을 대조하는 가상 연습이다. 용량·판매 구성의 불일치, 색상 일치, 보온 성능 근거 부족을 구분한다. 수정 후 두 항목의 판정만 바뀌는지도 비교한다. 예상 판정은 사람이 제공 자료로 판단한 답안이며 실제 모델 실행 결과가 아니다. 사이트·도구를 연결하지 않고도 따라 할 수 있는 요청문을 넣었다.

## 검증 기록

- 분야별 목록에서 추출한 최초 발행일·URL 11쌍과 뉴스레터의 전체 기사 목록이 정확히 일치한다. 빠진 글·중복·기간 밖 글이 없다. 작업물 소개는 고유 페이지 2편이며 추천 3편을 이중 집계하지 않았다.
- 변경 HTML 3개의 태그 짝·중복 ID·ARIA 참조·noindex·테마·분석·갱신 스크립트·외부 링크 속성을 검사했다. 로컬 파일·앵커 참조 108개가 유효하다. 신규 HTML과 조사 기록의 엠대시·줄 끝 공백·마지막 개행도 확인했다.
- `node --test`: 기존 테스트 71개 통과. `git diff --check`: 공백 오류 없음. 신규 파일은 별도로 공백을 검사했다.
- 로컬 HTTP와 Edge 기반 Playwright로 1440·768·390·320px, 라이트·다크 총 8개 조합을 확인했다. 문서와 본문 요소의 가로 넘침이 없고, 추천 카드는 넓은 화면에서 3열·작은 화면에서 1열로 표시된다.
- 두 테마의 실제 배경색과 토글 상태, 이미지의 1280×720 로드를 확인했다. 데스크톱 도입부·작업물, 모바일 도입부·실습 화면을 캡처해 읽었다. 실습 목차를 눌렀을 때 제목이 고정 메뉴 아래에 보이는지도 확인했다.
- 홈·목록은 320px의 두 테마에서 가로 넘침이 없다. 홈 최신 카드 → 4호 → 목록 → 4호 → 첫 추천 가이드 이동을 확인했다. 목록은 04 LETTERS이며 테마 선택은 새로고침 후 유지된다.
- JavaScript를 끈 상태에서도 기사·업데이트 항목 13개와 추천 3편이 HTML에 표시된다. 반응형 확인 중 JavaScript 실행 오류와 로컬 HTTP 400 이상 응답은 없었다.
- 문장 검토에서 OFBiz 소개를 현재 기사에 실린 ‘소스 정리 자료’ 범위로 고쳤고, 두 회원 게임의 제작 과정을 구분했다. 내부 집계 설명은 조사 기록에 두고 독자에게는 새로 볼 내용을 중심으로 소개했다.

## 전체 문장 편집

사용자의 후속 요청에 따라 도입부부터 추천 카드, 분야별 요약, 회원 소식, 실험 안내와 맺음말까지 다시 읽고 다듬었다.

- ‘살펴봅니다·소개합니다·이어갑니다’가 반복되는 문장을 줄이고, 각 글에서 얻을 내용이나 직접 할 행동을 앞에 적었다.
- ‘상품정보 두 장’을 ‘명세서와 판매 페이지’로, ‘표준 관리 이관’을 ‘표준의 관리 주체 변경’으로 풀었다. ‘후자’는 바로 앞 게임을 가리키는 표현으로 바꾸고, ‘Microsoft의 AI 공격 사례’는 ‘Microsoft가 분석한 AI 공격 사례’로 주체를 명확히 했다.
- 실험 안내의 ‘보온 성능의 다음 행동’은 공급사에 시험 근거를 요청하는 행동으로 구체화했다. 가상 입력·요청문·기대 판정은 그대로 두고, 설명의 순서와 문장을 다듬었다.
- 홈과 뉴스레터 목록의 소개 문구를 같은 문장으로 맞추고 본문의 메타 설명도 갱신했다. 제목·수록 기간·편수·원문 URL·확인 범위는 유지했다. 추가 조사나 새 모델 실험을 수행한 것으로 표현하지 않았다.

편집 직전 원고와 편집본의 HTML 태그·속성을 대조했다. 메타 설명 두 곳 외에는 구조와 속성이 같으며, 링크·날짜·실습 입력·요청문은 바뀌지 않았다. 기사·업데이트 13개와 추천 3개의 구성을 확인했다. `git diff --check`와 신규 원고의 공백 검사도 통과했다. 로컬 브라우저에서 1440px 라이트·390px 다크·320px 라이트 화면의 가로 넘침이 없음을 확인하고, 추천 카드와 320px 도입부를 캡처해 줄바꿈을 읽었다. 공통 코드·스타일은 수정하지 않았으며 문장 편집 단계에서는 기존 동작 테스트를 다시 실행하지 않았다. 이 단계까지 커밋·푸시는 보류했다.

## 최종 반영 준비

- 후속 의견에 따라 포자 대청소 소개 첫 문장에 ‘조민하 회원의 퍼즐 게임’이라고 명시했다. 이름은 해당 문장 한 곳에만 추가했다.
