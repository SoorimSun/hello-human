## 실험 제안의 변경 이유

최근 11월9일은 파서와 업무 검증기, 11월10일은 규칙 기반 모델 선택·응답 재사용, 11월11일은 HTML/JSON 상품 추출·견적 직전 변경을 다뤘다. 초안의 일반 모델 대 판단 모델 라우팅 비교를 그대로 반복하지 않고, 이번 API의 확률 출력을 활용한 보류 기준 검증으로 바꿨다.

- 가상 상품 문의의 파손·배송 지연·사용법·추가 확인, 4개 유형으로 한정한다.
- 합성80건 = 조정20건 + 평가60건. 평가의 각 유형15건, 모델 평가3회. 180회는 고유 문의180건이 아니다.
- A/B에 같은 모델 출력·서버 권한 검사를 재사용한다. 바뀌는 것은 확률에 따른 보류 정책이다. 모델 종류와 안전장치를 동시에 바꿔 생기는 비교 혼선을 제거한다.
- 보류·자동 전달 비중·자동 전달 중 오분류율을 함께 제시한다. 전량 보류가 높은 성능처럼 보이지 않게 한다. 담당자에게 전달하는 것은 문의 해결이나 환불 완료를 뜻하지 않는다.
- 표의0.96·0.64·0.97, 기준0.90은 설명용 가정이며 API 결과가 아니다. 모델의 전체 확률 분포는 실험 때 수집할 항목이다.
- 개발용 후보 기준은 평가 전 고정. 이 글의 탐색용 통과 조건은 회차마다 자동 전달 오류0건·자동 전달 비중50% 이상. 운영 신뢰도 근거로 확대하지 않는다.
- 입력 순서에 따라 누적 상태가 변하는 실험이 아니므로 정적 흐름도와4개 결과표를 채택했다. 복잡한 재생 UI·실제 API 호출은 추가하지 않았다.
- 비용·응답시간은 제안 실험의 측정 항목이다. 이 기사 작성 작업의 사용량을 수집하는 절차가 아니다.

## 사이트 반영과 검증

- 작성 전 작업 트리는 비어 있었고, 현재 최대 일반뉴스44·속보14를 확인했다.
- 새 일반뉴스45 추가. 전체59·일반45·속보14. 홈 일반뉴스 카드만 교체했다.
- 전용 CSS 추가, 공통 자산 파일은 변경하지 않았다. 기존 noindex·테마·목차·갱신 감지 스크립트 유지.
- `node --test`: 기존71개 통과. 새 JS 없음.
- `git diff --check`: 통과. Git의 CRLF 안내는 오류가 아니다.
- HTML 파서로 기사·목록·홈의 상대 링크와 조각 식별자를 검사했다. 누락0·중복ID0, 이미지 alt·크기·noindex 확인. 목록 실제 항목도 일반45·단신14로 일치했다.
- 로컬 HTTP 미리보기에서 데스크톱1280×720과 모바일390×844를 확인했다. 제목 줄바꿈, 라이트·다크 대비, 실험 흐름·결과표, 목차 이동과 접힌 설명의 Enter 조작을 확인했다. 모바일 문서의 가로 넘침은 없었다.
- 목록 필터는 일반45·단신14·전체59로 표시됐고 새 글은1개였다. 글 열기→영상·접힌 설명 조작→목록 복귀→새로고침 뒤 새 글에 Updated가 붙지 않았다. 홈 최신 카드에서 기사로 이동했다.
- 공식 이미지2개의 실제 로딩·고유 크기를 확인했다. Tabletop 인쇄 대체 이미지는 별도로 원본을 열어 내용을 확인했으나, 숨겨진 인쇄 이미지의 브라우저 로딩은 확인하지 않았다.
- Tabletop iframe은 자동 재생 없이 대기하고, 클릭 후0초에서17초 이상 진행했다. 일시 정지 상태와 키보드k로 재개를 확인했다. 모바일 영역은 약343×193으로16:9를 유지했다.

- 실제 모델 호출·확률 평가·업무 서비스 연동은 수행하지 않았다. 기사에 실측 결과를 싣지 않았다.
