## 실제 확인 경로와 한계

- Anthropic 10/9 보고서는 웹 원문과 브라우저 본문으로 확인했다. 이 사이트의 10/10 기사에서 이미 다룬 보고서임을 확인하고 내부 링크를 연결했다.
- Axios는 검색 도구가 반환한 본문을 확인했다. 직접 열기는 도구에서 실패했다. 과도한 재서술 대신 당사자 설명을 담은 Reuters·현지 직접 취재로 범위를 교차 확인했다.
- Reuters 원문 도메인은 브라우저에서 접근 확인 화면이 나왔다. 이를 우회하지 않고 Investing.com에 표시된 Reuters 전재 본문을 사용했다. SpaceX 기사는 10/25 18:42 수정 표기가 있었다(사이트 표시 시간대는 확정하지 않음).
- 주정부 자체 공지와 이 조달 완료를 확인하는 별도 회사·금융기관 문서는 확보하지 못했다. 검색 부재를 문서가 존재하지 않는다는 뜻으로 쓰지 않는다.
- 영문 공식 자료와 한국어 자료 검색을 대조했지만 이 주장들의 유효한 공식 한국어 원문은 확인하지 못했다.
- 초안의 ‘최근 24시간’ 표현은 조사 범위를 과장할 수 있어 제거했다. 정확한 사건 발생일·전체 실행 기록·금융 계약·독립적인 방어 효과는 확인하지 않았다.

## 시각 자료 확인

- Anthropic 사건 보고서의 실제 DOM은 대표 삽화 1개, 동영상·iframe 0개였다. 사건 경위를 설명하는 도식 대신, 직접 연결되는 실행 격리 주제의 공식 기술 자료를 추가로 조사했다.
- [2025-10-20 Claude Code 샌드박스 글](https://www.anthropic.com/research/claude-code-sandboxing)의 파일·네트워크 격리 도식을 채택했다. 이번 내부 사건 환경과 동일하다는 뜻이 아님을 캡션에 명시했다. 원본 내용도 직접 열어 확인했다.
- 머스크의 해당 X 게시물 본문에는 이번 거래의 장비·계약 도식이 없었다. [Colossus 공식 소개](https://x.ai/colossus)의 항공 사진을 채택했다. 페이지의 오래된 규모 숫자·목표는 이번 조달의 설치 현황으로 사용하지 않았다. 사진을 실제로 열어 시설 전경임을 확인했다.
- 각 소식의 시점을 타임라인·단계 도식으로 정리했다. 금액 비례 그래프나 측정하지 않은 비용 절감률을 만들지 않았다.
- 파일·원본 URL·형식·가공 상태: [미디어 기록](../assets/news/claude-access-compute-media.md).

## 실험 편집

- 실행하지 않은 제안. 합성 상품과 모의 API에 한정한다.
- 수동 기준선, 같은 모델·프롬프트만 쓰는 방식, 실행 검사기를 추가한 방식을 비교한다.
- 연습 5건 / 최종 20건 / 에이전트 3회 반복은 시작용 예시이며 일반 기준이 아니다.
- 권한 거부, 예산 원자적 예약, 동시 호출, 재시도 상한, 응답 유실, 멱등성, 직접 네트워크 우회 차단을 검사한다.
- 실패 비용을 포함한 작업당 비용과 완료율을 함께 보고 실제 청구·가상 단가·인건비 추정을 분리한다. 이 기사 제작 과정의 사용량을 수집한 것이 아니다.

## 사이트 반영

- 최초 로컬 기준은 최대 일반뉴스 번호 25, 전체 35편·일반뉴스 25편·단신 10편이었다. 작업 전에 원격 변경을 가져오지 않아 10월 24·25일의 26·27호를 누락했다.
- 최초 로컬 커밋에서는 26호였으나, 원격 변경 머지에서 이 기사를 28호로 조정했다. 최종 목록은 전체 38편·일반뉴스 28편·단신 10편이다.
- 기사 H1·title·OG 제목, 목록과 홈의 제목·날짜·링크를 동기화했다. 홈의 단신 카드는 유지했다.
- 공통 CSS·JS 수정 없이 기사 범위의 CSS만 추가했다. README에는 개별 글을 계속 추가하지 않는 현재 저장소 지침을 따랐다.

## 최초 로컬 작성 단계의 검증

- `node --test` 통과. 출력 요약을 별도로 확인한 `node --test --test-reporter=dot`도 종료 코드 0.
- `git diff --check` 통과.
- HTML 파서로 기사·목록·홈의 태그 짝, 중복 ID, 목차·내부 링크 대상, 자산 존재, noindex, 외부 링크의 새 탭·rel 속성을 검사했다. 제목·OG·H1·홈·목록, 호수·날짜·36/26/10 편수 일치 확인.
- loopback의 `/hello-human/` 프로젝트 경로에서 브라우저 확인. 서버는 공개 콘텐츠 폴더만 허용하며 `.git`·`.agents` 등 숨김 경로를 제공하지 않도록 제한했다.
- 1440·768·390·320px에서 화면과 가로 넘침을 확인했다. 라이트·다크 테마, 의미 단위의 제목 줄바꿈, 표·도식 배치 확인. 768px의 세 칸 도식은 칸이 좁아 한 열 배치로 조정했다.
- WebP 3840×2161과 AVIF 828×310이 실제로 로딩되는 것 확인. 이미지 확대 링크의 대상은 동일 원본 파일이다.
- 목차의 SpaceX 절 이동, 홈 최신 카드에서 기사 진입 확인. 키보드 방향키로 전체 36 → 단신 10 → 일반뉴스 26을 전환했다. 새 기사 링크는 1개이며, 기사 열기·목록 복귀·새로고침 뒤 잘못된 Updated 표시가 없었다.
- 기사 브라우저 콘솔의 error/warn 조회 결과 0건.
- 추가 JavaScript가 없으며 HTML의 본문·도식·목록은 정적으로 제공된다. JavaScript를 끈 브라우저 및 인쇄 대화상자는 별도로 실행하지 않았다.
- 이 단계의 검증 범위는 로컬 결과물이었다. 이후 원격 조회와 머지 내역은 아래에 별도로 기록한다.

## 원격 변경 머지

- 먼저 이번 기사 변경을 `9844617`로 로컬 커밋했다.
- `git fetch origin` 후 `origin/main`의 `0f34c1c`, `73c6725`, `f79acff`를 확인했다. 각각 10월 24일 기사·OFBiz 자료, 홈 썸네일 제거, 10월 25일 기사 변경이다.
- `index.html`과 `news/index.html`의 충돌에서 원격 26·27호와 로컬 기사를 모두 보존했다. 홈은 최신 날짜인 10월 26일 기사를 가리키고, 썸네일 없는 기존 홈 카드 형태를 유지한다.
- 기사·미디어 기록·조사 기록·목록·홈의 이번 기사 번호를 28로 맞췄다. 날짜와 URL은 유지했다.
- 원격 변경은 로컬로 가져오는 방향으로만 반영한다. 푸시·배포는 수행하지 않는다.
- 머지 검증에서 충돌이 없던 원격 파일 73개가 원격과 동일한지 확인했다. 목록 URL 집합은 로컬·원격의 합집합이며, 38개 링크 중복 없음·일반뉴스 1~28호의 유일성·날짜순 정렬·기사 번호 일치가 모두 통과했다.
- 머지 후 `node --test`, `git diff --check`, 기사·목록·홈의 HTML·링크·메타데이터 검사를 통과했다. 브라우저에서도 이번 28호와 원격 27·26호, 전체 38편·일반뉴스 28편·단신 10편 표시를 확인했다.
