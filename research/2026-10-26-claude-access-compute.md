## 시각 자료 확인

- Anthropic 사건 보고서의 실제 DOM은 대표 삽화 1개, 동영상·iframe 0개였다. 사건 경위를 설명하는 도식 대신, 직접 연결되는 실행 격리 주제의 공식 기술 자료를 추가로 조사했다.
- [2025-10-20 Claude Code 샌드박스 글](https://www.anthropic.com/research/claude-code-sandboxing)의 파일·네트워크 격리 도식을 채택했다. 이번 내부 사건 환경과 동일하다는 뜻이 아님을 캡션에 명시했다. 원본 내용도 직접 열어 확인했다.
- 머스크의 해당 X 게시물 본문에는 이번 거래의 장비·계약 도식이 없었다. [Colossus 공식 소개](https://x.ai/colossus)의 항공 사진을 채택했다. 페이지의 오래된 규모 숫자·목표는 이번 조달의 설치 현황으로 사용하지 않았다. 사진을 실제로 열어 시설 전경임을 확인했다.
- 각 소식의 시점을 타임라인·단계 도식으로 정리했다. 금액 비례 그래프나 측정하지 않은 비용 절감률을 만들지 않았다.
- 파일·원본 URL·형식·가공 상태: [미디어 기록](../assets/news/claude-access-compute-media.md).

## 실험 편집

- 실행하지 않은 제안. 합성 상품과 모의 API에 한정한다.
- 수동 기준선, 같은 모델·프롬프트만 쓰는 방식, 실행 검사기를 추가한 방식을 비교한다.
- 연습 5건 / 최종 20건 / 에이전트 3회 반복은 시작용 예시이며 일반 기준이 아니다.
- 권한 거부, 예산 원자적 예약, 동시 호출, 재시도 상한, 응답 유실, 멱등성, 직접 네트워크 우회 차단을 검사한다.
- 실패 비용을 포함한 작업당 비용과 완료율을 함께 보고 실제 청구·가상 단가·인건비 추정을 분리한다. 이 기사 제작 과정의 사용량을 수집한 것이 아니다.

## 최초 로컬 작성 단계의 검증

- `node --test` 통과. 출력 요약을 별도로 확인한 `node --test --test-reporter=dot`도 종료 코드 0.

- loopback의 `/hello-human/` 프로젝트 경로에서 브라우저 확인. 서버는 공개 콘텐츠 폴더만 허용하며 `.git`·`.agents` 등 숨김 경로를 제공하지 않도록 제한했다.
- 1440·768·390·320px에서 화면과 가로 넘침을 확인했다. 라이트·다크 테마, 의미 단위의 제목 줄바꿈, 표·도식 배치 확인. 768px의 세 칸 도식은 칸이 좁아 한 열 배치로 조정했다.
- WebP 3840×2161과 AVIF 828×310이 실제로 로딩되는 것 확인. 이미지 확대 링크의 대상은 동일 원본 파일이다.
- 목차의 SpaceX 절 이동, 홈 최신 카드에서 기사 진입 확인. 키보드 방향키로 전체 36 → 단신 10 → 일반뉴스 26을 전환했다. 새 기사 링크는 1개이며, 기사 열기·목록 복귀·새로고침 뒤 잘못된 Updated 표시가 없었다.
- 기사 브라우저 콘솔의 error/warn 조회 결과 0건.
- 추가 JavaScript가 없으며 HTML의 본문·도식·목록은 정적으로 제공된다. JavaScript를 끈 브라우저 및 인쇄 대화상자는 별도로 실행하지 않았다.
- 이 단계의 검증 범위는 로컬 결과물이었다. 이후 원격 조회와 머지 내역은 아래에 별도로 기록한다.

## 원격 변경 머지

- 먼저 이번 기사 변경을 `9844617`로 로컬 커밋했다.
- `git fetch origin` 후 `origin/main`의 `0f34c1c`, `73c6725`, `f79acff`를 확인했다. 각각 10월 24일 기사·OFBiz 자료, 홈 썸네일 제거, 10월 25일 기사 변경이다.
- `index.html`과 `news/index.html`의 충돌에서 원격 26·27호와 로컬 기사를 모두 보존했다. 홈은 최신 날짜인 10월 26일 기사를 가리키고, 썸네일 없는 기존 홈 카드 형태를 유지한다.
- 기사·미디어 기록·조사 기록·목록·홈의 이번 기사 번호를 28로 맞췄다. 날짜와 URL은 유지했다.
- 원격 변경은 로컬로 가져오는 방향으로만 반영한다. 푸시·배포는 수행하지 않는다.
- 머지 검증에서 충돌이 없던 원격 파일 73개가 원격과 동일한지 확인했다. 목록 URL 집합은 로컬·원격의 합집합이며, 38개 링크 중복 없음·일반뉴스 1~28호의 유일성·날짜순 정렬·기사 번호 일치가 모두 통과했다.

## 본문 가독성과 실험 구성 수정

- 문체가 딱딱하고 실험이 직관적이지 않다는 피드백에 따라 소식 → 일상적인 업무 예시 → 의미 순서로 본문을 다시 썼다. 전문용어 정의와 반복되는 확인 절차 설명을 줄이고, 확인 범위는 해당 주장 옆에 남겼다.
- Claude의 접근 대상, Anthropic·주정부의 설명, Reuters의 독립 확인 한계, 10월 9일 보고서와 25일 보도의 차이를 유지했다. SpaceX의 400억 달러는 머스크의 발언이며 거래 조건·장비 가동은 확인되지 않았다는 구분도 유지했다. 새로 외부 사실을 조사하거나 최신화한 수정은 아니다.
- 주변 논점인 NVIDIA 구매 협상·네오클라우드 전망·CAPEX/OPEX 용어·모델 교체 인터페이스 설명을 본문에서 덜어냈다. 공식 이미지와 날짜 도식은 맥락에 맞게 유지했다.
- 비용 산식은 ‘총 조회비 1,000원 / 검증 통과 5건 = 완료 1건당 200원’이라는 가상 계산으로 풀었다. 검토 시간과 운영비를 합산할 조건은 접이식 설명으로 옮겼다.
- 실험은 동일 키보드의 A·B·C 가게 가격 비교로 구체화했다. 상품 가격 49,000·47,000·45,000원, 조회 요금 0·40·80원, 조회 한도 100·150원은 모두 가상이다. 모델에는 상품 가격 정답을 사전 제공하지 않는다.
- 기본 조건은 A·B만 조회 허용, C 계약 없음, 한도 100원이다. 기대값은 A 1회·B 1회·C 0회, 요금 40원·잔액 60원이며 확인한 가격 중 B가 최저다. C도 허용하되 한도 100원이면 예산 때문에 C 중단, 150원이면 모두 조회해 총 120원·잔액 30원으로 C가 최저다. 각 사례는 잔액을 초기화하고 A→B→C 순서로 실행한다.
- 같은 요청문·모델·도구에서 검사 함수 유무를 비교한다. 단순 성공 선언 대신 모의 서버 호출·요금 기록을 확인한다. 세 예제는 조정용이고, 새 평가 입력 10건·각 3회 반복은 시작용 제안이다. 동시 예약, 응답 유실, 중복 처리, 403·429, 우회 경로, 평가 방법은 접이식 설명에 남겼다.
- 본문 실험을 실제 구현하거나 모델에 호출한 것은 아니다. 이번 작업 범위는 기사와 관련 소개문·전용 스타일의 편집이다. 호수·발행일·URL·편수는 유지한다.

## OUR WORK 비용 예시 재수정

- 사용자가 현실성을 물은 대상은 SpaceX 조달액이 아니라 OUR WORK의 ‘상품 조사 10건에 1,000원’ 예시였다. 1,000원은 설명 편의를 위한 임의 금액으로, 특정 모델·입출력량·데이터 이용료·검토 시간에 근거한 비용이 아니었다.
- 해당 금액과 200원·100원 계산을 본문·도식에서 삭제했다. ‘조사 10건 중 검증을 통과한 결과가 5건’이라는 가상 상황으로 설명하고, 실제로 쓴 총비용을 완료 5건으로 나누도록 바꿨다. 같은 총비용을 10건으로 나눈 값과 비교하면 2배라는 관계만 남겼다.
- 실제 금액은 모델·데이터 이용료와 검토·수정 시간을 기록해 계산하도록 명시했다. SpaceX의 원화 환산과 별도 실험의 모의 조회 요금은 이번 수정 대상이 아니다.

## OUR WORK에 계산 근거가 있는 비용 예시 반영

- 사용자는 금액 삭제를 원한 것이 아니라 실제 업무에서 나올 법한 비용과 짧은 계산 근거를 요청했다. 앞선 무금액 예시를 상품 페이지 URL 10개의 가격·배송 조건을 비교표로 만드는 업무의 추정 비용으로 교체했다.
- 2026년 10월 26일 [Anthropic 공식 API 요금표](https://platform.claude.com/docs/en/about-claude/pricing)를 직접 열어 Claude Sonnet 5.5 일반 입력 100만 토큰당 2달러, 출력 100만 토큰당 10달러를 확인했다. 캐시·배치 할인 없는 일반 글로벌 요금이다. 모델 추천이나 실제 실행 결과를 뜻하지 않는다.
- 전체 입력 120,000토큰·출력 12,000토큰은 실패·재시도까지 포함한 가정이다. 계산은 (120,000 / 1,000,000 × 2) + (12,000 / 1,000,000 × 10) = 0.36달러. 앞서 검증한 환율 1,323.76원을 적용하면 476.5536원이며, 독자용으로 약 500원으로 반올림했다.
- 담당자 작업은 검토 10건 × 3분 = 30분, 오류 수정 4건 × 5분 = 20분으로 총 50분을 가정했다. 예시용 시간당 30,000원 × (50 / 60) = 25,000원이다. 시간당 단가는 업계 평균이나 사용자 회사의 실원가가 아니며, 추가 결제액이 아닌 시간 투입의 비용 환산이다.
- 수정 후에도 출처를 확인하지 못한 2건은 보류하고 8건을 완료로 세는 상황이다. 정확 계산은 (476.5536 + 25,000) / 8 = 3,184.5692원, 반올림한 모델료를 쓰면 25,500 / 8 = 3,187.5원이며 모두 완료 한 건당 약 3,200원이다.
- 유료 검색·데이터 구매, URL 사전 수집, 개발·운영비와 세금은 제외한다. 받은 URL의 공개 자료를 읽어 비교표로 정리하고 검토·수정하는 단계만 다룬다. 공식 단가와 가정한 사용량·작업 시간을 구분해 본문에 표기했다.
- 별도 실험의 모의 조회 요금과 SpaceX의 조달액·원화 환산, 기사 제목·호수·날짜·목록 소개는 바꾸지 않았다. 이번에도 실제 모델 호출이나 업무 시간 측정은 하지 않았다.
- 환산·인건비·완료 건당 산식을 계산으로 대조했다. `git diff --check`와 기존 기사·목록·홈의 HTML·링크·메타데이터·편수 검사를 통과했고, 데스크톱·모바일 브라우저에서 금액 표시와 도식 줄바꿈을 확인했다. 모바일에서 문서 가로 넘침은 없었다. 커밋·푸시는 수행하지 않았다.
