# Patch the Planet 단신 확인 기록

- 확인일 2026-10-22, 한국시간. 사건·발표 날짜는 원문 표기를 따름.
- 대상 `news/2026-10-22-patch-the-planet.html`, BRIEF 10.
- 지정된 채팅 「AI뉴스 단신 작성」의 두 원고와 수정 요청을 읽었다. 마지막 원고의 방향에 따라 프로그램의 목적·지원 내용을 먼저 설명하고 PHP를 사례로 배치했다.
- 채팅의 인용 표시는 재사용하지 않고 원문을 다시 열었다. 긱뉴스·해커뉴스도 브라우저에서 읽었으며, 댓글은 검증할 쟁점을 찾는 데만 사용했다. 두 사이트의 URL과 댓글 인용은 결과물에 넣지 않았다.
- 최초 요청에 따라 로컬 기사·목록·홈을 반영하고 커밋·푸시를 보류했다. 이후 사용자가 2026-10-22 후속 메시지에서 푸시를 명시적으로 요청했다.

출범 소개의 한국어 URL은 열기 실패로 내용을 확인하지 못해 검증한 영문 원문을 연결했다. 10월 발표는 실제 열람한 한국어 원문을 사용했다. 취약점과 패치 효과를 직접 재현하지 않았으며 기사 하단에 명시했다.

## 토론에서 제기된 쟁점 처리

- AI와 사람의 공헌을 분리했다. ‘AI가 모든 일을 했다’는 해석은 채택하지 않았다.
- 공개 전 악용 시도와 공조의 필요성을 함께 설명했다. 공개 유예가 전 기간 안전을 보장했다고 쓰지 않았다.
- 지원 종료 버전에 패치가 전혀 없다는 댓글은 채택하지 않았다. PHP 공지는 일부 구버전용 최소 소스 패치와 배포업체의 지원을 안내한다. 본문에는 지원 중인 네 계열의 수정 버전과 공급업체 확인 안내만 간결하게 담았다.
- 프로그램 전체의 효과를 독립적으로 측정한 자료가 아니므로 생산성·피해 감소 성과를 만들어 넣지 않았다. ‘헬로우 휴먼의 시선’은 모임의 적용 제안으로 구분했다.

## 사이트 반영

- 기존 단신의 한 열 레이아웃과 공통 테마·분석·갱신 표시를 재사용했다. 지원 표와 다섯 단계 목록의 스타일만 기사 전용 CSS로 추가했다.
- 목록에 새 URL을 한 번 등록하고 같은 날짜 일반뉴스 앞에 배치했다. 전체 34편, 일반뉴스 24편, 단신 10편으로 맞췄다.
- 홈은 최신 단신 카드의 제목·날짜·번호·URL을 갱신했다.

## 검증

- `node --test` 기존 테스트 71개 통과.
- 홈·목록·기사의 로컬 참조 115개, 중복 ID, noindex, 외부 링크의 새 탭·보안 속성 확인.
- 전체 34편(일반뉴스 24, 단신 10), 날짜 내림차순과 같은 날짜 단신 우선 정렬, 신규 URL 1회 등록, BRIEF 10과 발행일 일치 확인.
- 기사에서 토론 사이트 URL, 채팅 전용 인용 표기, 엠대시가 없음을 확인.
- 브라우저에서 기사 → 목록 → 단신 탭(10편) → 홈 → 새 단신 이동 확인. 홈의 일반뉴스 24 연결 유지 확인.
- 데스크톱 1280px와 모바일 390px 설정에서 화면을 확인했다. 모바일 제목의 제품명이 갈라지지 않도록 크기·줄바꿈을 조정하고 다시 확인했다. 지원 표와 다섯 단계 목록, 라이트·다크 모드, 가로 넘침 없음을 확인했다.
- 기사 브라우저 경고·오류 로그 없음. 임시 화면 크기 설정을 해제했다.
- 최초 로컬 검증에서 `git diff --check` 통과. 당시 커밋·푸시·원격 배포는 수행하지 않았다.

## 공식 이미지 추가

- 사용자 요청에 따라 공식 이미지 유무를 확인했다. OpenAI의 두 대표 이미지와 출범 글의 도식, Trail of Bits의 공식 프로그램 이미지를 살펴봤다.
- 프로그램의 공동 운영을 보여주는 Trail of Bits의 호출기 모양 홍보 이미지 원본을 기사 상단과 공유 메타데이터에 추가했다. 출처·크기는 `assets/news/patch-the-planet-media.md`에 기록했다.
- 생성형 이미지를 만들거나 원본을 편집하지 않았다. 기사 내용·날짜·번호는 유지했다.
- PNG 파일의 크기·해상도, 기사 이미지 경로·대체 설명, 출처 링크 속성을 확인했다. 데스크톱·390px 모바일에서 이미지와 캡션이 정상 표시되고 가로 넘침이 없음을 확인했다. 실행 코드 변경이 없어 기존 동작 테스트는 반복하지 않았다. `git diff --check` 통과.

## 제목 확정

- 사용자와 재검토해 제목을 ‘OpenAI ‘Patch the Planet’, 취약점 수정부터 배포까지 공동 대응 제안’으로 확정했다. 프로그램의 목적을 설명하던 제목을 이번 발표의 새 내용인 공동 대응 절차 제안에 맞췄다.
- 본문 H1, 페이지 title, 공유용 제목, 뉴스 목록, 홈의 최신 단신 제목을 함께 수정했다. 사용자가 이 제목으로 변경한 뒤 푸시하도록 명시적으로 요청했다.
- 확정 제목의 다섯 노출 위치 일치와 데스크톱·모바일 줄바꿈, 가로 넘침 없음을 확인했다. 최종 작업 상태에서 기존 테스트 71개와 `git diff --check`가 통과했다.
