# OFBiz 산출물 제공 전후 실제 응답 비교 계획

실행 전에 조건과 판독 기준을 고정한다.

- 비교 단위: 독립 실행 2개, 조건별 1회. 반복·유의성 추정 없음.
- 같은 설정: 상위 세션의 동일 모델·추론 설정을 상속, 별도 모델 override 없음.
- 대화 이력: fork_turns=none. 이전 기사·구성 예시·다른 조건 답변을 전달하지 않는다.
- 공통 입력: 동일한 질문·응답 지시·소스 발췌 4개. 출처 커밋 e7b7ae0eaa4561a2357b198e21cc8ca63ffac105.
- 차이: run-02에만 작성된 기능 설명서·연결표 2개를 추가한다.
- 도구 조건: 자신의 입력 파일 1개만 읽고 답변. 다른 파일·외부 검색·코드 실행·수정 금지.
- 응답 길이: 한국어 1,200자 이내를 두 조건에 동일하게 지시한다.
- 모델 ID·sampling parameter: 도구가 제공하는 설정만 기록하며, 노출되지 않은 모델 버전·temperature·seed는 추정하지 않는다.
- 판독: 실제 알림 연결 위치, 일반/NoActions 경로 차이, 부분 취소 처리, 테스트와 미실행 상태, 추가 조사 항목, 소스 밖 단정 여부를 비교한다. 차이가 없으면 그대로 기록한다.
- 시간·토큰 비용: 이 비교에서 성능 지표로 평가하지 않는다.
- 제한: 관련 소스를 미리 골라 주므로 저장소 탐색 능력은 평가하지 못한다. 산출물에는 평가 질문과 유사한 사용 예시 및 테스트 초안이 들어 있다. 답변에 그 내용이 나타나는 것은 독립 발견이나 정확성 향상의 증거가 아니다.
