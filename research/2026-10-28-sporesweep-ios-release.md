# 포자 대청소 iOS 출시 반영

확인·수정일은 2026-10-28(한국시간)이다. 사용자 요청에 따라 기존 `works/jo-minha.html`과 홈 회원 작업물 카드를 수정했다. 최초 소개일 2026-10-16, URL, 상단 플레이 흐름 도식과 기존 웹 캡처를 유지했다.

## 근거

- [한국 App Store](https://apps.apple.com/kr/app/id6826591259)를 브라우저로 직접 열었다. 앱 이름 ‘포자 대청소’, 개발자 Min ha Cho, iPhone 전용, 무료, iOS 17.0 이상, 한국어·영어 제공을 확인했다. 개발자 웹사이트는 기존 제작자의 `code404.app/sporesweep/`로 연결된다.
- App Store의 게임 설명에는 24개 도시·380개 레벨, 제염 빔·중화 폭탄·정화 코어·청소 드론, 선택형 보상 광고가 안내돼 있다. 이 안내를 실제 기기 실행이나 광고 동작 시험 결과로 표현하지 않는다.
- [제작자의 공개 기록](https://github.com/twobeansdaddy-hue/SporeSweep/blob/0d280905e08ad2712e5734c49a69b7732b5364bd/HANDOFF.md)은 iOS 1.0의 2026-10-27 심사 완료·공개와 App Store 주소를 기록한다. 본문에는 별도 출시일을 단정하지 않고 2026-10-28에 확인한 출시 상태를 반영했다.
- 같은 기록은 웹을 동호회 체험용으로 열었고 실제 광고 대신 보상을 준다고 설명한다. 웹을 실제 광고 없는 테스트 버전으로 구분한 기존 안내를 유지했다.
- [제작자 소개 사이트](https://code404.app/)에는 ‘곧 출시’ 문구가 남아 있지만, 공식 App Store의 실제 공개 페이지를 현재 iOS 상태의 근거로 삼았다.

## 변경

- 메타 설명·상단 상태·플랫폼 현황·마무리·홈 카드를 iOS 출시 상태로 맞췄다. 상단, iOS 카드, 마무리에 공식 한국 App Store 링크를 넣었다.
- 플랫폼 안내에서 iOS를 첫 카드로 강조하고 웹은 테스트 체험으로 구분했다. 무료 다운로드와 선택형 보상 광고는 App Store 안내임을 표시했다. Android 정식 출시를 주장하거나 새 다운로드 주소를 추정하지 않았다.
- 예전 ‘특수 블록 3종·조합 6종’ 표현을 현재 스토어에서 확인한 특수 블록 네 가지 이름으로 바꿨다.
- 2026-10-20 웹 캡처 세 장은 그대로 두고 웹 테스트 화면임을 제목·캡션에서 분명히 했다. iOS 앱 화면으로 재표기하거나 새 이미지를 합성하지 않았다.
- 기존 강조 카드 CSS 선택자를 플랫폼 공통 이름으로 정리하고 전용 CSS 캐시 버전을 5로 올렸다. 공통 스타일과 JavaScript는 수정하지 않았다.

## 검증과 범위

- HTML 태그 짝·중복 ID·noindex·외부 링크 속성 확인, 두 페이지의 로컬 링크·리소스·앵커 66개 확인.
- App Store 버튼 세 개가 확인된 동일 주소를 가리킨다. 실제 버튼을 눌러 새 탭에 ‘포자 대청소 앱 - App Store’ 페이지가 열리는 것을 확인했다.
- 데스크톱 상단·플랫폼 안내, 390px 모바일 상단 버튼 줄바꿈, 320px 다크 모드의 플랫폼 안내를 확인했다. 모바일 가로 넘침 없음. 임시 뷰포트를 해제하고 라이트 모드로 복구했다.
- `/hello-human/` 경로의 홈 카드에서 작업물 페이지로 이동해 iOS 출시 안내와 다운로드 링크를 확인했다.
- `node --test`: 기존 테스트 71개 통과. `git diff --check`: 공백 오류 없음.
- 이번 확인은 스토어 공개 정보와 소개 페이지 검증이다. iOS 앱 설치·실기기 플레이·광고 재생·진행 저장은 시험하지 않았다. 2026-10-20의 직접 웹 플레이 기록은 기존 조사 문서에 남아 있다.
- 소개 수정과 검증을 마친 뒤 사용자가 커밋·푸시를 요청했다. 이번 업데이트의 변경 파일 4개를 기존 `main`에 함께 반영한다.
