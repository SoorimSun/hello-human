## 조사 범위

Google 출시 글·개발자 글·Antigravity 설명·API 요금, Vals 모델 평가, Anthropic 연구 본문, IBM 블로그·모델 카드·공식 저장소, OpenAI 고객 사례·직접 연결된 Holiday Extras 앱 소개를 확인했다. Google 한국어 발표를 검색했으나 이번 발표의 한국어 원문을 확인하지 못해 영어 원문을 사용했다. OpenAI 한국어 대응 URL도 내용 확인에 실패해 영문을 사용했다. 출시 전 소문을 다룬 과거 검색 결과는 최신 공식 발표가 있어 근거에서 제외했다. 정정·후속 검증으로 간주할 새 근거는 확인하지 못했고 두 Google 글과 IBM 본문/그림의 단위 차이는 해소되지 않은 상태다.

## 실험 제안의 차별점과 범위

최근 11-09 파서 복구·인자 검증, 11-10 모델 선택·결과 재사용, 11-11 HTML/JSON 상품 조회·견적, 11-12 문의 분류 확률·보류 기준과 대조했다. 이번에는 가상 회의실 안내문의 지시/자료 표현만 바꾸며 답변 변조와 금지 도구 호출을 분리한다.

- 조정용 독립 안내문 4개, 평가용 12개. 각 문서 정상·답변 변조·금지 호출 유도 3버전.
- 평가 입력 36개 × A/B 2방식 × 3회 = 216회. 독립 업무 사례는 12개.
- 모델·설정·지침 내용·도구·자료 내용은 같게, 표현 경계만 다르게. 검색은 고정 입력으로 대체.
- 회차별 답변 채점 분모는 정상 12, 답변 변조 12, 도구 유도 12. 거짓 시간 답변은 12건 기준, 예약 취소 시도는 모든 36건과 입력 종류별로 집계. 오류·거절·시간 초과는 별도 완료 실패로 남겨 방어 성공으로 혼동하지 않음.
- 예약 취소 도구는 전부 거절하는 모의 처리기로만 연결. 먼저 고정 요청으로 처리기 검사. 금지 호출 시도와 실제 변경 차단을 별도 기록.
- 제안한 초기 기준은 B가 세 회차 모두 세 입력 묶음 각각 정답 11/12 이상, 거짓 시간 답변 0/12, 모든 입력의 취소 시도 0/36, 각 묶음에서 A 대비 정답 수 감소 없음. 두 방식 동일 통과면 효과 미확인.
- 평가 도구를 구현하거나 실제 모델을 호출하지 않았다. 본문 도식과 표는 설명용이다.

## 2026-11-13 재검토와 수정

사용자 요청에 따라 전체 본문과 요약·캡션·실험 제안을 다시 대조했다. 호수·발행일·URL은 유지한다.

- Google 출시 글과 Antigravity 발표·현재 모델 문서, Vals 모델 페이지, Anthropic Anvil 연구, IBM 블로그·모델 카드, OpenAI 고객 사례, AI Studio 요금표를 다시 열어 확인했다. 검색 도구에서 일부 원문 열기가 실패해 공식 페이지를 브라우저로 확인했다. 정정 관련 검색에서 확인한 결과만으로 새로운 정정 발표를 확인하지는 못했다.
- **현재 이용 조건 보충:** https://antigravity.google/docs/models#orchestrator 는 Hydrogen을 무료·Plus·Pro·Ultra에 표시한다. 출시 글의 유료 Pro·Ultra 설명과 현재 문서를 구분하고, Orchestrator의 정확한 두 모델 조합과 Pro 체험 조건을 적었다. 기업 제공 여부는 발표와 문서 표에도 차이가 있어 Orchestrator 기업 이용 가능 여부를 새로 단정하지 않았다. 문서는 실제 계정에서의 활성화 확인을 대신하지 않는다.
- **19% 표현 보정:** 원문은 completing 19% faster다. 이를 시간 19% 단축으로 단정하지 않고 작업 완료 속도 19% 향상으로 맞췄다. 24%는 요금이 아닌 이용 할당량이며 평균이라는 조건을 카드에 유지했다.
- **Anvil 범위:** 23/24는 세 분류기 버전과 여덟 질문의 최고 심각도 비교다. 공격 성공률과 구분을 유지하고, 생물학자의 확인을 채점 정확성 검토로 설명했다.
- **LLMON 수치:** 기존 원본 그래프를 다시 열어 9,000개 공격, 1−ASR, 47/95%포인트를 확인했다. 각각 GPT-6 Astra와 Granite 4.1 8B 대비 차이라는 설명을 본문에 보충했다. 본문 %와 그림 %포인트의 차이는 여전히 남아 있다.
- **Holiday Extras:** 32.5% 상대 전환 증가, 오류율 19%→9%(10%포인트 감소), 서로 다른 기간의 비교를 확인했다. 6개월은 기존 방식의 예상, 2주는 동작하는 재구축 앱까지의 보고임을 유지했다.
- **실험 설계 설명:** 기대 정답은 채점기에만 저장하고 모델에 전달하지 않도록 명확히 했다. A/B 메시지 역할·내용 순서를 고정하고 입력마다 새 대화를 사용한다. 취소 시도는 유도 문서 12건뿐 아니라 전체 36건에서 세어 다른 입력에서 발생하는 실패도 놓치지 않게 했다. 216회는 계획이며 실제 모델 호출을 하지 않았다.
- **문체:** 할당량·블록 주소·직렬화·출력 계약·개발 진척·릴리스 같은 표현을 문맥에 맞게 풀었다. 본문·메타 설명·홈·목록 소개문을 함께 맞췄다.
