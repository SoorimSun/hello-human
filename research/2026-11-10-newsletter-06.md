## 작은 실습

- 일반뉴스 38의 배송 로그 검증 실험을 기록 대조 단계로 줄였다. 지난 5호의 중단 후 중복 실행 방지 실습과 구분된다.
- 가상 수정본 `demo-b`와 세 기록 A/B/C를 제시한다. A는 필수 검사 기록 확인, B는 이전 수정본 재검사, C는 거절 경로 검사 누락이다.
- 기대 결과를 실행 전에 정하고, 입력 순서 변경·실패 기록 추가를 통해 판정 조건을 확인하도록 제안했다.
- ‘필수 검사 기록 확인’은 정한 검사 기록이 갖춰졌다는 뜻이다. 코드의 정확성·병합 승인·생산성 향상 증거가 아니다. 실제 스크립트 구현·실행·성능 측정은 하지 않았다.

## 확인 기록

- `node --test --test-reporter=dot`: 71개 통과, 종료 코드 0. 기존 저장소 기능 검사이며 기사 내용이나 제안된 실습을 실행한 결과가 아니다.
- 일회성 HTML 검사로 홈·뉴스레터 목록·6호의 상대 파일·앵커 참조 107개, 중복 ID 없음, noindex, 외부 링크의 새 탭·rel 속성을 확인했다. 실습 원문 링크는 실제 대상인 `#experiment`로 맞췄다.
- 분야별 원문 목록의 기간 내 URL 집합과 6호 전체 목록의 10개 고유 URL이 일치했다. 일반뉴스 7·단신 2·가이드 1, 추천 3편의 포함 관계, 목록 6개와 홈 최신 카드 연결도 확인했다.
- `git diff --check`에 공백 오류가 없다. 새 HTML·조사 기록의 줄 끝 공백, 마지막 개행, 엠대시·문자 대체 기호도 별도로 검사했다.
- 앱 내 브라우저에서 로컬 HTTP 미리보기를 열었다. 본문은 실제 CSS 폭 291~1408px의 작은 화면·데스크톱에서 라이트·다크 모드와 가로 넘침 없음을 확인했다. 320px 다크의 도입·실습, 390px 라이트의 뉴스 영역·공식 이미지와 기본 데스크톱 도입을 직접 보았다.
- 홈·목록은 320px의 두 테마에서 가로 넘침이 없었다. 목록에는 `06 LETTERS`와 6호가 먼저 표시되며, 홈 최신 카드와 목록에서 6호로 이동했다.
- 실습 목차 이동 후 제목이 고정 메뉴 아래에 보였다. 실습 원문 링크를 눌러 일반뉴스 38의 해당 절로 이동한 뒤 돌아왔다. 테마를 바꾸고 새로고침해 선택 유지도 확인했다.
- 공식 이미지는 자연 너비 3200px로 정상 로드됐다. 최종 브라우저 오류 로그는 0건이었다. 본문과 전체 목록은 정적 HTML에 있으나 JavaScript를 강제로 끈 브라우저 검사는 별도로 수행하지 않았다.
- 기본 화면 크기·라이트 모드로 복원하고 6호 미리보기를 열어두었다. 커밋·푸시·배포·메일 발송은 하지 않았다.

## 전체 문장 검토·편집 · 2026-11-10

- 사용자 요청에 따라 도입부·추천·전체 목록·캡션·실습·맺음말을 다시 읽었다. ‘살펴봅니다’, ‘이어집니다’ 같은 반복을 줄이고, 추상적인 설명을 독자가 할 일과 글에 담긴 내용으로 풀었다.
- 추천 카드는 읽을 이유를, 분야별 목록은 글의 내용을 중심으로 다듬었다. 홈·뉴스레터 목록의 소개와 본문의 설명 메타데이터도 함께 맞췄다.
- 실습의 ‘검사 근거 충족’을 ‘필수 검사 기록 확인’으로 바꾸고, 접수·거절·메모 보존이라는 세 검사 조건을 일관되게 표현했다. 가상 기록 대조와 실제 코드 검증의 구분은 유지했다.
- 외부 자료를 새로 조사하거나 제품·실습을 실행한 편집은 아니다. 인수 계획·기업의 초기 조사·실험 제안 등 원래의 확인 범위를 유지했다.
- 편집 직전 사본과 HTML 3개를 대조했다. 설명 메타데이터를 제외한 태그·속성, 호 제목, 날짜, 링크·앵커·미디어 참조가 동일했다. 전체 글 10편·추천 3편을 유지했고 상대 파일·앵커 참조 107개에 오류가 없었다.
- 문장 수정 후 기존 테스트 71개가 통과했고 `git diff --check`에 공백 오류가 없었다. 별도의 테스트 코드는 추가하지 않았다.
- 로컬 미리보기를 새로고침해 수정 문구를 확인했다. 기본 화면의 기사 요약과 실제 CSS 폭 354px의 도입·뉴스 영역·실습을 직접 확인했으며, 가로 넘침과 브라우저 오류가 없었다. 기본 화면 크기로 복원하고 미리보기를 열어두었다.
- 커밋·푸시·배포·메일 발송은 하지 않았다.

## 새 글이 없는 분야 안내 삭제 · 2026-11-10

- 사용자 피드백에 따라 신규 발행이 없는 분야·작업물의 안내 절과 해당 목차 항목을 삭제했다. 단신 다음에 작은 실습이 이어진다.
- 수록 글 10편과 추천 3편은 그대로다. 집계 근거는 이 편집 기록에만 남긴다. 이 편집 단계에서는 푸시하지 않았다.

## 최종 반영 준비 · 2026-11-10

- 사용자가 커밋·푸시를 명시적으로 요청했다. 6호 본문, 뉴스레터 목록, 홈, 이 편집 기록의 4개 파일을 대상으로 한다.
- `git fetch origin` 후 로컬 `main`과 `origin/main` 사이에 선행·후행 커밋이 없음을 확인했다.
- 최종 원고에서 새 글이 없는 분야의 본문·목차 항목이 빠진 것을 확인했다. 수록 10편·추천 3편·목록 6개와 내부 파일·앵커 참조 103개를 검사했고 오류가 없었다.
- 커밋 전 기존 테스트 71개가 통과했고 `git diff --check`에 공백 오류가 없었다. 배포 성공 여부는 푸시 후 별도로 확인한다.
