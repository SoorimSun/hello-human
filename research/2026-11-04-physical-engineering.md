## 확인 범위와 제외

- OpenAI 한국어 후보 페이지는 접근되지 않았고 관련 한국어 검색에서 유효한 번역을 확보하지 못해 실제 확인한 영문 원문을 사용했다.
- Open WebUI 릴리스는 확인 시 Latest로 표시됐다. 상세 보안 권고의 공개 상태는 별도 검증하지 않았으므로 CVE 공개 예정 문구를 본문에 복제하지 않았다.
- 독립적인 제조 비용 절감·실도로 안전성 개선 수치는 확보하지 못했다. 공급사 발표를 독립 측정으로 표현하지 않았다.
- OpenAI 영상은 실제 페이지에서 해당 위치로 이동해 확인했지만 Vimeo iframe의 재생 주소가 비어 있어 재생되지 않았다. 원문에 영상이 없다고 단정하지 않는다.
- Mazda 영상은 재게재·재사용 금지 문구가 있어 임베드·다운로드하지 않았다.
- 바이두 기술 설명은 출처가 바이두인 발표문 전재를 근거로 했다. Reuters는 공개 사건과 10만 km 주장의 보조 대조 자료다.

## 실험 설계

- 최근 글 대조: 11월 3일은 견적 변경·위임 취소·주문 원장 검증, 11월 2일은 채널 참여 판단·작업 복구, 10월 30일은 재시도와 늦게 도착한 비용 집계였다.
- 이번 질문: 파일 수정·실행·실패 로그 전달을 연결하면 가상 CSV 가져오기 수정의 사람 개입이 줄어드는가.
- 8개 결함은 서로 독립된 시작 코드로 준비한다. 연습 2건과 최종 8건을 분리하고 동일 요청·모델·설정·실행 환경을 유지한다. 각 방식 3회, 전체 48회라는 제안이다.
- 모델이 수정할 수 없는 정답 검사를 별도로 두고 JSON·오류 목록·화면을 대조한다. 실제 앱·검사기·API 호출은 이 기사 작성의 구현 범위가 아니다.
- 데이터 형식과 업무 규칙을 먼저 정의했다. 중복 상품 코드는 두 행 모두 제외하는 가상 정책이며 일반적인 CSV 규격의 규칙이 아니다.
- 비교의 완전한 통제에는 한계가 있다. 같은 모델에 도구를 연결하면 도구 설명·메시지 형식도 달라진다. 특정 브랜드의 우열이나 운영 신뢰도로 일반화하지 않는다.
- A에도 같은 소스 파일·오류 재현 정보를 제공하고 모델 수정안을 그대로 적용한다. 사람의 직접 코드 수정은 자동 수정 성공에서 제외한다. 요청 전달부터 검사 종료까지 15분은 이 가상 과제에 제안한 동일 상한이며 제품의 제한이나 측정값이 아니다.
- 결과물은 버전이 있는 입력·시작 코드·요청문·검사기·변경 내역·실패 기록. 비용의 실제 단가와 금액은 제시하지 않았으므로 이번 기사에 가격·환율 추정을 추가하지 않았다.

## 검증 기록

- `node --test`: 기존 테스트 71개 통과, 실패 0. 새 실행 로직은 추가하지 않았다.
- `git diff --check`: 오류 없음. 기존 파일의 LF→CRLF 변환 안내는 있으나 공백 오류는 없다.
- HTML 검사: id 11개 중복 없음, 목차와 상대 링크·자산 경로 존재, 외부 링크의 새 탭·보안 속성, noindex, 엠대시 미사용 확인.
- 기사·목록·홈의 제목, ISSUE 37, 2026-11-04, URL 일치. 전체 50편·일반뉴스 37편·단신 13편, 새 기사 링크 한 번만 등록.
- 브라우저: 기본 데스크톱 1280px, 모바일 390px·320px 확인. 320px에서 회사명만 한 줄로 남는 현상을 발견해 전용 CSS의 좁은 화면 글자 크기를 조정하고 다시 확인했다.
- 라이트·다크 화면, 모바일 도식의 세로 순서, 실험 표, 가로 넘침 없음 확인. 이미지 3개는 각 절로 이동해 기사 내 로딩을 확인했다.
- 목차 클릭과 Enter 이동, 일반뉴스·단신 필터의 37·13편, 필터의 ArrowRight 이동 확인. 기사 열기→목록 복귀→새로고침 뒤 새 기사에 불필요한 Updated가 붙지 않았다.
- 홈의 최신 일반뉴스가 새 기사로 연결되고 기존 단신 링크는 유지됨을 확인했다. 마지막에는 기사 미리보기를 열고 임시 화면 크기 설정을 해제했다.
- 설명도·표·실험은 HTML에 정적으로 포함돼 있다. 자바스크립트를 실제로 끈 브라우저 세션과 인쇄 미리보기는 별도 확인하지 않았다.
- 공식 영상은 임베드하지 않았다. 제품 설치·모델 성능·48회 실험 실행은 수행하지 않았다.
