## 실험 제안의 범위

최근 11/12 문의 분류·보류, 11/13 문서 속 명령, 11/14 결제 응답 유실, 11/15 실행·비용 집계 대조 절을 읽었다. 이번 검증 질문은 캐시 재사용이 가리는 설치 구성 변경이다. 입력은 가상 상품 무게이며, 사람의 판단이나 모델 라우팅을 비교하지 않는다.

- A: 서버 버전 고정, 하위 패키지 1.x 허용. B: 전체 버전·파일 해시 고정 후 직접 실행.
- 로컬 저장소 1.0 기준 설치 후 소수부를 버리는 오류를 의도적으로 넣은 테스트용 1.1 추가(0.5 kg → 0 g). OS·런타임·패키지 관리자·입력은 고정.
- 12개 최종 입력: kg 4, g 4, 잘못된 단위 2, 누락 2. 조정 데이터와 분리.
- 네 조건 × 3회. 해시 불일치 조건은 격리된 재설치 검사에서 차단하며 업무 요청 미실행.
- B의 재시작 3회마다 구성 차이 0, 기대 상태 12/12. 해시 불일치 3/3 차단. A 재설치에서 변경 선택이 재현되지 않으면 조건 오류부터 확인.
- 목록 일치, 배포 파일 해시, 설치 파일 비교, 출력의 의미 일치를 별개로 기록한다.
- 실제 구현·설치·모델 호출·벤치마크를 수행하지 않았다. 기사 속 표와 도식은 기대 상태를 표현한 정적 설명이다.
