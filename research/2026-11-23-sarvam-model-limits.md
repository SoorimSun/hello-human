# 일반뉴스 56호 조사 기록

발행일과 확인일은 2026년 11월 23일(한국시간)이다. Sarvam 발표문과 OpenAI 에세이에 적힌 날짜는 모두 11월 22일이다. 두 원문의 정확한 게시 시각을 같은 시간대에서 대조하지 않아 초안의 ‘최근 24시간’은 쓰지 않았다. [기사](../news/2026-11-23-sarvam-model-limits.html) · [미디어 출처와 확인 범위](../assets/news/sarvam-model-limits-media.md)

## Sarvam의 가중치 교체

기사 첫 장면은 사르밤이 골라 공개한 영어 상담 예시다. 고객이 긴 불만 끝에 잠시 기다려 달라고 하자 사르밤 모델은 기다렸고 GPT-6 Luna는 도구를 호출했다. 힌디어 예시에서는 반대로 짧은 대답을 듣고 상담을 이어 가야 했다. 사르밤은 대화를 이어 갔고 GPT-6 Luna는 연결 상태를 잘못 해석했다. 원문에 실린 두 사례의 설명과 대조했다. ‘잠깐만요’는 영어 ‘hold on’을 옮긴 말이다. 회사가 고른 예시와 헬로우 휴먼이 제안한 가상 배송 상담을 구분했다. [사르밤의 음성 상담 예시](https://www.sarvam.ai/blogs/sarvam-105b-1711#samvaad-voice-agents)

## OpenAI 수석과학자의 제안

파호츠키가 수학 문제의 풀이를 팀 대화방에서 봤다는 대목은 저자 본인의 회고다. 에세이에서는 연구진이 1년 넘게 미해결 수학 문제를 모델에 냈고 성과가 달라진 뒤 오래 고민한 문제들의 해법이 같은 Slack 대화에 잇따라 올라왔다고 설명한다. 기사에서는 이 경험이 사전학습 연구의 가속을 우려하는 그의 전망으로 어떻게 이어졌는지 소개했다. [파호츠키의 연구 에세이](https://openai.com/index/perplexity-and-intelligence/)

| 확인한 항목 | 근거와 기사에 적용한 범위 |
| --- | --- |
| 무엇을 측정했는가 | 파호츠키는 GPT-3.5 이후 OpenAI가 사전학습 진전을 살필 때 쓰는 고정된 내부 코드 평가 자료를 설명했다. 원본 그래프 세로축은 퍼플렉서티에 로그를 취한 값이다. 공식 차트 데이터의 GPT-3.5 0.986, GPT-6.2 Astra 0.761, 별도 내부 모델 0.732를 대조했다. 회사가 공개한 측정이며 외부 서비스의 업무 품질이나 안전성 점수로 환산하지 않았다. [에세이와 각주 2·3](https://openai.com/index/perplexity-and-intelligence/) · [원본 그래프](https://openai.com/index/perplexity-and-intelligence/#base-model-log-perplexity) |
| 개발 한계선 | 여러 지표로 연구소 간 비교 방식을 마련하고, 행동 이해·감시 기술이 합의한 수준에 도달하기 전에는 일정 한계를 넘지 말자는 저자의 제안이다. 기존 CoT 모니터를 이을 기술은 저자가 든 예다. 특정 수치를 채택하거나 적용 일정을 결정한 공동 합의는 이 글에 없다. [제안 원문](https://openai.com/index/perplexity-and-intelligence/) |
| 전망과 한계 | 0.68~0.70은 새 능력이 나타날 가능성을 저자가 짚은 로그 퍼플렉서티 구간이다. 2027년도 사전학습 연구 가속이 가능하다고 본 이른 시점이다. 연구소별 데이터 차이, 개별 과업과의 거리, 사전학습 이후의 추론 능력 변화를 반영하지 못하는 점을 기사에서 설명했다. [에세이 후반부](https://openai.com/index/perplexity-and-intelligence/) |

한국어 주소는 확인 시 영문 원문으로 이동했다. 초안의 샘 올트먼 지지 발언은 해당 X 게시물 본문에 접근할 수 없어 제외하고 저자 본인의 제안에 초점을 뒀다. 11월 23일까지 찾아본 두 기관의 공개 자료에서 이 제안을 시행하기로 한 후속 합의나 위 점수 차이에 대한 정정은 확인하지 못했다.

## 모임 실험의 범위

가상 상담 40건과 버전별 세 번 반복은 편집부가 제안한 설계다. 55호는 취소 재전송에 따른 쿠폰 중복 복구, 54호는 월경계·중복 통지를 반영한 정산, 51호는 쿠폰 정책 테스트와 모델 비용을 다뤘다. 이번에는 모델 교체 뒤 같은 문의에서 도구 선택이 달라지는지, 그 시도를 외부 정책이 막았는지를 실행 기록으로 대조한다. 정답을 세 번 모두 만족한 상담 수, 이전 성공에서 새 실패로 바뀐 상담, 금지된 호출 시도와 검토 시간을 따로 본다. 실제 고객 자료나 API를 사용하지 않았고 모델 벤치마크와 상담 실험을 직접 수행하지 않았다.
