## 요약의 확인 범위

이 호는 기존 기사의 안내서다. 각 기사 본문과 요약에 근거해 1~2문장으로 소개하며, 외부 소식 전체를 10월 13일 기준으로 다시 조사했다고 표시하지 않는다. 독자는 연결된 원문에서 개별 확인 시점과 근거를 볼 수 있다.

추천 문장의 범위를 확인하기 위해 다음 원문도 10월 13일 직접 열었다.

- [Claude Code Mods 공식 한국어 문서](https://code.claude.com/docs/ko/plugins/mods/overview): 인터페이스·도구 호출을 확장하는 기능과 공식 샘플을 확인했다. 상태판이 모든 오류를 막아준다고 쓰지 않았다.
- [35mm-studio 제작기](https://shannadige.com/blog/darkroom/): 스캐너 직접 제어 시도 이후 VueScan을 유지하고 스캔 뒤의 처리를 자동화한 경위를 확인했다. 수치와 하드웨어 사고는 추천 문장에 재인용하지 않았다.
- [Google 검색의 AI 기능 안내](https://developers.google.com/search/docs/appearance/ai-features?hl=ko): 기존 SEO 기준, 표시 정보와 구조화 데이터의 일치, 판매자 정보의 현행화 안내를 확인했다. 이를 다른 AI 쇼핑 서비스 전체의 규칙으로 일반화하지 않았다. 상품 검수 도구는 기존 인사이트의 제안으로 소개했다.

## 함께 둘러보는 도시 코너

사용자 요청에 따라 도입부 다음에 사례연구 06과 회원 작업물의 3D 단지뷰·드론 탐험을 함께 소개하는 별도 코너를 추가했다. AI 송도의 시민·기억·관계 관찰과 K-Stock Hub의 건물·지형 기반 공간 탐색을 각각 설명했다. 동일한 서비스이거나 같은 시뮬레이션 구조라고 쓰지 않았다.

- 근거는 [AI 송도 사례연구](../case-studies/2026-10-08-ai-songdo.html), [회원 작업물](../works/choi-taejun.html#k-stock-hub), [K-Stock Hub 기존 조사 기록](2026-10-11-k-stock-hub-showcase.md)이다. 3D 화면을 현장 사진이나 실제 드론 영상으로 표현하지 않았다.
- 기존 `assets/case-studies/songdo-city.jpg`(1536×674, 10월 8일 캡처)와 `assets/works/k-stock-hub-realestate-3d.jpg`(1280×720, 10월 11일 캡처)를 다시 사용했다. 두 이미지를 직접 열어 확인했으며 자르거나 합성하지 않았다. 이미지 전체와 큰 원본 링크, 서비스 출처와 캡처 날짜를 제공한다.
- 원작·권리 기록은 [사례연구 이미지 출처](../assets/case-studies/README.md)와 [작업물 이미지 출처](../assets/works/README.md)를 따른다. 기존 캡처를 최신 화면이라고 표시하지 않았다.
- 사례연구·작업물 소개 및 원래 작업물에 있던 부동산맵·드론 탐험 경로로 연결했다. 코너에 재소개한 항목은 새 글 15편이나 작업물 업데이트 2편에 추가로 세지 않는다.
- 2호 전용 스타일 `assets/newsletter-city-tour.css`를 추가해 데스크톱에서는 두 카드를 나란히, 작은 화면에서는 위아래로 배치한다. 공통 뉴스레터 스타일과 1호는 수정하지 않았다.
- 추가 후 내부 파일·앵커와 외부 링크 속성, 신규 15편의 URL 집합 및 별도 업데이트 2편을 다시 검사했다. 기존 테스트 7개와 `git diff --check`도 통과했다. 브라우저에서 두 이미지 로딩, 두 열에서 한 열로 바뀌는 배치, 라이트·다크 화면과 가로 넘침이 없음을 확인했다.

## 문장 다듬기

사용자 검토 의견에 따라 도입부, 도시 소개, 기사 요약, 실험 안내와 맺음말을 다듬었다. 반복되는 표현과 긴 나열을 줄이고, 추상적인 설명은 독자가 보거나 해볼 수 있는 행동으로 풀었다. 사실관계, 날짜, 수록 편수와 링크는 유지했다. 도시 코너 상단에는 회원 이름을 넣지 않고, 작업물 카드에는 `최태준 회원 작업물` 표시를 유지했다. 홈과 목록의 날짜는 발행일과 수록 기간을 풀어 쓰고, 홈의 창간호 중심 안내는 주간 발행 소개로 바꿨다. 맺음말에는 눈을 잠시 쉬게 하자는 인사를 남겼다.

## 검증

- 분야별 목록에서 추출한 기간 내 원문 URL 집합과 뉴스레터의 분야별 전체 목록을 비교했다. 15편이 일치하며 누락·중복·분야·날짜 불일치가 없다.
- 작업물 업데이트 2편은 별도 섹션에 있으며, 추천 3편은 신규 15편에 포함된다.
- 본문·뉴스레터 목록·홈의 제목, 호수, 발행일, 수록 기간과 편수를 맞췄다. 1호 원문은 수정하지 않았다.
- 변경한 HTML 3개의 내부 파일·앵커 링크, 중복 ID, noindex, 테마·분석·갱신 스크립트, 외부 링크 속성을 확인했다. 글 목록은 HTML에 직접 들어 있어 JavaScript 실행 없이 읽을 수 있다.
- `node --test` 7개 통과, `git diff --check` 통과. 새 HTML의 줄 끝 공백과 엠대시도 검사했다.
- 프로젝트 하위 경로를 포함한 로컬 HTTP 미리보기에서 데스크톱과 좁은 모바일 화면, 라이트·다크 모드, 추천 카드와 본문 배치를 확인했다. 본문 요소의 가로 넘침은 발견되지 않았다.
