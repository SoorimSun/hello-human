# 포자 대청소 웹 테스트 버전 소개 업데이트

확인·수정일은 2026-10-20(한국시간)이다. 기존 `works/jo-minha.html`을 수정하며 최초 소개일 2026-10-16과 URL을 유지한다.

## 요청과 반영 범위

사용자는 앱스토어 미출시 상태에서 제작자가 웹으로 포팅해 서비스를 시작했으며, 웹은 테스트용이라 실제 광고를 붙이지 않았다고 전했다. [웹 서비스](https://play.code404.app/)의 실제 화면과 설명을 작업물 페이지에 반영하도록 요청했다.

상단 도식 중심 구성은 유지한다. 게임 설명 뒤의 기존 홍보 이미지 자리에 실제 웹 화면 세 장을 배치하고, 상단·플랫폼 현황·마무리에서 웹으로 이동할 수 있도록 한다. 홈 카드와 메타 설명도 웹 공개 현황에 맞춘다. 코드 리뷰 내용은 포함하지 않는다.

로컬 페이지 갱신과 검증을 마친 뒤, 사용자가 이번 업데이트의 커밋·푸시를 요청했다. 기존 `main` 브랜치에서 이 업데이트의 변경 파일 8개를 함께 커밋·푸시한다.

## 직접 확인한 웹 동작

- `https://play.code404.app/`의 페이지 제목은 ‘포자 대청소’이며 시작 버튼을 확인했다.
- 별도 계정 로그인 없이 시작 화면과 도입 안내를 거쳐 서울의 숭례문·레벨 선택 화면으로 이동했다.
- 첫 레벨을 열어 규칙 설명과 시작 부스터 선택 화면을 확인했다. 부스터를 선택하지 않고 시작했다.
- 데스크톱 브라우저에서 블록을 드래그해 교환했다. 화면상 남은 이동 횟수가 15에서 14로 줄고 점수가 0에서 390으로 바뀐 것을 확인했다.
- 390×844 모바일 뷰포트에서도 진행 중인 보드가 표시되고, 도시로 돌아가기·나가기·지도·세계 지도 버튼이 동작했다.
- 서울 화면에는 숭례문 0/9 복원, 별 0/36과 12개 레벨이 표시됐다. 세계 지도에는 8개 권역과 다음 권역의 잠금 안내가 표시됐다.
- 촬영용 세션에서 오늘의 선물을 받고, 진행 중인 첫 레벨을 나가면서 가상 생명 1개가 줄었다. 결제·로그인·외부 메시지 전송은 수행하지 않았다.

## 사실의 출처와 경계

| 내용 | 근거 | 페이지 표현 |
| --- | --- | --- |
| 웹버전 공개와 첫 퍼즐 플레이 | 직접 연 웹 서비스와 UI 조작 | 브라우저에서 바로 플레이할 수 있는 웹 테스트 버전 |
| 앱스토어 미출시 | 사용자가 전한 제작자 현황, 2026-10-20 | 아직 앱스토어에는 올라오지 않았음 |
| 웹은 테스트용이며 실제 광고 없음 | 사용자가 전한 제작자 안내 | 제작자 안내에 따르면 실제 광고를 붙이지 않은 테스트용 웹 |
| Swift에서 Kotlin으로 전환한 제작 과정 | 기존 2026-10-16 소개의 공개 코드·기록 | 완료된 전환 과정으로 소개하고 새 Android 배포 상태는 단정하지 않음 |
| 24개 도시·380개 정식 레벨 등 게임 구성 | 기존 소개에서 확인한 공개 저장소 | 기존 수치를 유지하며 웹 전체 레벨을 완주·검증한 것으로 표현하지 않음 |

첫 레벨 일부 조작과 화면 이동을 확인했으며 레벨 클리어, 별 사용에 따른 복원, 전체 도시와 레벨, 진행 저장·동기화는 이번 확인 범위가 아니다. 웹 구현 언어·프레임워크나 앱스토어 심사 상태는 추가로 추정하지 않았다. 광고 SDK·통신 감사를 수행한 것이 아니므로 ‘실제 광고 없음’은 제작자 안내로 귀속한다.

## 검증

- `node --test`: 기존 콘텐츠 업데이트 동작 테스트 7개 통과.
- `works/jo-minha.html`과 `index.html`: HTML 태그 짝, 중복 ID 없음(각 10개·16개), 로컬 리소스·링크·앵커 67개 확인.
- 새 이미지 3개: JPEG 유효성, 390×844 크기, 대체 텍스트·명시적 크기·원본 확대 링크 확인. 브라우저에서 세 장 모두 로드되고 원본 비율을 유지한다.
- 데스크톱에서는 도식이 앞에 유지되고 실제 화면이 3열로 표시된다. 모바일 390px·320px 뷰포트 설정에서는 1열이며 가로 넘침이 없다. 브라우저 확대가 적용된 실제 CSS 너비 291px에서도 확인했다.
- 라이트·다크 모드에서 갤러리와 웹 공개 현황을 확인했다. 모바일의 ‘실제 화면 보기’ 이동 시 고정 메뉴에 제목이 가려지는 문제를 전용 CSS의 스크롤 여백으로 보정했다. 최종 확인에서 섹션 상단 약 128px, 메뉴 하단 약 111px으로 제목이 보인다.
- ‘웹에서 플레이’를 실제 클릭해 새 탭의 `https://play.code404.app/` 시작 버튼을 확인했다. 홈 회원 작업물 카드에서 소개 페이지로 이동하는 것도 확인했다.
- 루트 경로와 GitHub Pages용 `/hello-human/` 경로에서 소개 페이지·이미지·홈 연결을 확인했다.
- `git diff --check`: 공백 오류 없음. 공통 CSS·JavaScript, 이전 분석·코드 리뷰 문서는 수정하지 않았다.
- 임시 뷰포트 설정을 해제하고 라이트 모드로 되돌렸다. 로컬 미리보기 탭을 남겼다.
