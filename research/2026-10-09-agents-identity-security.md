## 시각화와 편집 변경

- 원본 제품 화면 대신 설명용 신원 흐름도, 가상 지표 정의, 자체 집계 수치 카드, 97건 평가 막대, 모임 운영 흐름을 사용했다. 실제 UI나 시험 결과로 표시하지 않는다.
- 정책 일정 타임라인은 사용자의 검토 의견에 따라 제거했다. 발표일(10월 8일)과 시행일(11월 12일)은 본문 한 문장에 남겼고, 기사 확인일(10월 9일)은 기존 확인 기준 안내에서 구분한다. 전용 타임라인 CSS도 정리했다.
- 타임라인 제거 후 `node --test` 7개와 `git diff --check`를 통과했다. 데스크톱·390px 모바일에서 타임라인 없이 문단이 이어지고 가로 넘침이 없음을 확인했다.
- 막대는 동일 평가 안의 85:11:1 구분만 표현한다. 색 외에 건수와 판정 설명을 모두 텍스트로 제공한다.
- 이전 6개월 집계와 초기 97건 평가를 별도 그림으로 나눴다. 미검토 후보를 오탐으로 계산하거나, 약 6,000건을 유효 판정으로 처리하지 않는다.
- 초안의 ‘보안 검사는 AI가 맡는다’를 ‘취약점 후보를 찾는다’로 바꿔 제목에서 검증이 끝났다는 오해를 줄였다.
- 일반 서비스 계정은 실행 주체를 구분하기 어렵다는 포괄적 비교는 제외했다. 구체적인 신규 계정·권한·기록 기능에 집중했다.
- 마지막 단계에만 Human Approval을 둔 직선 도식을 수정해, 권한·필요 승인 확인을 실행 전으로 옮기고 결과 검증을 실행 후로 구분했다.
- 실험 제안은 설치 가이드로 확장하지 않고 검토 과정과 측정 항목 중심으로 줄였다.
- 사용자의 추가 요청에 따라 Google Cloud 공식 발표의 Gemini at Work 2026 행사 이미지를 상단 썸네일과 공유 대표 이미지로 등록했다. 원본은 `assets/news/gemini-at-work-2026-official.jpg`, 출처·가공·이용 조건 기록은 `assets/news/agents-identity-security-media.md`에 남겼다.
- README와 파일 구성 문서는 개별 기사마다 목록을 늘리지 않는 현재 저장소 지침에 따라 유지했다.

## 검증 기록

### 멤버 가독성 편집 · 2026-10-09

- 사용자의 문장 다듬기 요청에 따라 제목을 ‘회사 계정으로 일하는 AI, 보안 점검을 돕는 AI’로 정리하고 홈·목록·공유 메타데이터에 맞췄다.
- ‘신원·수행 주체’는 계정과 작업한 이름으로 풀고, 에이전트·토큰·샌드박스·취약점 후보·위협 모델·회귀 테스트는 쉬운 설명을 앞세웠다. 긴 문단은 개념별로 나누고 소식 사이에 연결 문장을 더했다.
- 모임 관점은 맡길 일·허용 범위·완료 기준 중심으로 정리했다. 실험은 개발에 익숙한 멤버와 함께 보안 보고서를 검토하는 제안으로 설명했다.
- 발표사 주장과 모임 해석, 무료 검사 대상, 초기 기능의 제공 범위, 수치의 평가 조건, 11월 12일 정책 시행일은 유지했다. 문장 편집 작업이며 추가 조사나 제품 시험을 수행한 것으로 기록하지 않는다.
- 검증: `node --test` 7개 통과, `git diff --check` 통과. 제목·소개 문구의 기사/홈/목록 일치, 기존 출처 URL·이미지·스크립트·본문 ID 유지, 내부 앵커와 파일 경로, 주요 수치·정책 시행일을 확인했다. 데스크톱과 390px 모바일의 본문·도식 및 라이트·다크 표시를 확인했고 가로 넘침은 없었다. 커밋·푸시·배포하지 않았다.

### 기사 작성·썸네일 추가 검증

- `node --test`: 기존 테스트 7개 통과, 실패 0개. 기사 사실 검증과 별개인 콘텐츠 갱신 상태 테스트다.
- `git diff --check`: 통과. 신규 파일 세 개의 줄 끝 공백도 별도 확인했다. 새 JavaScript는 없다.
- 정적 검사: 기사·목록·홈의 로컬 경로, 중복 ID, 내부 앵커, noindex, 제목 일치 확인. 전체 18편 = 일반뉴스 11편 + 속보·단신 7편, 새 기사 링크 1개.
- 브라우저: `/hello-human/` 프로젝트 접두 경로에서 기사·목록·홈을 실제 열었다. 1280px 데스크톱, 390px·320px 모바일 화면과 라이트·다크 모드를 확인했다. 수치 그림·세로 흐름도·한글 줄바꿈에 가로 넘침 없음.
- 모바일 목차: 공통 스크롤 여백이 겹쳐 이전 절이 강조되는 현상을 발견했다. 새 기사 전용 CSS에서 여백을 조정했고, 보안 검사 목차 선택 후 절 상단 약 136px·현재 목차 일치를 확인했다. 공통 파일은 수정하지 않았다.
- 필터: 일반뉴스 11개, 단신 7개, 전체 18개. 키보드 왼쪽 방향키 전환 확인. 필터를 바꿔도 목록 총 18개, 새 기사 1개 유지.
- 갱신 표시: 기사 열기·테마 전환·목차 이동·목록 복귀·필터 변경·새로고침 뒤 새 글 링크에 잘못된 New/Updated가 재표시되지 않음을 확인했다.
- 홈 최신 일반뉴스의 11호·10월 9일·제목·링크를 확인했다. 기존 단신 07 카드는 유지했다.
