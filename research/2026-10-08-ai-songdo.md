## 초안에서 보강한 사항

- 초안에는 사이트와 프롬프트를 독립 확인하지 못했다고 적혀 있었다. 이번 작업에서는 실제 화면·공식 설명·개별 장면을 확인해 확인 범위를 수정했다.
- 공개된 ‘차례 대화에서 말할 때’ 프롬프트는 text와 inner를 함께 작성하게 한다. 속말을 모델의 비공개 내부 추론으로 설명하지 않았다.
- 공식 설명에는 모델별 균형 노출, 유사 장면 접기, 거래·속임수·폭로 장면 우선 배치가 있다. 관람용 사건 선택이 평가 표본과 같지 않다는 해석을 추가했다.
- 초안의 사건 맥락·실행 결과 화면 제안 중 일부는 이미 제공된다. 오늘의 변화·장면별 결과는 직접 확인한 기능으로, 장기 이력과 차단 사유를 연결하는 전체 흐름은 추가 제안으로 구분했다.
- 단일 에이전트 기준선과 역할을 나눈 처리를 동일 입력으로 비교하는 작은 실험을 제안했다. 실제 실행한 실험이 아니다.
- 시즌 종료일은 제작자 원문·화면의 10/24 안내에 따른 2026-10-24. 화면 D-15 표시는 서비스 계산을 재현하지 않고 사용하지 않았다.

## 물류·풀필먼트까지 분석 확장

- 같은 날 후속 요청에 따라 기존 글에 풀필먼트 역할과 별도 9절을 추가했습니다. 실험 제안은 10절로 옮겼고 홈·목록·부제·설명·목차를 함께 맞췄습니다.
- [풀필먼트 조사 기록](2026-10-08-fulfillment-agent-sandbox.md)의 E-Commerce Bench를 출고·반품을 포함한 LLM 운영 환경으로, Mega/KION을 물리 창고·로봇 검증과의 비교점으로 사용했습니다. 한국어 공식 자료가 확인된 NVIDIA·Shopify는 한국어 링크를 본문에 넣었습니다.
- E-Commerce Bench의 출고 기한과 반품은 해당 연구의 모형으로 소개했습니다. 본문 속 창고 처리량과 검수 판정은 헬로우 휴먼이 추가한 실험 조건이며 해당 벤치마크가 구현했다고 쓰지 않았습니다.
- 네 역할 팀의 공동 목표를 판매·배송·반품까지의 약속 이행과 전체 처리비용으로 확장했습니다. 단일·세 역할·네 역할 비교 시 같은 업무 범위를 주도록, 세 역할 팀에서는 기획자가 물류 조정도 맡게 했습니다.
- 예시 수량은 A센터 보유 300개 = 기존 주문 할당 180개 + 판매 가능 120개. 남은 출고 가능량은 별도 단위인 주문 120건이며, 주문마다 상품 1개라는 가정 아래 미처리 60건을 찾습니다. B센터의 재고·처리량·수락과 기존 작업 취소 확인이 있어야 재배정합니다.
- 취소 대기, 배송 지연, 일부 수량 부족, 중복 알림, 반품 중 2개 파손을 추가했습니다. 회수·검수·판매 재고 복구·환불은 별도 상태로 기록하고, 반품 검수를 환불의 보편적 선행 조건으로 규정하지 않았습니다.

## 커머스 역할 실험 관점 확장

같은 날 사용자가 MD·마케터·기획자 에이전트를 만들기 전 실험 환경이라는 관점으로 선행 사례 조사와 본문 확장을 요청했습니다. 기존 사례연구의 7~9절에 반영했고 홈·목록 요약도 함께 바꿨습니다. 푸시하지 않는 지시는 유지합니다.

- 상세 근거는 [커머스 실험 환경 조사 기록](2026-10-08-commerce-agent-sandbox.md)에 모았습니다.
- Magentic Marketplace는 정보·제안 순서, Vending-Bench와 Project Vend는 장기 운영과 역할별 지표, τ-bench는 정책·도구·최종 상태 검증의 근거로 사용했습니다. 원 연구의 결과와 헬로우 휴먼의 적용 제안을 구분했습니다.
- MD·마케터·기획자 팀의 사전 실험과 실제 커머스 성과를 함께 검증한 사례는 이번 조사에서 직접 확인하지 못했습니다. 본문의 역할 구성과 기획전 시나리오는 설계 제안입니다.
- 가상 상품 30개와 대표 상품 재고 120→40개는 설명용 설정입니다. 가용 재고 100개 이상 및 승인 후 조건 변경 시 재검토라는 실험 규칙을 명시했습니다. 실험 환경 구현·실행은 하지 않았습니다.
- 정책 위반, 예산 초과, 잘못된 집행, 인수인계 누락을 관찰하고 기존 절차·단일 에이전트·역할 팀을 같은 과제로 비교하도록 제안했습니다. 가상 고객의 반응을 실제 구매율로 사용하지 않습니다.
- Agent4Rec·ACES도 조사했지만 본문은 세 가지 핵심 축으로 묶어 길이를 조절했습니다. 각 연구의 추가 근거와 한계는 상세 기록에 남겼습니다.

- 그림을 각 사례의 첫 설명 뒤에 두고 한국어 핵심 해설과 출처·확대 링크를 붙였습니다. Vending-Bench와 Project Vend는 각각 별도 그림을 사용합니다.
- τ-bench 원본의 오른쪽은 항공 예약 사례이므로 주문 처리 그림처럼 오해하지 않도록 캡션에 명시했습니다. E-Commerce Bench의 overview.png는 논문 Figure 3이며 결과 순위 그래프가 아닙니다.

- 기억 절 목차와 법 효과 앵커 이동, 본문 → 목록 → 새로고침 → 본문 이동을 확인했다. 목록 카드에 잘못된 `Updated`가 다시 붙지 않았다. 검증 후 임시 뷰포트를 해제하고 원래 다크 모드로 복원했다.
- `git diff --check` 오류 없음. 최종 변경은 본문·사례연구 목록·이 조사 기록의 3개 파일이다. 커밋·푸시·배포하지 않았다.

### 시즌 소식과 기존 흐름 연결, 반복 설명 정리

같은 날 사용자 요청에 따라 새 자료를 추가 조사하지 않고, 확보한 근거와 현재 원고를 대조해 문장과 배치를 다듬었다.

- 도입은 취업과 기억 표결을 시즌 1의 두 사건으로 함께 소개하고 시즌 2로 이어지게 정리했다. 시작 날짜는 기억 절, 우승 소식은 리그 절에 남겨 반복을 줄였다.
- 기억 절의 옛 예상 보존율은 리그 절로 옮겨 시즌 1 예상치·우승 보고·시즌 2 예상치를 함께 읽도록 했다. 기억 절에서는 규칙과 표결, 비용과 동기 해석에 집중하고, 이전 시점의 취업 사례로 돌아간다는 연결 문장을 넣었다.
- 투표자가 전후 값을 받았다는 설명은 투표 집계에, JSON 포함 여부·프롬프트 전문 미확인과 제작자의 안내 수정은 실행 절에 모았다. 동기와 수정 효과가 검증되지 않았다는 조건을 유지했다.
- 기본소득이 지급 총액이라는 설명은 표 머리글에 남겼다. 가상 화폐 ‘송’의 설명은 처음 비용이 나오는 기억 절로 옮겼다. 정규식 결과와 쿠폰 실험의 반복 설명을 줄이고 마지막 실험으로 연결했다.
- 쪽지 안내는 기존 사건 화면의 구체적 예시 뒤로 옮겼다. 기존 예시가 쪽지 기능의 실행 결과처럼 읽히지 않게 했으며, 전송·반응 미시험 표시는 유지했다.
- 편집 직전 사본과 대조해 숫자·단위의 고유 값, 외부 출처 URL 집합, 모든 ID, 헤더·메타데이터와 이미지·영상 속성이 유지됐는지 확인했다. 8절 이후는 변경하지 않았고 제목·목록·스타일·스크립트도 이번에는 수정하지 않았다.
- 로컬 링크·자산 참조 128개에 누락이 없고, 목차 11개와 본문 절의 순서가 일치한다. `git diff --check` 오류 없음. 문구·배치 편집이므로 기능 테스트는 다시 실행하지 않았다. 열려 있는 `file://` 화면은 브라우저 도구의 URL 정책으로 접근이 차단되어 이번 화면 검증은 수행하지 못했다.
- 이번 수정 파일은 본문과 이 조사 기록이다. 앞선 목록 변경은 유지했고 커밋·푸시·배포하지 않았다.

### 로컬 서버로 PC·모바일 화면 재검증

- 사용자 요청에 따라 `127.0.0.1`에만 연결되는 임시 정적 서버를 띄우고 최신 원고를 브라우저에서 확인했다. PC 1,440×1,000px, 모바일 390×844px와 320×844px 뷰포트로 검사했으며 실제 휴대기기 검사는 아니다.
- 각 화면에서 문서 폭과 스크롤 폭이 각각 1,425px, 375px, 305px로 같아 페이지 전체의 가로 넘침이 없었다. 제목·본문 줄바꿈, 기억 도식의 모바일 세로 배치, 라이트·다크 모드의 표 가독성을 확인했다. 모바일의 490px 표 내용은 내부 가로 스크롤로 표시되고 키보드 오른쪽 화살표로도 이동했다.
- 모바일 앵커 이동 후 목차가 이전 절을 선택한 채 남는 문제를 발견했다. 공통 모바일 여백 108px와 상단 스크롤 여백 72px의 합이 목차의 현재 절 판정선 160px보다 커서 생겼다. 송도 전용 CSS에서 모바일 절 이동 여백을 84px로 조정하고 본문의 CSS 참조 버전을 5로 올렸다. 공통 CSS와 목차 스크립트는 변경하지 않았다.
- 수정 후 320px 화면의 기억 절과 390px 화면의 기억·마지막 실험 절로 새로 이동해 제목이 상단 약 156px에 표시되고 목차의 현재 절도 일치하는지 확인했다. 본문에서 목록으로 돌아갔다가 다시 여는 동작과 마지막 실험으로 연결되는 본문 링크도 확인했다.
- CSS 수정 후 `node --test` 71개 통과, 실패 0개. 로컬 링크·자산 참조 128개 누락 없음, 중복 ID 없음, 목차 11개 순서와 본문·목록 제목 일치. 기존 이미지 7개·영상 1개의 참조는 유지했으며 영상 재생은 이번에도 다시 시험하지 않았다.
- 기존 본문·목록·조사 기록 변경에 송도 전용 CSS 수정이 더해져 현재 변경 파일은 4개다. 로컬 미리보기 서버는 사용자가 확인할 수 있도록 유지하며 커밋·푸시·배포하지 않았다.

### 후속 배포 승인과 커밋 전 확인

- 같은 날 사용자가 위 4개 파일의 커밋·푸시와 배포 확인을 명시적으로 요청했다. 앞선 푸시 보류는 이 후속 요청으로 해제됐다.
