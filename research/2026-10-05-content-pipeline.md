# 한 시간의 라이브를 30초 숏폼으로, AI는 어디까지 맡을까?

- 글: `insights/2026-10-05-content-pipeline.html`, COMMERCE INSIGHT 04
- 발행일·공개 자료 확인일: 2026-10-05, 한국시간. 기존 URL·호수·날짜 유지.
- 업무 질문: 홈쇼핑·티커머스의 콘텐츠 PD는 긴 판매방송에서 어떤 장면을 찾아 숏폼으로 만들고, 무엇을 확인한 뒤 다시 게시할 수 있는가?
- 범위: 방송 재편집 사례, 영상 이해·탐색, 세로 구도와 자막, 만료된 방송 혜택, 작업시간·완성 품질 검증.
- 가상 사례: 60분 유리 밀폐용기 방송을 시연형·질문형으로 재편집하고 만료된 쿠폰 구간은 보류. 상품·시간·조건은 설명용 가정이며 실제 생성 결과가 아님.
- 자료 선택: 설명문 생성·이메일 실험을 숏폼 자동화의 근거로 삼았던 이전 구성을 교체. 아래 자료는 모두 영상 제작·이해·편집 또는 해당 게시 채널과 직접 관련됨.
- 공개 범위: 개인 대화 URL, 내부 자료, 비공개 고객·기업·사업 정보를 포함하지 않음.

## 1. 신세계라이브쇼핑: 방송에서 AI 숏츠로

- 공식 발표: https://www.shinsegaegroupnewsroom.com/new-era-live-shopping-ai/
- 공개일: 2024-07-09. 공식 본문 직접 확인.
- 확인한 내용: 20~60분 판매방송을 1분으로 요약. 장면·멘트 분석과 대표 화면 선정, 비율 변환, 배경·자막 작업. 도입 당시 하루 약 10편 제작.
- 사용할 표현: 티커머스에서 긴 방송을 짧은 모바일 콘텐츠로 바꾼 공개 도입 사례.
- 한계: 발표 당시 수치이며 현재 처리량·제작시간 절감률·무검수 게시 비율·매출 효과가 아님.
- 공식 소개 영상 페이지: https://www.shinsegaegroupnewsroom.com/new-world-live-shopping-app/ (2024-08-06)
- 페이지에 삽입된 원본: https://www.youtube.com/watch?v=3cUPp9cMlFI
- 영상 확인: 공식 페이지의 플레이어를 직접 재생해 AI 서비스 이용 화면 확인. AI 숏츠·방송 요약 등 서비스 홍보 영상으로 설명. 편집 엔진의 정확도 검증 영상으로 표현하지 않음.
- 이용 방식: 원본 공식 YouTube 플레이어 삽입, 출처·공개일·성격 명시, 자동 재생 없음. 영상·섬네일을 내려받아 재가공하지 않음.
- 참고 정책: https://www.shinsegaegroupnewsroom.com/policy/ (직접 확인)

## 2. 현대홈쇼핑: TV·모바일 라이브를 H몰 숏딜로

- 공식 그룹 웹진: https://together.ehyundai.com/vol029/sub0103_w5.html?code=0103
- 확인한 내용: 평균 60분의 TV·모바일 라이브 방송에서 높은 시청률 구간을 분석해 1분 이내 상품 숏폼 제작. 스타일링·조리 같은 핵심 정보를 다루며, 당시 매주 최대 100개 소개 계획.
- 사용할 표현: 판매방송에서 상품을 이해할 핵심 장면을 골라 짧게 재사용한 도입 사례.
- 날짜 주의: 본문은 8월 5주 기사이나 명확한 발행연도 미표시. 공통 상단의 최신 호 날짜(접속 시 2026년 5월)를 이 기사의 발표일로 오인하지 않음. 본문에는 최신 2026년 도입이라고 쓰지 않음.
- 한계: 최대 소개 물량은 처리 성능·실제 평균 제작량이 아님. 무인 제작·매출 상승을 입증하지 않음.

## 3. GS SHOP·AWS: 영상 구간 검색과 추천

- 공식 기술 사례: https://aws.amazon.com/ko/blogs/tech/gs-shop-ai-powered-video-recommendation-platform/
- 공개일: 2026-05-15. 본문 직접 확인.
- 확인 위치: 수작업의 한계, 영상 검색 데모, 추천 실험, 향후 계획.
- 확인한 내용: PD가 시연 장면을 찾고 오래된 카드 혜택·라이브 한정 멘트를 제거하는 작업. TwelveLabs 기반으로 자연어 영상 검색과 영상 이해를 구현하고 상품 소구점 추출·추천에 활용.
- 사용할 표현: 화면·음성·글자를 함께 이해하는 방식은 대본의 단어 검색만으로 찾기 어려운 시연 구간 탐색에 쓰일 수 있음.
- 결정적 한계: 당시 숏픽 영상은 사람이 제작한다고 본문에 명시. 영상 자동 재생성은 향후 계획. 완전 자동 제작 사례로 분류하지 않음.
- 수치: 같은 기간·영역에서 추천 트래픽을 50:50으로 나눈 실험의 총주문고객수 57.5% 증가. AI 자동 편집 효과나 전체 회사 매출 증가로 표현하지 않음.
- 본문에서 이 수치는 제작 성과와 추천 성과를 구분하는 예로만 사용.

- 현재 제품 설명: https://www.opus.pro/clipanything
- 공식 출시 소개 영상: https://www.youtube.com/watch?v=F5pfPDEvWsg (2024-08-07, OpusClip)
- 확인한 내용: 영상과 자연어 요청으로 구간을 찾고 클립을 구성. 시각·소리·대화 단서를 활용하며 화면 비율 변환 기능 안내.
- 사용할 표현: 방송에서 특정 제품 동작을 찾는 방식에 적용해 볼 수 있는 공개 도구.
- 한계: 한국어 홈쇼핑 영상에서의 검출·편집 정확도를 시험하지 않음. 제품의 품질 주장·바이럴 점수를 구매 전환의 근거로 쓰지 않음.
- 미디어: 공식 소개 영상 플레이어와 원본 링크, 날짜·성격·적용 한계 표시. 출시 영상의 공개일과 현재 기능 문서를 분리함.

## 6. 네이버 쇼핑라이브: 표현과 노출 관리의 실제 제약

- 사용할 표현: 생성한 시연을 실제 사용 증거로 혼동시키지 않아야 함. 네이버의 정책이며 전 채널에 동일한 법적 의무라고 일반화하지 않음.

- 사용할 표현: 영상 파일·게시 위치를 연결하고 채널별 중단 방법을 확인해야 함.
- 한계: 실제 계정의 관리 화면 조작·업로드·삭제 API는 실행하지 않음. 도움말의 갱신일은 명시되지 않음.

## 편집과 설계 판단

- 원본 타임라인 → 시연형·질문형·보류 후보, 30초 구성표, 얼굴 중심 자르기와 제품 시연을 보존하는 재배치 비교는 직접 만든 HTML/CSS·SVG 설명도.
- 위 도식은 실제 방송 화면·제품 인터페이스·AI 출력물이 아니며 각각 가상 예시로 표시.
- 방송·발췌 구간·상품·옵션·혜택·게시 위치를 연결하고 변경된 조건을 확인하는 흐름은 헬로우 휴먼의 제안.
- 방송 10편은 업무 점검 범위의 가정. 같은 원본·완성 기준, 편집자·순서 교차 배정으로 중복 시청 학습 효과를 줄이는 비교 제안.
- 작업시간은 찾기·편집·수정·검수까지 포함. 비용 분모는 검수를 통과한 숏폼 수. 폐기 후보의 비용도 분자에 포함하고 0편이면 계산하지 않음. 개발·연동·유지보수는 별도 합산.
- 클릭·조회·추천 실험의 결과를 제작시간 단축이나 자동 편집의 매출 효과로 바꾸지 않음. 실제 도구 실행·생성·게시·고객 실험은 수행하지 않았음.
- 기존 URL·04호·발행일을 유지하고 홈·인사이트 목록의 제목·요약을 같은 내용으로 수정.
- 이번 수정의 완료 범위는 로컬 결과물. 커밋·푸시·배포 없음.

## 사이트 검증

- 로컬 브라우저 1440px 데스크톱·390px 모바일, 라이트·다크 확인. 가로 넘침 없음. 모바일 타임라인·결과 카드는 한 열, 30초 구성표는 두 열로 표시.
- 본문에 삽입한 신세계·OpusClip 공식 플레이어를 각각 클릭해 실제 시간 진행 확인. 자동 재생 없이 시작하며 원본 링크도 제공. OpusClip은 57초 출시 소개 영상으로, 기능을 직접 실행한 검증과 구분.
- 홈·목록·본문의 제목·04호·날짜, 목록 총 4편, 해당 글 링크 각 1개 확인. 목차 이동, 상대 자산·링크 존재, 중복 id와 HTML 태그 대응 검사 통과.
- 본문 열기·영상 재생·테마 전환 → 목록 복귀 → 새로고침 뒤 불필요한 Updated 표시가 없음을 확인. 홈의 최신 카드로 본문 재진입 확인.
- `node --test` 기존 7개 통과. `git diff --check` 통과. 브라우저 콘솔 오류 미검출.
- 새 JavaScript·AI 실행·외부 게시 연동은 추가하지 않음. 외부 영상의 향후 가용성과 실제 AI 도구의 한국어 방송 정확도는 보장하지 않음.
