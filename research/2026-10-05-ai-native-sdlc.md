## 시각 자료

- 원문 본문에서 병목, 순환, 도입 의존 관계에 관한 이미지 참조 3개와 비교표의 내용을 확인.
- 원문 이미지 CDN은 웹 도구에서 열기 실패 후 Browser 도구에서 사이트 보안 정책으로 접근 차단됨. 다른 도구로 우회 다운로드하지 않았고, 원본 이미지를 보거나 복제했다고 표시하지 않음.
- 가이드에는 원문 페이지를 연결하고 비교표의 짧은 요약을 사용. 원본 래스터 이미지의 재사용은 하지 않음.
- 자체 제작: 시간 계산기, 6단계 순환도, 역할 카드, 예외 상황 표, 검증표, 배포 경로, 운영 예시, 90분 실습, 체크리스트.
- 계산기는 사용자 피드백에 따라 구현만 조절하는 예시에서 전 과정 비교로 확장. 기획·설계·구현·검증·배포·운영의 개선 배율을 독립적으로 조절하며, 기준 시간은 [2, 2, 4, 3, 1, 2]시간으로 총 14시간. 운영은 특정 피드백 한 건을 진단·정리하는 작업 시간으로 한정. 운영 기간 전체를 개발 시간에 합산하지 않음.
- 구현만 개선한 비교는 10 + 4/구현배율, 전 과정은 Σ(단계별 기준 시간/단계별 배율). 동일한 구현 배율을 사용하므로 다른 단계 개선의 차이를 볼 수 있음. 기본 예시 [2, 2, 4, 2, 2, 2]배는 각각 11시간과 6시간이며 추가 절약 5시간. 기준 대비 전 과정 시간 감소율은 57%(반올림). 모든 숫자는 설명용 가정이며 실측·원문 수치·벤치마크가 아님.
- 시간만 비교하는 단순 모형으로 같은 품질과 범위를 가정하며 외부 승인 대기, 병렬화, 재작업을 제외. 실제 도입 성과는 품질·재작업·운영 안정성도 확인하도록 설명.
- 다운로드 `assets/guides/ai-native-sdlc/practice-kit.txt`는 헬로우 휴먼 자체 템플릿이며 원문 예제의 번역/복제가 아님.

## 독자와 실습 범위

- 독자는 개발자뿐 아니라 기획·운영 멤버까지 포함.
- 가상의 정원 20명 모임 기능을 설계 예제로 사용. 실제 사내 시스템이나 개인정보 없음.
- 전체 설계 예제와 90분 실습의 구현 범위를 구분. 첫 실습은 가상 데이터 로컬 화면만을 대상으로 하며, 서버·인증·동시성은 미구현이면 미검증으로 남기도록 명시.
- 실습 시간은 편집 제안이고 성능 보장 아님. 제품 가격·최신 모델·보안 스캔 성능 등 불필요한 원문 주장은 재인용하지 않음.
- 커밋·푸시·배포 없음. 가이드 목록과 홈의 최신 가이드 진입점은 로컬에서 함께 반영.

## 실제 수행한 검증

- `node --test`: 저장소 기존 테스트 7개 통과.
- `node --check assets/guide-sdlc.js`: 문법 확인 통과.
- `git diff --check`: 공백 오류 없음. 기존 파일의 LF/CRLF 변환 안내만 있음.
- 신규 HTML의 로컬 링크·자산 21개 존재, 중복 ID 없음, 목차 앵커 모두 유효, noindex 확인.
- Browser로 1280px 데스크톱, 390px 모바일 및 라이트/다크 테마 확인. 전체 페이지 가로 넘침 없음. 작은 화면의 표는 내부 가로 스크롤과 안내문 사용.
- 전 과정 계산기 기본 예시: 구현만 11시간, 전 과정 6시간, 감소율 57%, 추가 절약 5시간 확인. 모두 1배: 두 비교 모두 14시간/0%, 모두 10배: 구현만 10.4시간, 전 과정 1.4시간/90%, 추가 절약 9시간 확인.
- 각 단계만 1배로 되돌려 해당 단계가 독립적으로 반영되는지 확인: 기획 7h, 설계 7h, 구현 9h, 검증 7.5h, 배포 6.5h, 운영 7h. 구현 이외의 입력은 '구현만 개선' 비교값을 바꾸지 않음.
- 체크리스트 6/6 및 해제 후 5/6, 프롬프트 펼침, 가이드 목록과 홈 진입점 확인.
- 계산기 조작 후 목록 복귀 및 새로고침에서 불필요한 Updated 표시가 생기지 않음.
- 원문 이미지 CDN 차단은 해결하지 않았으며 원본 이미지 재사용은 검증 범위에 포함하지 않음.

- 후속 시각화: 기획 → 설계 → 구현 → 검증 → 배포 → 운영 → 기획의 순환도를 추가. 각 단계의 AI 작업·사람 판단·산출물을 구분하고, 검증 실패와 운영 피드백의 복귀 경로를 표시. 헬로우 휴먼의 자체 개념도임을 명시.
- 순환도 데스크톱 3열 2행 및 모바일 세로 배치 확인. 390px 모바일에서 페이지와 카드의 가로 넘침 없음, 라이트/다크 테마 확인, 브라우저 콘솔 오류 없음.
