토큰 합계를 다시 계산했다. Astra는 977,494 + 18,176 = 995,670, 캐시 923,776 + 비캐시 53,718 = 977,494이고 캐시 비중은 94.505%다. Sol은 3,367,846 + 27,696 = 3,395,542, 캐시 3,253,376 + 비캐시 114,470 = 3,367,846이고 캐시 비중은 96.601%다. 추론은 출력의 부분집합이라 다시 더하지 않는다.

모델 비용도 보고서 단가로 다시 계산했다. Astra는 53,718×$8 + 923,776×$0.40 + 18,176×$40 (100만 토큰당) = $1.5262944, Sol은 114,470×$2 + 3,253,376×$0.10 + 27,696×$10 = $0.8312376으로 보고서와 같다. 두 보고서 모두 장문 할증 기준(272,000토큰)을 넘은 요청이 없다고 적었다. 단가 자체는 보고서의 확인 결과를 인용했으며 이 기록에서 OpenAI 가격표를 따로 확인하지 않았다.

두 모델은 이미지 생성 도구로 1536×1024 그림 두 장을 만들었다. 이미지 모델과 품질 설정이 기록에 없어 보고서가 각자 추정했는데, Astra 보고서는 GPT-Image-2, Sol 보고서는 Images 2.6을 기준으로 삼아 기준이 다르다. 같은 날 같은 Codex에서 실행했으므로 둘 중 하나는 실제와 다를 수 있다. 어느 쪽이 맞는지 확인하지 않았으므로 표에는 그림 생성비를 뺀 모델 비용만 싣고, 그림 포함 추정액은 기준 차이와 함께 주석에만 둔다. 실제 청구액은 두 보고서 모두 확인되지 않았다.

제작 시간에는 그림 생성과 제작 중 브라우저 확인이 들어 있고, 보고서 작성은 빠져 있다. 두 작업 모두 과제 문구의 폴더명만 바꾸고 단일 HTML 제출, 다른 모델 결과 참고 금지, 브라우저 검증을 따로 안내했다. 보고서의 제작 프롬프트에는 ‘실수는 절대 금물입니다.’가 붙어 있는데, 이 문장은 GPT-6.1 Sol·Terra, Opus 5.5 등 기존 보고서에도 있으므로 공통 프롬프트 표기는 기존대로 둔다.

결과 HTML의 내장 자원은 원본에서 확인했다. Astra는 WebP 그림 3개, woff2 서체 1개(Noto Serif KR 서브셋), Sol은 WebP 그림 2개, woff2 서체 3개를 담고 있다. 카드 소개의 조작(그림책 열기와 세 장면 넘기기, ‘거울로 읽기’, 소리 켬 시 합성 종소리 / 체스판 칸 이동, 꿈 선택 시 그림 좌우 반전)은 배포된 페이지를 Chrome에서 직접 눌러 확인했다.

## 정렬

GPT-6.2 Astra는 최상위 체급, GPT-6.2 Sol은 플래그십 체급에 둔다. 공식 출시일 자료는 찾지 못했다. 다만 Fable 5.2는 2026-11-10에 이미 실행·반영됐고, 웹 검색으로 찾은 2026-11-10 무렵까지의 자료(대부분 블로그·집계 사이트)는 GPT-6.2를 공식 발표 전 모델로 다뤘으며, 두 보고서는 2026-11-18에 OpenAI 공식 단가를 확인했다. 그래서 GPT-6.2가 같은 체급의 기존 모델보다 최근에 나왔다고 보고 각 체급 맨 앞에 두었다. 출시일이 확인되면 순서를 다시 맞춘다.
