## 후속 확인과 편집 판단

- GitHub 연결 도구로 두 릴리스의 본문·발행 메타데이터와 연결 PR을 실제 읽었다. 웹 검색으로 릴리스·관련 수정 자료를 찾고 공식 페이지를 열었다. 검색 결과 요약만으로 확정하지 않았다.
- LobeHub 릴리스의 기본 활성화 표현보다 PR에 자세한 예외가 있어 이를 우선해 보완했다. PR의 검수 여부·성과 수치를 독립 검증으로 승격하지 않았다. Wake records의 woke는 활성화 수이며, 에이전트가 이후 침묵할 수도 있어 답변 수로 번역하지 않았다.
- Paseo 릴리스와 PR의 Linux·Codex 시험 설명은 개발진이 수행한 검증이다. 본 작업에서는 제품을 설치하거나 실험하지 않았고, 보편적인 복구 성공률을 제시하지 않았다.
- 공식 원문의 한국어 전문은 확보하지 못했다. LobeHub 검수 페이지의 일부 UI가 한국어로 표시되지만 검수 내용은 중국어다. 기능 근거는 영문 공식 릴리스·PR에 둔다.
- 초안의 ‘최근 24시간’은 시각이 흐를 때 범위가 달라지므로 실제 릴리스 날짜로 교체했다. LobeHub를 라이선스 정의가 필요한 ‘오픈소스’라고 단정하는 대신 제품명으로 서술했다.
- 예약 지침 안내, favicon·검색 결과 조각, 과도한 개념 정의와 반복 결론을 제거했다. 언어·프레임워크는 지정하지 않았다.

## 실험 설계와 도식의 범위

- 실제로 실행하지 않은 제안이다. 제품 간 기본 연동을 전제하지 않는다. 입력 재생기·작업 기록·모의 저장소는 별도 구현 대상이다.
- 참여 판단: 조정용 6묶음과 독립 평가용 30묶음(미해결 10, 이미 담당자 처리 중 10, 일반 10). 같은 대화·로그·모델·지침에 시작 조건만 변경. 사람이 필요한 건을 찾아 호출하는 시간과 선제적 오개입을 함께 측정.
- 복구: 참여 결과와 입력 작업을 고정, 자동 재개만 on/off. 중복 방지·저장소는 동일. 4개 중단 지점 × 3회 = 방식별 12회. 완료 기록 전 저장 성공, 저장 결과 불명 상황을 포함한다.
- 기준은 제안값: 미해결 발견 9/10 이상, 불필요 개입 1/20 이하, 중복 보고서·근거 없는 완료 0. 완료·올바른 보류·실패 분리. 사람 시간 개선과 같은 품질 유지가 다음 시험의 조건.
- 단순 단계와 중단 지점별 전후 표로 충분해 정적 도식으로 구성했다. 조작이나 모델 API 호출 없이 읽을 수 있다.
- 특정 API 비용·환율·생산성 수치는 넣지 않았다. 실제 평가 시 사용량·재시도와 사람 시간을 기록하도록 제안했다.

## 후속 수정 · Paseo 공식 이미지 추가

- 사용자의 요청에 따라 공식 한국어 README에 실린 데스크톱·모바일 통합 소개 이미지 1장을 Paseo 첫 문단 뒤에 추가했다. 원본·라이선스·저장소 등록 이력은 미디어 기록에 남겼다.
- 원본 이미지의 마지막 변경은 2026-03-26 커밋이다. 0.15 베타 복구 시연으로 오인하지 않도록 캡션에 이전 제품 소개 화면이라고 명시했다. 기존 복구 도식은 함께 유지한다.
- 원본 2048 × 1233 비율, 내용 중심 alt, 원본 크기로 열리는 내부 링크와 공식 한국어 소개 링크를 추가했다. 기사 호수·발행일·제목·목록·홈은 변경하지 않았다.
- 수정 후 `git diff --check`와 `node --test --test-reporter=dot` 통과(71개). 브라우저에서 실제 이미지 로딩, 데스크톱·390px 모바일 배치, 원본 이미지 링크와 기사 복귀를 확인했다. 가로 넘침과 오류 로그는 없었으며 임시 화면 폭 설정을 해제했다.

## 후속 수정 · 전체 문장 검토

- 부제·요약·본문·도식·캡션·실험 절의 주어와 서술어 호응을 다듬고, 압축된 명사 표현을 행동 중심으로 풀었다. ‘장애 없이’는 실험에서 작업을 중단시키지 않는다는 뜻으로 명확히 했다.
- 판단 기록의 수동 활용, 활성화와 실제 답변의 구분, 외부 에이전트의 기본 설정 예외, Paseo의 복구 한계와 실험 비교 조건을 유지했다. 같은 뜻을 반복하던 학습 관련 설명은 합쳤다.
- 문체 수정에 한정했으며 새 외부 조사나 제품 실험은 수행하지 않았다. 기사 제목·호수·발행일·URL과 출처·이미지 경로는 유지했다.
- 검증: 기존 테스트 71개 통과, `git diff --check` 통과. 수정 전후의 링크·자산 경로·ID·날짜·이미지 크기·제목을 대조했다. 데스크톱과 360px 모바일에서 수정 문단·실험 표의 줄바꿈과 가로 넘침을 확인했고 브라우저 오류는 없었다.
