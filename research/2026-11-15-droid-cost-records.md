## 시각과 확인 범위

상태 페이지의 검색 추출 화면은 시각을 다른 시간대로 표시했다. 브라우저에서 한국시간 표시를 직접 확인했으며, 문제 시작을 표시한 `<time>`의 datetime은 `2026-11-14T01:10:07.366+09:00`이었다. Updates의 03:56 및 14:31도 같은 화면의 KST 표시를 사용했다. 현재 시간을 보여준 datetime 역시 `+09:00`이었다.

Factory의 날짜에는 확인된 시각·시간대가 없어 ‘최근 24시간의 발표’라고 단정하지 않았다. 초안의 하루 전체 모델 발표와 비교하는 문장도 조사 범위를 벗어나므로 삭제했다. 공식 자료 두 소식에 집중했다.

11월 10일 복구된 ‘Incorrect cost data in Costs API exports’는 별개 사건이다. 이번 지연 공지와 섞지 않았다. 현행 공개 Costs API는 운영 설계의 참고 자료이며, 이번 Compliance API 사건과 공개 API의 모든 고객·경로가 동일하게 영향을 받았다고 단정하지 않는다.
