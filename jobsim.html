AI가 코드를 작성하고, 문서를 분석하고, 로그를 살펴보고, 테스트를 수행하고, 여러 도구를 직접 호출하는 시대가 되고 있습니다.

그래서 이런 질문을 해보려고 합니다.

“이 작업에 사람이 계속 개입해야 할까?”

사람이 반복해서 하던 일을 Software + AI + Agent + Workflow로 다시 설계해보는 비공식 기술 모임, 헬로우 휴먼입니다. 회사 공식 프로그램이나 업무 활동이 아닌, 관심 있는 사람들이 자율적으로 모이는 기술 놀이터입니다.

주제는 Workless Engineering. 정해진 교재나 진도 없이, “이거 되나?” 싶은 것을 일단 붙여봅니다.

  • 비공식 · 자율운영
  • 2주 단위 · 유연하게
  • 구경만 해도 OK

EXHIBIT 01

Workless Engineering

Workless Engineering의 목표는 단순한 자동화가 아닙니다.

내가 반복해서 하는 일을 들여다보고,

  1. 01Human Driven
  2. 02AI Assisted
  3. 03AI Delegated
  4. 04Human on Exception

방향으로 바꿔봅니다. 작은 스크립트 하나로 귀찮은 일이 줄어도 충분합니다.

AI에게 모든 판단을 넘기자는 것도 아닙니다.

  • RuleRule로 해결할 일은 Rule로,
  • SoftwareSoftware로 해결할 일은 Software로,
  • AIAI가 필요한 곳에는 AI를 사용하고,
  • Human사람이 꼭 필요한 지점만 남기는 것이 목표입니다.

EXHIBIT 02

이런 거, 한번 붙여볼까요?

반복하는 일을 Workflow로

매번 손으로 하던 일을 쪼개보면, 맡길 수 있는 틈이 보일지도 모릅니다.

  1. Trigger
  2. Context
  3. Decision
  4. Action
  5. Validation
  6. Exception

그리고 각 단계에서 질문합니다.

  • 자동화할 수 있는가?
  • 기존 코드나 API로 해결할 수 있는가?
  • LLM의 판단이 필요한가?
  • Agent가 Tool을 호출하게 할 수 있는가?
  • 사람이 승인해야 하는 지점은 어디인가?
  • 실패하면 어떻게 복구할 것인가?
HUMAN INSTRUCTION BOARD

귀찮은 것부터, 궁금한 것까지

매주 10분, 30분씩 쓰던 시간을 줄여봐도 좋고, 그냥 재미있어 보여서 해봐도 좋습니다.

  • 회의 TODO 정리
  • 메일에서 할 일 추리기
  • Legacy Code 탐색
  • MCP로 도구 연결
  • 테스트 데이터 생성
  • 로그 패턴 찾기
  • PR 먼저 훑어보기
  • 반복 명령 CLI로 묶기
  • 작은 로컬 모델 실험
  • 여러 Agent 협업 구경

조금 더 파고들고 싶다면, 이런 Workflow도 돌려볼 수 있습니다.

도구와 프레임워크는 그때그때 골라 씁니다. “굳이 이렇게까지?” 싶어도 궁금하면 해봅니다.

“이게 왜 필요한데?”보다 “이거 되나?”를 먼저 물어봅니다.

EXHIBIT 03

운영 방식

기본 활동 주기는 2주 단위로 생각하고 있습니다. 각자 조금씩 만져보고, 이야깃거리가 생기면 온라인이나 오프라인으로 편하게 모입니다.

모든 일정에 참석할 필요 없이, 각자의 관심과 상황에 맞게 참여합니다.

PLAY CARDTINKER

혼자 해도, 같이 해도

  • 궁금한 기술 일단 설치해보기
  • 없애고 싶은 반복 작업 골라보기
  • 마음이 맞으면 작은 PoC 함께 만들기
  • 시간이 나는 만큼 조금씩 만져보기
PLAY CARDHANG OUT

보여줘도, 구경만 해도

  • 공유할 것이 생기면 편하게 올리기
  • 혼자 만든 것, 만들다 만 것 보여주기
  • 막힌 부분이나 웃긴 실패 이야기하기
  • 다른 사람의 삽질 구경하기

↻ 2주는 느슨한 활동 리듬. 숙제나 발표 마감은 없습니다.

완성된 제품이 없어도 괜찮습니다. “해봤는데 이건 사람이 하는 게 낫더라”도 좋은 결과입니다.

작게 만들고, 실행해보고, 실패해보는 것을 중요하게 생각합니다.

그래서, 뭐가 덜 귀찮아졌나요?

해본 이야기를 나눌 때 이런 질문을 곁들여봅니다. 전부 측정할 필요 없이, 실패한 이유나 “그냥 재미있었다”는 이야기도 좋습니다.

Cycle Time기다리는 시간까지 줄었나요?
Success Rate다시 돌려도 잘 되던가요?
