# NEON ATLAS 실습 요구사항 v1

## 목적

가상의 야간 아트 페스티벌을 소개하는 한국어 웹페이지를 만듭니다.
처음 보는 사람이 행사 분위기를 느끼고, 프로그램을 골라볼 수 있어야 합니다.
시각적으로 인상적인 구성과 실제로 작동하는 인터랙션을 함께 완성합니다.
이 문서는 여러 모델에 동일하게 주는 비교용 입력입니다. 수정하지 않습니다.

## 행사 정보

- 이름: NEON ATLAS
- 한 줄 소개: 도시가 잠든 뒤, 빛으로 길을 찾다.
- 날짜: 2026년 11월 14일
- 운영 시간: 18:00~23:00
- 장소: 가상도시 루멘항 문화지구
- 안내: 학습용 가상 행사입니다. 실제 예약이나 결제는 진행하지 않습니다.

## 시각 방향

- 밤의 전시 포스터 같은 강한 첫 화면. 큰 타이포그래피와 분명한 정보 위계를 사용합니다.
- 짙은 배경에 네온 라임·보라·시안 등을 선택적으로 사용합니다. 작은 글씨는 선명하게 읽혀야 합니다.
- 빛의 궤도, 파동, 격자 등 주제에 맞는 시각 요소를 CSS 또는 인라인 SVG로 직접 만듭니다.
- 유리 질감 카드나 은은한 움직임을 활용할 수 있지만, 같은 카드만 반복하는 구성은 피합니다.
- 화면 구성·색 조합·그래픽은 스스로 정합니다. 외부 이미지, 아이콘, 폰트, 라이브러리는 쓰지 않습니다.

2. 세 가지 경험 소개: 빛 / 소리 / 퍼포먼스. 각 경험의 짧은 소개 문구는 창작해도 됩니다.

4. 관심 프로그램 개수와 비우기 버튼.

## 실제로 작동할 것

- 프로그램 필터는 전체 / 빛 / 소리 / 퍼포먼스 네 개입니다. 처음에는 전체가 선택되어 여섯 개를 보여줍니다.
- 각 분류에는 두 개씩 있습니다. 필터를 바꾸면 해당 프로그램만 표시하고 현재 보이는 개수를 갱신합니다.
- 모든 프로그램에는 관심 담기 / 취소 기능이 있습니다. 중복으로 담기지 않습니다.
- 관심 개수는 전체 여섯 프로그램을 기준으로 0~6입니다. 필터로 숨겨진 프로그램의 선택도 유지하고 개수에 포함합니다.
- 관심 목록 비우기는 모든 선택을 해제합니다. 현재 선택한 분류 필터는 유지합니다.
- 새로고침하면 전체 필터, 관심 0개로 돌아갑니다. 저장 기능은 만들지 않습니다.
- 첫 화면의 프로그램 보기 링크는 프로그램 영역으로 이동해야 합니다.

## 화면과 접근성

- 1440px과 390px 너비에서 글자·카드·버튼이 겹치거나 가로로 잘리지 않아야 합니다.
- 키보드 Tab으로 조작 요소에 접근하고 Enter 또는 Space로 실행할 수 있어야 합니다.
- 키보드 포커스를 눈으로 확인할 수 있어야 하고, 선택 상태는 색만으로 구분하지 않습니다.
- prefers-reduced-motion 환경에서는 장식 애니메이션과 부드러운 스크롤을 줄이거나 끕니다.
- 실제로 작동하지 않는 예약·구매 버튼, 가짜 참가자 수, 가짜 후기는 넣지 않습니다.

## 결과 파일

- 현재 폴더에 index.html 한 개를 직접 만듭니다. HTML 코드만 대화에 출력하고 끝내지 않습니다.
- CSS와 JavaScript를 같은 파일 안에 넣습니다.
- 브라우저에서 파일을 직접 열어 실행합니다. 설치·빌드·서버·네트워크 요청 없이 작동해야 합니다.
- 외부 패키지, CDN, 이미지 URL, 웹폰트, API, 분석 스크립트는 추가하지 않습니다.
- 날짜·시간·장소·프로그램 정보는 주어진 값을 유지합니다.
- brief.md와 AGENTS.md는 수정하지 않습니다. 커밋·푸시·배포는 요청하지 않습니다.
- 완료 후 만든 파일, 구현한 기능, 실제 확인한 항목과 확인하지 못한 항목을 짧게 보고합니다.
- 브라우저 확인 도구가 없으면 화면을 확인하지 못했다고 보고합니다.
