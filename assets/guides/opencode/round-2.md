# Round 2 공통 수정 요청

현재 index.html에서 아래 두 가지를 수정해줘.

1. '빛의 정원' 시작 시간을 19:00에서 19:30으로 바꿔줘.
2. '관심 프로그램만 보기' 체크박스를 추가해줘. 처음에는 꺼져 있어야 해.

분류 필터와 관심 필터는 동시에 적용해. 둘 다 만족하는 프로그램만 보여줘.
필터 결과가 없으면 '조건에 맞는 프로그램이 없습니다.'를 표시해.
관심 개수는 필터와 관계없이 전체 선택 개수를 유지해.
관심 보기 중 담기를 취소하면 해당 카드가 즉시 사라지고 개수와 빈 상태도 갱신돼야 해.

나머지 날짜·시간·장소·프로그램 정보, 시각 디자인과 기존 동작은 유지해.
외부 의존성이나 새 파일을 추가하지 말고 index.html만 수정해.
brief.md와 AGENTS.md는 그대로 두고, 커밋·푸시는 하지 마.
수정한 내용과 실제 확인한 항목, 확인하지 못한 항목을 구분해서 알려줘.
