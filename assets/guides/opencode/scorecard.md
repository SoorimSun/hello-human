## Round 1 체크

- [ ] 한 개의 index.html이 실제로 만들어졌다.
- [ ] 외부 리소스·설치·서버 없이 파일을 직접 열어 동작한다.
- [ ] 날짜·시간·장소와 여섯 프로그램의 값이 정확하다.
- [ ] 전체 6개, 각 분류 2개가 표시된다.
- [ ] 전체 필터로 돌아와 빛의 문과 잔향 수집을 담으면 전체 관심 개수가 2다.
- [ ] 빛 필터로 바꿔도 관심 개수 2가 유지된다.
- [ ] 빛 필터에서 비우면 관심 0개가 되고 빛 프로그램 2개는 계속 표시된다.
- [ ] 새로고침하면 전체 6개, 관심 0개다.
- [ ] 1440px / 390px에서 가로 잘림·겹침이 없다.
- [ ] 키보드 조작과 포커스가 작동한다.
- [ ] OS 동작 줄이기 설정에서 장식 움직임이 줄거나 멈춘다.

## Round 2 체크

- [ ] 빛의 정원은 19:30이며 다른 프로그램의 시간은 그대로다.
- [ ] 새 체크박스는 처음에 꺼져 있다.
- [ ] 새로고침 후 빛의 문·잔향 수집을 담으면 관심 2개다.
- [ ] 빛 필터 + 관심만 보기를 켜면 빛의 문 1개, 전체 관심 2개다.
- [ ] 빛의 문을 취소하면 빈 상태 문구, 전체 관심 1개다.
- [ ] 전체 필터로 바꾸면 잔향 수집 1개가 나타난다.
- [ ] 나머지 시각 디자인과 기존 기능이 유지된다.

## 관찰 점수

0 = 요구를 충족하지 못함 / 1 = 일부 충족 / 2 = 대체로 충족.
연결 오류로 결과가 없으면 채점하지 않고 미실행으로 기록합니다.
12점 합계는 이번 과제의 참고치이며 모델의 일반 성능 순위가 아닙니다.

| 기준 | 0~2점 | 근거 한 문장 |
| --- | --- | --- |
| 첫 화면의 정보 위계와 가독성 | | |
| 주제에 맞는 시각 구성과 디테일 | | |
| 모바일 배치와 접근성 | | |
| 필터·관심 담기의 실제 동작 | | |
| 데이터·파일·의존성 요구 준수 | | |
| Round 2 변경 정확도와 기존 결과 보존 | | |
| 합계 (최대 12) | | |

가능하면 같은 모델을 새 폴더·새 세션에서 2~3회 반복합니다.
