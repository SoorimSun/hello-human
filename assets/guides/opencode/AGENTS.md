# OpenCode HTML 비교 실습

## 작업 범위

- 이 폴더는 가상 행사 페이지 제작 실습용입니다.
- 요구사항은 brief.md를 따릅니다. 사용자가 후속 변경을 요청하면 해당 변경만 반영합니다.
- 결과물은 현재 폴더의 index.html 한 개입니다. CSS와 JavaScript도 그 안에 작성합니다.
- 외부 의존성·네트워크 요청 없이 브라우저에서 직접 열 수 있어야 합니다.
- 기존 자료, 이 지침, 상위 폴더와 다른 실험 폴더를 수정하지 않습니다.
- 추가 스킬·플러그인·하위 에이전트를 사용하지 않습니다.
- 모델을 바꾸거나 다른 모델에게 작업을 넘기지 않습니다.
- Git 커밋·푸시와 배포는 수행하지 않습니다.

## 완료 보고

- 만든 파일과 구현한 내용을 짧게 설명합니다.
- 실제 실행한 확인과 미실행 확인을 구분합니다.
- 브라우저를 사용할 수 없다면 시각 확인이나 버튼 조작을 통과했다고 쓰지 않습니다.
