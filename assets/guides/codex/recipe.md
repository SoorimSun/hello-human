# 헬로우 키친 · 갈비찜

헬로우 휴먼의 Codex 학습을 위해 간단하게 구성한 갈비찜 예시 자료입니다. 실제 판매 메뉴나 영양 분석 자료가 아닙니다.

## 기본 정보

- 페이지 이름: 헬로우 키친
- 요리 이름: 갈비찜
- 기준 인원: 2인분
- 소개: 소갈비에 무와 당근을 더하고 간장 양념으로 뭉근하게 조리는 갈비찜. 재료를 손질하고, 데치고, 양념이 배도록 익힙니다.

## 재료 · 2인분 기준

| 재료 | 양 | 단위 |
| --- | ---: | --- |
| 소갈비 | 600 | g |
| 무 | 200 | g |
| 당근 | 100 | g |
| 간장 | 60 | mL |
| 설탕 | 20 | g |
| 다진 마늘 | 15 | g |
| 참기름 | 5 | mL |

물은 갈비를 데칠 때와 냄비에서 조릴 때 사용하며, 재료가 잠기는 정도와 졸아드는 상태를 보며 조절합니다. 정해진 양이 없는 물은 심화 실습의 계산 대상에서 제외합니다.

## 조리 순서

1. 일곱 가지 재료를 계량합니다. 소갈비는 냉장고에서 찬물에 담가 핏물을 빼고, 무와 당근은 큼직하게 썹니다.
2. 끓는 물에 갈비를 데친 뒤 씻어 준비합니다. 데친 물은 버립니다.
3. 냄비에 갈비, 간장, 설탕, 다진 마늘과 새 물을 넣고 뭉근하게 끓입니다.
4. 갈비가 부드러워지기 시작하면 무와 당근을 넣고 함께 조립니다. 고기와 채소가 충분히 익고 양념이 배면 참기름을 넣어 마무리합니다.

## 페이지 요구사항

- 한국어로 작성합니다.
- 요리 이름, 2인분 표시, 소개, 일곱 가지 재료와 수량·단위, 네 단계의 조리 순서를 표시합니다.
- 모바일에서도 읽기 쉬운 한 페이지로 만듭니다.
- 입문 단계는 index.html 하나에 CSS를 포함합니다. 외부 패키지·이미지·폰트를 쓰지 않습니다.
- 입문 단계에는 인분 입력, 로그인, 결제, 데이터 저장 기능을 넣지 않습니다.
- 정확한 조리 시간, 영양 수치, 건강 효능, 제품명은 추가로 만들어 넣지 않습니다.
- 별도 배포 요청 전에는 커밋·push·공개 업로드를 하지 않습니다.

## 입문 완료 기준
