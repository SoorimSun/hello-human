# 헬로우 키친 작업 지침

## 작업 방식

- 한국어로 설명하고, 목표·현재 작업 폴더·변경 파일·확인 결과를 짧게 알려줍니다.
- recipe.md를 요리 내용의 기준으로 사용합니다. 없는 시간·영양·건강 정보를 만들지 않습니다.
- 요청한 단계의 기능만 구현합니다. 관련 없는 파일을 변경하지 않습니다.
- 커밋·push·공개 배포는 사용자가 별도로 요청한 범위에서만 수행합니다.

## 입문 단계

- index.html 한 파일에 HTML과 CSS를 작성합니다.
- 외부 패키지, 외부 이미지·폰트, 서버 기능, 로그인, 데이터 저장은 사용하지 않습니다.
- 수량·단위·조리 순서와 모바일 화면을 확인합니다.

## 심화 단계로 진행하라는 요청을 받은 경우

- advanced-brief.md의 요구사항과 사용자가 확인한 설계를 적용합니다.
- 사용자가 Wayfinder·Superpowers 학습 과정을 요청했다면 결정 요약, 설계, 구현 계획을 먼저 남기고 확인된 단계부터 구현합니다.
- 실제 사용한 스킬과 생성 문서 경로를 알려줍니다. 리뷰와 검증 결과에 확인 근거를 남깁니다.
- index.html, servings.mjs와 로컬용 tests/, tools/, docs/ 파일을 사용할 수 있습니다.
- 브라우저에서 실행되는 외부 패키지나 빌드 과정은 추가하지 않습니다.
- 계산기 검증은 Node.js 내장 테스트를 사용합니다. 계산기 자체에 추가 npm 패키지는 필요하지 않습니다.
- 계산 로직 테스트는 실제 servings.mjs를 가져와 확인합니다. 테스트 안에 계산 코드를 복제하지 않습니다.
- 테스트 실행 여부와 결과를 정확히 보고합니다. 실행하지 못하면 원인과 확인하지 못한 항목을 알립니다.

## 공개 파일

- 입문: index.html, 비어 있는 .nojekyll
- 심화: index.html, servings.mjs, 비어 있는 .nojekyll
- recipe.md, AGENTS.md, advanced-brief.md, docs/, tests/, tools/는 이 실습에서 로컬 작업 자료로 유지합니다.
- 비밀번호·인증키·개인정보·내부 자료는 공개 파일에 넣지 않습니다.
