# 가상 모임 안내 페이지 실습

이 파일의 행사와 장소는 헬로우 휴먼 입문 가이드를 위해 만든 가상 자료입니다.
실제 참가자를 모집하거나 신청 정보를 수집하지 않습니다.

## 안내할 내용

- 모임 이름: 나의 첫 AI 작업실
- 일시: 2026년 10월 17일 토요일 오후 2시~4시
- 장소: 가상 공간 '작은 작업실'
- 대상: AI 도구로 처음 무언가 만들어 보고 싶은 사람
- 준비물: 노트북, 해보고 싶은 작은 일 하나
- 진행 순서: 서로 소개하기 20분 → 각자 만들기 70분 → 결과 나누기 30분
- 신청 안내: 신청 기능은 준비 중입니다.

## 만들 결과

- 브라우저에서 직접 열 수 있는 index.html 한 개
- 한국어로 읽기 편한 모임 안내 페이지
- CSS는 같은 HTML 안에 작성
- 휴대폰처럼 좁은 화면에서도 읽을 수 있는 배치
- 신청은 안내 문구만 표시. 입력 폼이나 실제 전송 기능은 만들지 않음
- 최종 결과는 개인 GitHub 공개 저장소에서 GitHub Pages 프로젝트 사이트로 배포
- 기본 주소 형태: https://YOUR_USERNAME.github.io/hello-claude-practice/
- YOUR_USERNAME은 본인의 GitHub 사용자 이름으로 교체

## 작업 범위

- 이 폴더 안에서 작업
- brief.md 원문 유지
- 패키지 설치, 외부 글꼴·이미지·스크립트, 서버 연결 없이 만들기
- 주어지지 않은 참가비, 연락처, 신청 링크를 만들지 않기
- 먼저 로컬 화면을 완성하고 확인한 뒤 별도의 배포 요청으로 공개 진행
- 배포 준비 단계에서 같은 폴더에 빈 .nojekyll 파일 추가 가능
- 공개할 파일은 index.html과 .nojekyll. brief.md·작업 지침·메모·인증 정보는 제외
- 배포 요청이 오면 지정한 개인 저장소에만 커밋·푸시하고 Pages 설정과 접속 결과 확인

## 사람이 확인할 내용

- 제목·일시·장소·준비물이 위 내용과 일치하는가?
- 신청 안내가 '준비 중'으로 표시되는가?
- 파일을 브라우저에서 직접 열 수 있는가?
- 창 너비를 좁혀도 글과 카드가 잘리지 않는가?

## 다음 수정 실습

brief.md는 최초 요청의 기록으로 유지하고, 변경 요청은 대화에서 전달합니다.

## 배포 완료 기준

- 본인 계정의 Public 저장소에 최종 HTML이 올라가 있는가?
- Settings > Pages가 Deploy from a branch / main / (root)로 설정되었는가?
- 배포 작업이 성공했고 https://YOUR_USERNAME.github.io/hello-claude-practice/가 열리는가?
- 공개 주소에도 수정한 오후 3시~5시와 '신청 기능은 준비 중입니다.'가 표시되는가?
- 휴대폰이나 다른 브라우저에서도 확인했는가?
- 기본 브랜치 이름이 main과 다르면 Pages도 실제 브랜치로 맞췄는가?
