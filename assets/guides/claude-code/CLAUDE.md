# 모임 안내 페이지

## 목적
가상 모임 정보를 브라우저에서 읽는 작은 실습 프로젝트입니다.

## 파일
- brief.md: 최초 요청의 기록. 수정하지 않습니다.
- index.html: 안내 페이지. 스타일도 이 파일에 둡니다.
- .nojekyll: 배포 준비 단계에서 추가하는 빈 파일. 정적 파일을 그대로 게시하도록 합니다.

## 작업 원칙
- 한국어로 설명합니다.
- 별도 패키지와 외부 리소스를 추가하지 않습니다.
- 참가비, 연락처, 신청 링크를 추측해 넣지 않습니다.
- 요청에 포함되지 않은 파일 수정은 먼저 설명합니다.
- 커밋·푸시는 사용자가 별도로 요청할 때 수행합니다.
- 요청받은 파일만 포함하고 현재 원격 연결과 브랜치를 확인합니다.
- 기본 공개 파일은 index.html과 .nojekyll입니다.
- brief.md, CLAUDE.md, next-step.md, .claude/, .env와 인증 정보는 업로드하지 않습니다.
- 기존 저장소를 덮어쓰거나 강제 푸시하지 않습니다.

## 확인과 보고
- 현재 요청의 일시·장소·준비물과 HTML 내용을 대조합니다.
- 브라우저를 사용할 수 있다면 화면을 직접 확인합니다.
- 브라우저를 사용할 수 없다면 화면 검증은 미실행으로 보고합니다.
- 바꾼 파일, 확인한 내용, 아직 확인하지 못한 내용을 알려줍니다.
- 커밋·푸시를 요청받았다면 수행 결과를 알려줍니다.
