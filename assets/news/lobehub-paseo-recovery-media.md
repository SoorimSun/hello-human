- 원본 이미지: <https://paseo.sh/hero-mockup.png>.
- 저장소 파일: <https://github.com/getpaseo/paseo/blob/bf8ba4da8fc73da65300ba0dc357962f0eb99f69/packages/website/public/hero-mockup.png>.
- 등록 이력: [2026-03-26 변경 커밋](https://github.com/getpaseo/paseo/commit/bf8ba4da8fc73da65300ba0dc357962f0eb99f69). 최초 화면 촬영일·제품 버전은 이미지에 명시되지 않았다. 확인일 2026-11-02.
- 용도: 데스크톱의 프로젝트·작업 목록, 에이전트 대화·명령 기록, 코드 변경 패널과 휴대폰 검토 화면을 함께 보여주는 공식 소개용 합성 이미지. 0.15 베타의 복구 기능 시연으로 사용하지 않는다.

- 이용 조건: 저장소의 [LICENSE](https://github.com/getpaseo/paseo/blob/main/LICENSE)는 Paseo에 Apache-2.0을 적용하며 제삼자 구성요소는 별도 라이선스를 따른다고 명시한다. 저장소 공개 자산이며 별도 이미지 라이선스 표시는 확인되지 않았다. 저작권 문구와 라이선스 전문을 `paseo-LICENSE.txt`에 함께 보관했다. 루트의 별도 NOTICE 파일은 없었다.
- 채택 판단: 공식 README의 데스크톱·모바일 통합 이미지가 제품 소개에 적합해 Paseo 첫 문단 뒤에 추가했다. 별도의 `mobile-mockup.png`도 직접 확인했으나, 같은 모바일 사용 맥락을 반복하므로 기사에는 추가하지 않았다.
- 검증: 다운로드 파일 전체 내용을 직접 확인했고 PNG 헤더의 크기를 대조했다. 기사에서 원본 2048 × 1233 이미지의 로딩 완료를 확인했고, 데스크톱·390px 모바일에서 비율과 캡션 배치를 확인했다. 원본 이미지 링크 이동과 기사 복귀가 정상 동작하며 가로 넘침과 브라우저 오류가 없었다.

## Paseo 복구 도식

- 위치: 기사 `#paseo`, ‘데몬 재시작 뒤, 작업을 이어가는 두 방식’ HTML/CSS 도식.
- 근거: <https://github.com/getpaseo/paseo/releases/tag/v0.15.0-beta.1>, <https://github.com/getpaseo/paseo/pull/7644>, <https://github.com/getpaseo/paseo/pull/8127>.
- 성격: 헬로우 휴먼의 설명용 도식. 터미널 프로그램 유지와 에이전트 대화 재개를 나란히 구분한다. 아래의 업무 결과 확인은 적용 관점이다.
- 공식 시각 자료 탐색: 릴리스·두 PR 본문에는 채택할 복구 화면/영상이 없었다. 공식 소개 <https://paseo.sh/>의 데스크톱·모바일 대화형 화면도 브라우저에서 확인했다. 후속 요청에서 공식 한국어 README의 정적 제품 소개 이미지를 확보해 위와 같이 추가했다. PR 8127은 복구 검증 스크린샷이 로컬에 남아 있다고 명시하며, 공개 댓글에도 추가 미디어는 없었다.
- 한계: 운영체제 재부팅·전원 손실에서도 실행 중 프로그램이 유지된다는 뜻이 아니다. 정확히 한 번 실행 보장·업무 상태 복원 보장으로 확대하지 않는다.

## 실험 흐름과 중단 지점 표

- 위치: 기사 `#experiment`의 역할별 4단계, INC-017 중단 지점 표.
- 제공자: 헬로우 휴먼 자체 작성, 2026-11-02.
- 성격: 아직 실행하지 않은 가상 실험의 기대 동작. 별도 구현할 연결 코드·모의 저장소이며 제품 내장 연동이나 실제 측정 화면이 아니다.
- 입력: 가상 장애 알림·대화·로그. 출력: 판단과 이유, 사건 ID로 한 번만 반영되는 모의 보고서·검증 결과.
- 정적 HTML/CSS로 구성해 JavaScript 없이도 모든 분기와 기대 결과를 읽을 수 있다. 숫자는 실험 설계값이다.
- 브라우저에서 1280px 데스크톱과 390px·360px 모바일, 라이트·다크 모드의 배치·가로 넘침을 확인했다. 모바일에서 복구 경로는 세로로 배치되며, 실험 표의 세 열이 화면 안에 들어온다.
