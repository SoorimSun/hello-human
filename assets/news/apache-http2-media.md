# Apache HTTP Server 단신 공식 로고

- 확인·저장일: 2026-11-13, 한국시간.
- 사용 기사: `news/2026-11-13-apache-http2-security.html`, 단신 15.
- 제공자: Apache Software Foundation.
- 공식 자료실: [Apache Project Logos · HTTP Server](https://www.apache.org/logos/#httpd).
- 공식 목록: [logos.json](https://www.apache.org/logos/res/logos.json), `httpd` 항목의 `httpd/httpd.png`.
- 원본 PNG: [httpd.png](https://www.apache.org/logos/res/httpd/httpd.png).
- 원본 보관: `apache-http-server-logo-official.png`, 1200 × 458, RGBA PNG, 55,081바이트. 다운로드한 파일 그대로이며 자르기·색상 변경·문구 변경 없음.
- 썸네일: `apache-http-server-thumbnail.jpg`, 1200 × 630. `apache-http-server-logo-card.html`을 브라우저에서 렌더링해 JPEG로 캡처했다. 흰 배경에 원본 로고를 같은 비율로 너비 80%에 배치해 여백을 둔다. 로고 자체를 다시 그리거나 생성형 이미지로 재현하지 않았다.
- 본문 상단의 공식 프로젝트 링크, 뉴스 목록 이미지, Open Graph·Twitter 공유 메타데이터에 같은 썸네일을 사용한다. 본문 캡션에 제공처와 상표권자를 명시한다.
- [Apache 상표 정책](https://www.apache.org/foundation/marks/)을 확인했다. 기사의 대상 제품을 식별하는 자료로 사용하며, 본문의 로고는 공식 프로젝트 홈페이지에 연결한다.
- 자료실에서 제공하는 깃털 형태의 프로젝트 로고를 사용했다. 공식 홈페이지의 가로 배너는 1600 × 144이며 오른쪽에 큰 투명 여백이 있어 썸네일 원본으로 쓰지 않았다. 자료실 로고를 ‘최신 로고’라고 단정하지 않는다.
- 실제 메신저·소셜 서비스의 공유 카드 표시와 캐시는 배포 후 별도 확인 대상이다. 이번 작업에서 원격 게시나 배포는 하지 않았다.
