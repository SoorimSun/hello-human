# OFBiz 새 질문 3개 · 산출물 제공 전후 반복 비교

2026-10-24 한국시간에 3문항 × 2조건 × 3회, 총 18개 독립 대화에서 응답을 수집했다. 모든 문항에서 사전 핵심 사항 세 개를 모두 명시한 응답은 소스만 제공 3/3, 문서 추가 3/3이었다. 이 범위에서 핵심 사항 충족의 차이는 관찰되지 않았다. 두 조건의 전반적 성능이 동등하다거나 문서화가 불필요하다는 결론은 아니다.

## 실행 조건

- 같은 상위 모델·추론 설정을 상속한 Codex 독립 에이전트 18개. 모델 override 없음. 이전 대화·다른 실행의 응답·판독 기준을 전달하지 않았다.
- 정확한 API 모델 식별자, temperature, seed는 도구에서 노출되지 않았다. 새 대화로 분리했지만 통계적 독립성이나 외부 재현성을 보장하지 않는다.
- A: 질문·지시문·소스 발췌. B: 동일한 A 입력 뒤에 기존 기능 설명서·규칙 연결표를 추가. 질문별·조건별 세 입력은 바이트 단위로 동일하다. 문서 내용은 실험 전에 고정하고 수정하지 않았다.
- 각 실행은 지정한 입력 파일 하나만 읽도록 제한했다. 도구 호출에서 그 파일의 읽기만 수행했음을 확인했다. 추가 검색·다른 파일·프로그램 실행·수정 없음.
- 한국어 1,200자 이내라는 같은 지시. 실제 답변은 원문 마크업·공백·줄바꿈을 포함해 849~1061자였고 제한 초과는 없었다.
- 질문·조건의 순서는 시드 20261024로 섞어 고정했고 최대 3개를 병행했다. 여기서 시드는 실행 순서용이며 모델의 생성 시드가 아니다.
- 조건별 3회 모두 보존했다. 실패나 답변 선별을 위한 재실행은 없었다. 이 보고서에서 시간·토큰 비용은 평가 지표로 사용하지 않는다.

## 해석의 한계

1. 한 모델 설정, 한 메서드 주변의 세 질문, 조건별 세 번뿐이다. 유의성·효과 크기·모델 간 일반화나 성능 동등성을 추정하지 않는다.
2. 관련 코드를 미리 골랐다. 두 조건이 모두 기준을 충족해 차이를 구분하지 못한 범위이며, 큰 저장소에서 자료를 찾는 어려움과 탐색 시간을 시험하지 않았다.
3. 새 질문의 구체적 답은 두 문서에 없지만 질문은 같은 기능·코드 범위에 속한다. 학습 때 접했는지 알 수 없어 새로운 문제 일반화의 증거로 해석하지 않는다.
4. 구조화된 문서의 효과와 추가 정보·입력 길이의 효과를 분리하지 않았다. 길이를 맞춘 대조군은 없다.
5. 문서·질문 작성자와 판독자가 같고 조건을 아는 판독이다. 선정 편향과 판독 편향의 가능성이 있다. 외부 전문가 평가나 사람의 업무 검토는 하지 않았다.
6. 정확한 모델 ID와 샘플링 값이 미공개이며, 독립 대화가 독립적인 확률 표본임을 보장하지 않는다.
7. 실제 OFBiz·하위 서비스·테스트는 실행하지 않았다. 정확도 개선, 조사·검토 시간 또는 비용 절감의 실측 결과가 아니다.
