# 리만 가설 형식 증명 기사의 자료

[일반뉴스 55호](../../news/2026-11-22-riemann-proof.html) · 확인 2026-11-22 (한국시간)

- **검사 원문 발췌.** ‘검증진이 확인한 네 가지’ 절의 코드는 앤드루 서덜랜드가 공개한 공리 검사 로그 중 리만 가설 정리와 그 정리의 의존 공리를 보여 주는 연속 두 줄이다. 원문 대소문자·순서·공리 이름을 보존하고, 화면 폭에 따라 줄바꿈하는 선택 가능한 텍스트로 옮겼다. 독자가 콜론 양쪽을 대조할 수 있도록 캡션을 붙였다. 검증 페이지의 갱신 시각은 11월 21일 12:55 UTC다. [audit.log](https://math.mit.edu/~drew/grh/audit.log) · [출력의 실행 조건](https://math.mit.edu/~drew/grh/)
- **검토한 다른 자료.** 저자의 발표문 첫 쪽, Lean·Mathlib 성명, 서덜랜드의 결과표와 Mathlib 정의를 대조했다. 이번 사건은 제출물과 기준 명제가 일치하는지가 쟁점이어서, 해당 관계를 바로 읽을 수 있는 실제 로그를 골랐다. 클레이가 연결한 역사 자료, 저자의 인물 사진과 첨부 원고의 사이트 아이콘은 이번 검증 결과를 보여 주지 않아 싣지 않았다. 외부 이미지·영상은 복제하지 않았다. [발표문](https://alpo.ge/remark.pdf) · [공동 성명](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/) · [클레이의 관련 자료](https://www.claymath.org/millennium/riemann-hypothesis/)
- **실험 표.** ‘쿠폰 복구 규칙 실험’의 세 행은 헬로우 휴먼이 가상 정책을 적용해 만든 기대값이다. 같은 요청 번호의 재전송까지 한 주문의 입력 순서대로 배치했다. 표에 있는 0·1은 잔여 사용 횟수와 누적 복구 건수이며 측정 결과는 제시하지 않았다.
