## 소식별 확인과 제외

- OpenAI: 발표 페이지를 브라우저로 열고 설계 절까지 이동했다. ‘TamaGPT device experiments.’ 영상 설명은 확인했지만 iframe에 재생 URL이 없어 영상 재생·내용 전체는 확인하지 못했다. 실제 공개된 enclosure 링크의 원본을 채택했다.
- Mazda: 원문에 재게재·재사용을 엄격히 금지한다는 문구가 있어 영상은 사용하지 않았다.
- Open WebUI: 릴리스의 기능 설명과 공식 웹 개발·파일 브라우저 문서를 확인했다. 일반 로고 대신 Files 탭 화면을 채택했다. 제품 설치·브라우저 조작 기능의 직접 재현은 수행하지 않았다.
- GitHub/JetBrains: Changelog의 로컬 작업 화면과 JetBrains의 격리 환경 설명을 확인했다. 클라우드 실행을 직접 재현한 화면으로 소개하지 않았다.
- 바이두: 최초 작성 때 원본 열기가 시간 초과로 끝나 자체 흐름도만 사용했다. 사용자의 후속 요청으로 11월 4일 공개 CDN 파일을 다시 확보해 직접 열었다. 앞서 주변 본문을 근거로 ‘센서 그림’이라고 기록했던 `20261103204952_1726.png`는 실제로 경로 선택에 따른 주변 차량 반응을 비교한 회사 설명 이미지였으므로 기록을 바로잡았다. 발표 현장 사진도 확인했지만 동작 설명에 더 적합한 비교 이미지 한 장을 채택했다.

## 이용 조건과 확인

- 채택한 네 공식 이미지는 해당 기능을 설명하는 기사에 출처·원문 링크와 함께 제한적으로 사용했다. 별도 개방형 미디어 라이선스나 포괄적 재사용 허가를 확인한 것으로 표현하지 않는다.
- 바이두 이미지의 확보 경로는 자사 도메인이 아닌 ‘来源：百度’로 표시된 발표문 전재다. [중국기금보의 저작권 안내](https://www.chnfund.com/copyright)는 자사 콘텐츠의 무단 전재를 제한한다. 이번 자료는 바이두 브랜드가 표시된 발표 슬라이드 한 장을 해당 주장 설명에 사용했으며, 출처 확인을 별도 이용허락 확보로 기록하지 않는다. 현장 사진·기사 전문·영상은 복제하지 않았다.
- 네 로컬 이미지를 직접 열어 내용·크기·비율을 확인했다. 스크린샷을 변형하거나 실제 측정 결과처럼 재구성하지 않았다.
- 브라우저에서의 기사 내 로딩과 모바일 배치는 조사 기록의 검증 항목에 남긴다.
