- `#grid-response-title`: 전력 수요 집중→캠퍼스 수요 조절→다른 고객 공급 여력의 세 단계. 최대 1,000MW는 계약상 감축 범위이며 발전량·달성 실적이 아님. 감축 속도·지속시간을 임의 수치로 만들지 않음.
- `#approval-flow-title`: 38,000원 견적 승인 후 42,000원으로 변경될 때 주문 0건·재승인 대기가 기대되는 정적 흐름. 사용자 승인과 코드 검사의 역할을 구분하고 모바일에서는 세로 흐름으로 재배치한다.
- 실험 표: 다섯 상황의 기대 상태. 실행 기록이나 모델 평가 결과가 아니다. 별도 JS 없이 읽을 수 있다.

## 브라우저 재검증

첫 Windows UI 검증은 URL 확인 실패로 중단됐다. 사용자의 재검증 요청에 따라 2026-11-03 인앱 브라우저에서 1440×1000, 390×844, 320×812 뷰포트를 확인했다. 이미지 로딩·원본 링크, 제목 줄바꿈, 카드·그래프·흐름·표의 배치와 라이트·다크 대비를 확인했고 가로 넘침은 없었다. 모바일 목차의 도착 위치와 현재 절 표시가 어긋나는 문제를 기사 전용 CSS에서 수정한 뒤 재검증했다. 상세 결과는 조사 기록의 ‘브라우저 재검증’ 절에 남겼다. 실물 휴대전화에서의 동작 시험은 아니다.

공식 자료 추가 후 같은 세 뷰포트에서 다시 확인했다. 공식 이미지 네 개 모두 정상 로드됐고 실제 이미지 크기와 HTML의 width·height가 일치했다. LifeVal 내보내기 파일은 처음 예상한 크기가 아닌 1398×1016임을 디코딩 결과로 확인해 속성과 기록을 수정했다. 390px에서는 세 신규 공식 도표와 캡션, 320px 다크 모드에서는 전력 설명도의 세로 배치를 확인했다. Anthropic 이미지 링크는 원본 JPG를 새 탭으로 열었다. 가로 넘침·브라우저 콘솔 오류는 없었다.
