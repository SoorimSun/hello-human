- 제공자: 헬로우 휴먼, OpenAI 이미지 생성 도구로 제작
- 용도: 기사 상단 썸네일과 공유 대표 이미지
- 내용: AI를 상징하는 장치에서 접근이 닫힌 문과 상점으로 열린 문으로 이어지는 연결선
- 상태: 개념을 표현한 AI 생성 삽화. 실제 제품 화면·공급사 데모·측정 결과가 아님
- 원본: 이번 기사를 위해 신규 생성. 외부 원본 이미지·로고를 입력하지 않음

- 이용 조건: 제3자 사진이나 제품 스크린샷을 재사용하지 않음. 기사에 AI 생성 사실을 표시함
- 선정 이유: DeepSeek 공식 발표의 벤치마크 이미지와 제품 데모를 검토했지만, 복합 주제를 대표하기에는 범위가 좁고 별도의 이미지 재사용 조건을 확인하지 못해 직접 제작한 설명용 삽화를 선택함
- 대체 텍스트: AI를 상징하는 밝은 장치에서 연결선이 뻗어 나와, 주황색으로 닫힌 문과 상품·서버가 있는 초록색 열린 문 앞에 닿아 있는 모습

본문 비교 그래프는 HTML/CSS로 작성했다. 발표 점수는 공식 모델 카드와 변경 기록에서 확인했고, 검색 비용 예시는 편집부 설명도라고 표시했다.

Shop MCP 보강 시 일반적인 연결 방식 비교를 논리 구조도와 체크아웃 분기 그림으로 대체했다. 두 그림도 HTML/CSS로 직접 작성했으며, 공식 문서의 [개요](https://shop.dev/docs), [도구](https://shop.dev/docs/tools), [인증](https://shop.dev/docs/authentication), [체크아웃](https://shop.dev/docs/checkout), [오류](https://shop.dev/docs/errors)를 재구성했다. 실제 서비스 화면이나 내부 배포도가 아니며, 제목·노드·설명·출처를 읽을 수 있는 HTML 텍스트로 제공한다. 모바일에서는 서비스·결제 분기 카드를 세로로 배치한다. 기존 표지 이미지는 변경하지 않았다.

실험 제안은 처음에 Shop MCP 상품 검색·옵션 선택·체크아웃 생성 및 조회 절차를 보여주는 HTML/CSS 흐름도로 교체했다. 이후 사용자의 실제 실행 요청에 따라 2026년 10월 18일 11:46~11:49 KST에 공식 API를 호출하고, 같은 흐름도를 관찰 결과 요약으로 갱신했다. 검색 3개·옵션 가격 65,700원·체크아웃 상태 `requires_escalation`·결제 호출 0회는 실제 응답과 호출 기록에 근거한다. 원시 서비스 화면이 아니라 편집부가 구성한 결과 요약임을 표시했다. 공개 상품 링크와 가격·상태만 본문에 싣고, 접근 키가 있는 체크아웃 ID·진행 URL은 제외했다. 결제 완료를 나타내는 화면이나 그림은 만들지 않았다. 표지 이미지는 그대로 유지했다.

요청·응답 코드 예시 앞에는 실제 호출의 ID 연결을 보여주는 HTML/CSS 도식을 추가했다. 상품 ID(P) → 상세 조회, 선택한 옵션 ID(V)·판매자(S) → 체크아웃 생성, 체크아웃 ID(C)·같은 판매자(S) → 재조회의 세 연결을 원래 필드 경로와 함께 표시한다. 문자가 같은 표식은 같은 값을 뜻하며 색상에만 의존하지 않는다. 공개 상품·옵션 ID와 도메인은 범례에 남기고 체크아웃 ID는 가린 자리표시자로 통일했다. 판매자는 앞 단계에서 보관한 값이라는 점을 명시했다. 이 그림은 기존 호출 관찰을 재구성한 설명도이며 새로운 호출이나 구매 완료 증거가 아니다. 모바일에서는 응답 다음 요청 순서로 세로 배치한다.

연결도의 각 단계에는 해당 코드 예시를 여는 링크를 추가했다. 기사 전용 스크립트가 관련 두 예시와 필드 강조를 연결하고, 다음 요청·연결도로 돌아가는 이동을 제공한다. 실제 ID 값은 수정하지 않았으며 가린 체크아웃 ID도 그대로 유지했다. 화면 조작으로 외부 API를 호출하지 않는다. 강조는 배경색과 밑줄을 함께 사용하고, 키보드 초점 및 선택 상태 설명도 제공한다.

선택한 연결의 응답·다음 요청을 두 카드로 비교하는 영역을 추가했다. 기존 발췌에서 필드를 가져와 같은 표식·같은 행으로 맞추고, 주변 JSON도 함께 펼쳐 볼 수 있다. 데스크톱에서는 좌우, 모바일에서는 응답 다음 요청 순서로 위아래에 표시한다. 세 번째 연결의 판매자는 앞선 요청에서 유지한 값임을 따로 표시하고 체크아웃 ID 가림을 유지했다. 별도 API 호출이나 새 서비스 화면을 사용하지 않았다.

비교 영역의 두 JSON 발췌에 복사 버튼을 각각 제공한다. 표시된 코드 텍스트만 복사하며 민감정보를 가린 자리표시자는 유지한다. 복사 완료 상태를 화면과 보조 기술에 알린다. 시각 자료의 근거와 기존 가림 범위는 그대로다.

네 도구의 요청과 비교 화면의 다음 요청에는 cURL 접기 영역·복사 버튼을 추가했다. 기존 공개 JSON에 전송 형식을 더한 Bash/zsh 예시이며 새로운 API 호출 결과가 아니다. 민감정보 자리표시자와 설명용 클라이언트 정보임을 표시하고, 명령은 실행하지 않았다.

cURL 예시는 Bash/zsh와 PowerShell을 전환할 수 있게 확장했다. 선택한 셸의 코드와 복사 안내를 함께 바꾸며, 기존 체크아웃 ID·멱등성 키 자리표시자는 양쪽 형식에서 유지한다. PowerShell은 `curl.exe`와 UTF-8 임시 파일을 사용하는 설명용 예시다. 새 API 호출이나 서비스 화면을 추가하지 않았고 명령은 실행하지 않았다.

마지막 셸 선택은 같은 브라우저에서 새로고침 후에도 유지한다. 저장하는 값은 Bash/zsh·PowerShell을 구분하는 이름뿐이며, 코드·요청 데이터·식별자를 저장하지 않는다. 화면의 민감정보 자리표시자는 계속 유지한다.

JSON·cURL 예시의 펼침 상태와 마지막 비교 단계도 새로고침 후 복원한다. 도구별 예시와 비교 영역은 각각 상태를 기억하며, 거래 데이터는 저장하지 않는다. 본문·도식 설명의 문장을 다듬었지만 원래 코드·값·출처 링크·표지 이미지는 유지했다. 이번 수정에서 새 API 호출이나 결제는 실행하지 않았다.
