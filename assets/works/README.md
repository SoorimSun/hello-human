# 회원 작업물 이미지

아래 최태준의 작업물 이미지는 2026-10-11(한국시간)에 실제 서비스에서 직접 캡처한 JPEG입니다. 기본 크기는 1280×720이며, 스크롤 영역을 캡처한 코스피 맵은 1265×712, 부동산맵은 1265×988입니다. 이미지 편집이나 게임 화면 합성 없이 사용하며, 원본을 새 탭에서 열 수 있도록 연결합니다. 화면에 보이는 시장 수치와 게임 상태는 촬영 시점 기준입니다.
